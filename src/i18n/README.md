# 外观与语言

- `preferences.ts`：全局主题和语言偏好，`useSyncExternalStore` 订阅，本地持久化，浏览器 storage 事件及 Tauri 事件同步。
- `messages.json`：产品文案的中英双语目录，每项为 `[中文, English]`。现有中文或英文文案作为稳定查询键，不依赖页面 DOM 翻译。
- `index.ts`：`t(key, values)` 插值、日期/排序 locale、错误消息翻译。单数计数使用对应英文形式。
- `PreferenceFields`：按 `field` 显示语言或主题选项；语言位于分类设置的“通用”，主题位于“外观”。`AppearanceControls` 只提供顶栏亮暗按钮，使用透明底和图标过渡，不用 aria-pressed 表示持续选中。偏好即时应用，不参与研究数据保存队列。

默认中文、跟随系统。持久化键 `scientify.preferences.v1`；首次升级从旧 `workspace.settings.theme` 读取主题，此后独立保存。存储不可用时继续在当前进程生效。偏好不包含秘密，不写入科研工作区 JSON。

开发约定：

1. 新增产品文案必须提供中英两份，使用 `t()`；数量、路径等变量使用 `{name}` 占位符。
2. 导航配置可以保存未翻译键，渲染时调用 `t()`，不要在模块加载时固定语言。
3. 用户标题、正文、文件名、模型回答不可传入通用翻译；业务枚举保存稳定值，仅翻译其标签。
4. 不为切换语言重建编辑器或工作区。CodeMirror 仅更新可访问名称，保留文件会话、撤销与选区。
5. 日期使用 `locale()`；后端错误在显示边界使用 `translateError()`。外部服务及系统返回的未知诊断原样显示。
6. 原生文件选择器按钮由操作系统语言决定。PDF 页面保持原文和纸张颜色，周边工具随主题切换。

偏好与渲染回归测试涵盖系统主题变化、跨窗口通知、持久化、损坏值回退、用户文本与未保存草稿保护、枚举值稳定、错误参数和翻译占位符一致性。
