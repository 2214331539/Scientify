# 写作页设计方案

- **状态**：2026-11-15 第一版评审通过，第一期“编写和编译”已实现，见第十八节
- **原型**：[写作页原型.html](../演示/写作页原型.html)。单个文件，直接在浏览器打开；左下角“标注”会给每个区域编号，并写出参考了哪个产品。
- **范围**：项目里“写作”模块的定位、界面结构、功能和分期。文献、笔记、实验不在本文范围，只写它们和写作的衔接。

## 一、定位

**写作模块是本地的 Overleaf。**

研究生写论文几乎都用 Overleaf：左边文件树，中间 LaTeX 源码，右边 PDF，点“重新编译”出结果，日志里点错误跳到出错的行。Scientify 照这个结构做，用法不需要重新学；不同的是：

- **在本地编译**：不依赖网络和服务器排队，大论文也不受编译时限限制；用本机的 TeX Live / MiKTeX，没有安装时用内置的编译引擎。
- **文件就在本机**：稿件是一个普通的 LaTeX 文件夹，可以用 Git 管理，也可以从 Overleaf 导入、导出。
- **和研究打通**：输入 `\cite{` 直接搜文献库，选中后自动写进参考文献文件；图可以从实验文件夹里选；AI 能看到项目里的论文和笔记。
- **团队同步**：稿件随项目同步给合作者（已有）；实时多人同时编辑放在后续。

一个项目可以有多篇**稿件**（会议版、期刊扩展版、学位论文），每篇是一个 LaTeX 文件夹，在左上角的稿件部件里切换。

## 五、侧边视图

**文件**

- 文件树：新建文件、新建文件夹、上传（拖入）、重命名、删除；行内新建，规则和资源管理器一致。
- 主文档带一个标记；右键可以“设为主文档”。
- 下面是大纲：按 `\section`、`\subsection` 列出当前文件的结构，点击跳到源码，并在 PDF 里定位。

**搜索**

- 在整篇稿件里搜索和替换；区分大小写、全词、正则表达式。

**参考文献**

- 已引用：正文里用到的条目，点击跳到第一次引用的位置。
- 缺失：用了但 bib 里没有的键；如果文献库里能找到，一键补全。
- 未使用：bib 里有但没引用的条目。
- 从文献库添加：搜索文献库，把条目写进 bib。

**审阅**

- 批注：选中文字写批注，可以回复、标为已解决。
- 修订：打开后，所有改动先作为建议显示；逐条或全部接受、拒绝。
- 批注和修订记在稿件旁的数据里，不改动 tex 源码。

**历史**

- 每次编译成功自动留一个版本；可以给版本加标签，例如“投稿版”。
- 选两个版本对比差异；恢复单个文件或整篇稿件。
- 稿件是 Git 仓库时，同时显示提交记录。

## 六、顶部工具栏

- **稿件部件**：当前稿件名；点开可以切换稿件、新建稿件（选模板）、打开 LaTeX 文件夹、从 Overleaf 导入、上传 zip。
- **重新编译**：主按钮，Ctrl+S 保存时也会编译；下拉里有自动编译开关、草稿模式（不渲染图片，更快）、遇到第一个错误就停止、清除缓存后重新编译、编译设置。
- **日志**：图标上显示错误和警告数；点开在 PDF 的位置显示日志。
- **下载 PDF**。
- **布局**：源码和 PDF、只看源码、只看 PDF。
- **更多**：导出源码压缩包、字数统计、编译设置、在资源管理器中显示。

## 七、编辑器

| 内容         | 能做什么                                                                                                                                                                                                              |
| ------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| tex          | 语法高亮；补全命令、环境、`\ref` 的标签、`\cite` 的条目、`\includegraphics` 的文件；常用片段（figure、table、equation、itemize）；自动补全括号和 `\end`；折叠环境和章节；拼写检查；语法检查（环境没闭合、括号不配对） |
| bib          | 高亮；格式化；按键或年份排序                                                                                                                                                                                          |
| 编辑器工具栏 | 撤消、重做、章节级别、加粗、斜体、列表、插入图、插入表、引用、交叉引用、公式、符号、批注                                                                                                                              |
| 图片、PDF    | 直接预览                                                                                                                                                                                                              |
| 可视编辑     | 像 Overleaf 的 Visual Editor 那样所见即所得地写，放在后续                                                                                                                                                             |

快捷键照 Overleaf：Ctrl+Enter 重新编译，Ctrl+S 保存（并编译），Ctrl+B / Ctrl+I 加粗、斜体，Ctrl+/ 注释，Ctrl+F 查找，Ctrl+Shift+C 批注，Ctrl+Shift+A 打开或关闭修订。例外：Ctrl+J 是打开 AI，和其他模块一致。

## 八、编译和 PDF

- **TeX 环境**：先找本机的 TeX Live / MiKTeX（latexmk）；找不到时用内置引擎（Tectonic，第一次编译时按需下载宏包）。设置里显示当前用的是哪一个。
- **编译器**：pdfLaTeX、XeLaTeX、LuaLaTeX；中文稿件默认 XeLaTeX。参考文献工具按文档自动选 BibTeX 或 Biber。
- **主文档**：默认是包含 `\documentclass` 的文件，可以改。
- **编译方式**：在稿件文件夹之外的缓存目录里编译，不往稿件里写 aux、log 这类文件；只有 PDF 可以选择写回稿件文件夹。
- **SyncTeX**：双击 PDF 跳到对应源码；在源码里点“→”在 PDF 里定位并闪一下。
- **PDF 预览**：页码、缩放、适应宽度和页面；可以在新窗口打开，适合双屏。

## 九、日志和错误

- 按错误、警告、排版问题（overfull / underfull box）分组；每条显示文件和行号、原文，点击跳到源码。
- 常见错误附简短说明，例如“未定义的命令：检查拼写或是否引入了宏包”。
- 原始日志和输出文件（aux、bbl、log）可以打开查看。
- 每条错误旁有“让 AI 修复”：带上出错位置附近的源码和日志，给出修改的差异，确认后写入。

## 十、引用和参考文献

- **补全**：输入 `\cite{`、`\citep{`、`\citet{` 时弹出列表，同时搜 bib 条目和文献库，显示标题、作者、年份、键。
- **自动写入**：选中文献库里有、bib 里没有的论文，自动生成 BibTeX 条目写进主 bib 文件，键名按“第一作者姓 + 年份 + 标题首词”生成，可在设置里改。
- **检查**：参考文献视图列出缺失、未使用、重复的条目；编译后的“引用未定义”警告也指向这里。

## 十一、插入图表

- **插入图**：从稿件文件、项目里的其他文件（例如实验文件夹的输出）里选，或拖入图片；选项包括标题、标签、宽度；生成 figure 环境。从别处选的图会复制进稿件的 figures 文件夹。
- **插入表**：选行列数生成 tabular，可以从 CSV 粘贴。
- **公式和符号**：符号面板按类别（希腊字母、关系、箭头、运算符）列出，点击插入。

## 十二、AI

- **内联修改**（Ctrl+I）：选中段落，让 AI 润色、改写、压缩、扩写、中英互译；差异直接显示在源码里，接受后才写入。
- **对话**（Ctrl+J）：自动带上当前文件、选中的内容和编译日志；可以“根据文献库起草相关工作”“检查引用是否支持这句话”。
- **修复编译错误**：见第九节。

## 十三、稿件管理

- **新建**：空白、常见会议和期刊模板（NeurIPS、ICML、ICLR、ACL、CVPR、IEEE、ACM、Elsevier、Springer）、中文学位论文模板。
- **导入**：打开本机已有的 LaTeX 文件夹（原地使用）；从 Overleaf 导入（Overleaf 项目的 Git 地址，或下载的 zip）；上传 zip。
- **导出**：PDF；源码压缩包（只打包主文档用到的文件，可直接上传到 Overleaf 或投稿系统）。

## 十四、和现在相比

| 现在                                              | 改为                                     | 原因                             |
| ------------------------------------------------- | ---------------------------------------- | -------------------------------- |
| 写作页是文件编辑器，Markdown 有预览，tex 只能编辑 | 源码和 PDF 并排、能编译                  | 论文是 LaTeX，必须能编译和看 PDF |
| 引用页签单独列出项目引用                          | 引用补全 + 参考文献视图，直接来自文献库  | 引用发生在写作时，不该另开一页   |
| 没有稿件的概念，项目文件都在一棵树里              | 多篇稿件，每篇一个 LaTeX 文件夹          | 会议版、期刊版、学位论文常常并存 |
| 没有版本                                          | 编译成功自动留版本，可加标签、对比、恢复 | 投稿和改稿需要找回旧版本         |
