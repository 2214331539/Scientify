# 产品演示

## 管理后台原型

[管理后台原型.html](管理后台原型.html) 是协作服务器上的管理后台和桌面应用里“账号与订阅”的第一版。设计说明见[商业化与管理后台设计方案](../专题/商业化与管理后台设计方案.md)。

- **概览**：注册、活跃、付费、收入、模型成本、同步空间；每日活跃和新注册、每日模型消耗、收入和成本；“需要处理”里的按钮会跳到对应页面。
- **用户**：按套餐、状态筛选，搜索手机号或昵称；点一行进详情，可以调整额度、更改套餐、单独限制、强制下线、停用；手机号默认遮盖，点“显示”会记入审计。
- **团队**：协作关系图（每个团队一圈，所有者居中）和列表；团队详情有成员 × 项目矩阵、30 天活动热力图、成员用量、空间构成。
- **计费**：套餐与扣费规则、兑换码（生成后只显示一次）、模型的成本价和售价（改价格时实时算毛利率和倍率）、渠道、用量明细、订单。
- **审计**：后台的每一次写操作，原型里做的操作也会出现在这里。
- **用户端**：右上角“用户端”打开桌面应用里的“账号与订阅”和 AI 助手的模型菜单，可以切换“额度充足”和“额度用完”。
- 左下角可以切换深色和退出登录（看登录页）。

**状态**：2026-11-16 待评审。用户、团队、金额和模型价格都是虚构的示例。

## 文档页原型

[文档页原型.html](文档页原型.html) 是把笔记模块换成团队文档的第一版。设计说明见[文档页设计方案](../专题/文档页设计方案.md)。

- **侧边视图**：搜索、新建；最近、收藏；页面树（悬停出现“+”和“⋯”）；底部模板和回收站。
- **文档页**：面包屑、同步状态和最后编辑人、协作者、分享、收藏、更多；页面图标和标题；右侧目录。
- **块编辑器**：鼠标移到块左侧出现“+”和“⋮⋮”（块菜单：转换、颜色、复制块链接、删除）；页尾“输入 / 插入块”打开斜杠菜单，“论文”从文献库插入卡片；点“阈值从 0.5 往上调…”这句出现浮动工具栏。
- **研究块**：论文卡片（带原文引用）、实验运行卡片、公式、表格、图、待办、折叠块。
- **同步冲突**：打开“StreamingJev 时机模型消融”，结论一节两人同时改了，可以选保留哪一方。
- **新建和模板**：在页面树上点“+”新建空页面，选模板填入内容；文档首页列出最近编辑和收藏。
- **AI**：右上角 AI → “把这周三次组会纪要汇总成周报”：读三页、审批后新建一页。

**状态**：2026-11-16 待评审。页面内容、成员和论文都是虚构的示例。

## 写作页原型

[写作页原型.html](写作页原型.html) 是写作模块的第一版：本地的 Overleaf。设计说明见[写作页设计方案](../专题/写作页设计方案.md)。

- **侧边视图**：文件（文件树 + 大纲，点大纲跳到源码并在 PDF 定位）、搜索、参考文献（缺失、已引用、未使用）、审阅（修订开关、批注）、历史（版本、标签、对比）。
- **顶部工具栏**：稿件部件（切换稿件、新建稿件选模板、从 Overleaf 导入）、重新编译和下拉选项、日志（错误和警告数）、下载 PDF、布局。
- **源码和 PDF**：错误行和批注行在行号旁标出；点红色波浪线的 `\cite` 打开引用补全，选文献库里的论文会自动写进 references.bib；双击 PDF 段落跳到源码，中间的“→”从源码定位到 PDF。
- **日志**：点日志按钮在 PDF 的位置打开；点错误跳到出错行；“让 AI 修复”给出差异，应用后重新编译。
- **编辑器工具栏**：插入图（可以选实验文件夹里的图）、插入表、引用、交叉引用、符号；“AI 修改”在源码里显示差异。
- **快捷键**：Ctrl+Enter 重新编译，Ctrl+S 保存并编译，Ctrl+P 转到文件或引用。

**状态**：2026-11-15 评审通过，第一期（编写和编译、导入导出）已实现并通过 Windows 验收，进度见[写作页设计方案](../专题/写作页设计方案.md)第十八节。论文内容、编译结果和文献都是虚构的示例。

## 实验管理原型

[实验管理原型.html](实验管理原型.html) 是实验模块的第三版：在实验页原型的基础上，把“运行”这个概念去掉，以**实验**作为管理单元。设计说明见[实验页设计方案](../专题/实验页设计方案.md)第十七节。

- **侧边视图“实验”**：按进行中、实验组、未分组列出实验，显示进度或主要指标；可以筛选；实验组右侧可以直接比较这一组。
- **实验页**：目的、指标和参数、曲线、结论（“让 AI 起草”）、怎么做的（命令、代码版本、解释器、数据）；可以复制为新实验、用原代码重做、插入到笔记。
- **新建实验**：工具栏的 ＋ 或侧边视图的 ＋。写目的、选实验组、改参数；参数勾选“多个值”就一次建一组实验。工具栏的 ▶ 用当前代码和默认参数直接开始。
- **全部实验**：一张表看目的、状态、参数、指标，可以按实验组或提交分组、画图、勾选比较。
- **其他**：资源管理器里行内新建文件和文件夹；状态栏右下角点解释器打开“选择 Python 解释器”；侧边栏第五个图标是“扩展”（待开发）；面板里的“运行”改名为“输出”。

**状态**：2026-11-15 评审未通过：AI 味重，新建实验不该填一张通用表格（不同实验没有通用模板）。应用里的实验管理先显示“待开发”，以后重新设计；这份原型留作参考。

## 实验页原型

[实验页原型.html](实验页原型.html) 是实验模块的第二版设计：外壳和配色与现在的应用一致，里面按 VS Code、PyCharm 的布局做成代码工作台，再加上运行记录。设计说明见[实验页设计方案](../专题/实验页设计方案.md)。

- **左下角**：“标注”给每个区域编号，并写出参考了哪个产品；“夜”切换夜间配色；“重置”恢复示例数据。
- **侧边视图**：侧边栏顶部的五个图标切换资源管理器（展开折叠、打开文件）、搜索、源代码管理（暂存、放弃、AI 写提交消息、提交）、运行、Python 环境。
- **顶部工具栏**：文件夹部件（切换文件夹、克隆仓库、新建空文件夹）、分支部件、运行部件（切换配置、以不同参数运行、运行、停止）。
- **编辑器标签**：代码（Ctrl I 内联修改）、笔记本（运行单元格）、数据查看器、运行记录（表格、图表、分组、勾选比较）、运行详情（概览、日志、指标、产物，用原代码运行）、Git 图（展开提交）、差异。
- **面板和状态栏**：终端、运行、问题、变量；状态栏的解释器可以点开切换；Ctrl P 转到文件、运行或命令。
- **AI**：失败运行“让 AI 排查”，应用修改并重新运行；比较页“让 AI 总结”并补跑随机种子。
- **模拟**：正在跑的程序每隔几秒前进一轮，面板输出、运行表和曲线实时更新；一组运行超出并发数时排队。

**状态**：2026-11-15 第二版评审通过，第 1 期（布局）已实现并通过 Windows 验收，进度见[实验页设计方案](../专题/实验页设计方案.md)第十六节。原型里的代码、运行、提交和人员都是虚构的示例数据。

## 项目中心原型

[项目中心原型.html](项目中心原型.html) 是项目中心的可交互原型，用来验收重新设计的首页、我的项目、团队项目和收集箱。

- **顶部切换**：平台（Windows、macOS）、场景（日常使用、新用户、未登录、离线）、窗口大小（1100×740、1440×900、800×560）。
- **可以操作**：侧栏导航、筛选和排序、书架和列表、右键菜单、新建项目两步向导、共享到团队、邀请成员、改角色、处理冲突、登录、搜索面板（Ctrl K / ⌘K）；macOS 下顶部的系统菜单栏也能点。
- **设计说明**：右侧面板逐页写明布局、状态和与现在的区别（新增、调整、已有）；“实现范围”列出验收后的实现批次和需要服务端配合的事项。
