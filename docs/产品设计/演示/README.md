## 页面结构演示

[页面结构演示.html](页面结构演示.html) 用接近真实的界面演示 Scientify 每个页面的布局和功能入口，单个文件，离线可以直接用浏览器打开。

- **左侧目录**：按“开始、项目中心窗口、项目窗口、全局”分组，每页标注已有、需调整或待做。
- **平台切换**：左上角切换 Windows 和 macOS，界面外壳、菜单、设置窗口、快捷键随之变化；也可以在地址后加 `?plat=mac` 或 `?plat=win`。
- **编号说明**：界面上的橙色编号对应下方的“区域与入口”；下方还有“从这里去”“状态”“和现在相比”。
- **可点击**：界面里的模块栏、侧栏、搜索框、共享、通知等可以点击，跳到对应页面，用来检查入口是否通顺。

## 项目中心原型

[项目中心原型.html](项目中心原型.html) 是项目中心的可交互原型，用来验收重新设计的首页、我的项目、团队项目和收集箱。

- **顶部切换**：平台（Windows、macOS）、场景（日常使用、新用户、未登录、离线）、窗口大小（1100×740、1440×900、800×560）。
- **可以操作**：侧栏导航、筛选和排序、书架和列表、右键菜单、新建项目两步向导、共享到团队、邀请成员、改角色、处理冲突、登录、搜索面板（Ctrl K / ⌘K）；macOS 下顶部的系统菜单栏也能点。
- **设计说明**：右侧面板逐页写明布局、状态和与现在的区别（新增、调整、已有）；“实现范围”列出验收后的实现批次和需要服务端配合的事项。
