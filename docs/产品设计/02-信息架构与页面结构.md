# 信息架构与页面结构

本文定义 Scientify 的完整页面结构：有哪些窗口、每一级页面显示什么、从哪里进入、通往哪些子页面。每个页面的详细设计见 [页面设计](页面/README.md)。

状态标记：**已有** 表示已实现；**部分** 表示已实现但有明显缺口；**待做** 表示尚未实现或现在是占位页。

## 一、层级定义

| 层级          | 是什么                             | 例子                                                             |
| ------------- | ---------------------------------- | ---------------------------------------------------------------- |
| L0 窗口       | 独立的系统窗口或全屏覆盖页         | 项目中心、项目工作区、登录页、划词翻译浮窗                       |
| L1 一级页面   | 窗口左侧导航上的入口               | 我的项目、团队空间；概览、文献、笔记、实验、写作                 |
| L2 二级页面   | 一级页面里的视图，用侧栏或标签切换 | 文献库、订阅；实验列表、代码、运行记录、版本                     |
| L3 详情页     | 单个对象的页面                     | 论文阅读页、论文详情、笔记编辑页、实验详情、运行详情、稿件编辑页 |
| L4 弹窗与面板 | 表单、确认框、设置分区、右侧栏     | 新建项目、导入文献、运行配置、AI 助手、设置                      |

规则：

- **层级最多四级**：任何功能从窗口出发，最多点三次就能到达。
- **对象有固定的家**：每类对象只在一个一级页面下有详情页，其他地方一律链接过去，不重复做页面。
- **弹窗只做短任务**：填表、确认、选择。需要长时间停留的内容放进页面或右侧栏。

| ------------------------- | ---------------------------------- | -------------------------------------------------- | ---- |
| 项目中心                  | 启动应用、关闭项目后               | 首页、我的项目、团队项目、收集箱、账号和设置       | 已有 |
| 项目工作区                | 打开一个项目                       | 同一时间只开一个项目，可在顶栏原地切换项目         | 已有 |
| 登录页                    | 点左下角“登录”或任何需要登录的入口 | 全窗口覆盖页，登录后回到原处                       | 已有 |
| 首次使用引导              | 第一次启动                         | 介绍三步工作流，可打开示例项目                     | 待做 |
| 划词翻译浮窗、AI 问答浮窗 | 在任意应用里选中文字               | 由内置的 Yita 提供；箭头按钮把对话转到 AI 助手     | 已有 |

## 四、两个窗口的固定框架

### 项目中心

| 区域     | 内容                                                                           |
| -------- | ------------------------------------------------------------------------------ |
| 左侧导航 | 品牌、搜索入口；首页、我的项目、团队项目、收集箱；收藏；底部是账号、帮助、设置 |
| 主区     | 当前一级页面                                                                   |
| 顶部     | 页面标题和主要操作；Windows 的窗口控制在最右边，macOS 用系统标题栏             |
| 右侧栏   | 收集箱的笔记和快速问答在这里编辑；其他页面默认收起                             |

### 项目工作区

| 区域       | 内容                                                                       |
| ---------- | -------------------------------------------------------------------------- |
| 顶栏       | 返回项目中心、项目切换器、全局搜索按钮、同步状态、通知、主题切换、窗口控制 |
| 左侧导航栏 | 概览、文献、笔记、实验、写作；底部是设置、帮助                             |
| 资源侧栏   | 一级页面自己的侧栏（文献目录树、实验活动栏等），可调宽度、可收起           |
| 主区       | 二级页面或详情页；多个对象时用标签页                                       |
| 右侧栏     | AI 助手、笔记速记；可调宽度，窗口窄时浮在主区上方                          |
| 状态栏     | 保存状态、同步状态、运行中的任务、AI 和笔记开关                            |

## 五、导航规则

- **进入项目**：在项目库点项目、在首页点“继续工作”、在搜索结果里选项目或项目里的对象。进入后回到这个项目上次停留的位置；第一次打开进入概览。
- **离开项目**：点顶栏的品牌按钮回到项目中心。有未保存内容或后台任务时先提示。
- **切换项目**：顶栏的项目切换器原地切换，不新开窗口。
- **一级页面之间**：点左侧导航或用快捷键。每个一级页面记住自己上次的二级页面和打开的对象。
- **进入详情页**：从列表、树、搜索、链接进入。详情页顶部有面包屑，可以返回列表。
- **跨模块跳转**：
  - 笔记里的来源可以跳到论文的对应页码、运行或文件；
  - AI 回答里提到的论文、运行、文件可以点开；
  - 运行记录可以跳到所属实验和产生它的 AI 对话；
  - 稿件里的引用可以跳到论文详情。
- **深链接**：搜索结果、通知和“继续工作”都带目标对象，打开项目后直接定位到该对象。
- **返回与关闭**：弹窗按 Esc 关闭，有未保存内容先确认；标签页关闭前先保存。

## 六、每个页面都要处理的状态

| 状态     | 处理                                                                   |
| -------- | ---------------------------------------------------------------------- |
| 空       | 说明这里会出现什么，并给出第一步操作（例如“打开文献文件夹”“新建实验”） |
| 加载中   | 在原位置显示进度，不遮住整个窗口                                       |
| 出错     | 在出错的区域说明原因并给出重试；不丢已输入的内容                       |
| 离线     | 本机功能照常使用；需要网络的功能标明“联网后可用”                       |
| 无权限   | 团队项目里按角色隐藏或禁用编辑操作，并说明原因                         |
| 仅桌面版 | 浏览器预览里说明需要桌面应用                                           |
