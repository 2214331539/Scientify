# 笔记

项目里的研究笔记：阅读心得、实验记录、会议纪要、想法。笔记可以挂上来源，连到论文的某一页、某次运行或某个文件。

## 笔记库（部分）

**定位**：找到、整理项目里的全部笔记。

**入口**：左侧导航“笔记”；概览“最近笔记”；搜索结果。

**布局**：左栏是笔记列表，主区是当前选中笔记的编辑页。

**显示内容**：

- **分组**（待做）：
  - 全部、研究笔记、会议纪要、待办、收藏；
  - 论文笔记：汇总各篇论文旁边的笔记。
- **标签**（待做）。
- **列表**：标题、摘要、更新时间、标签、来源数量。
- **排序**（待做）：更新时间、创建时间、标题。

**操作**：

- **新建**：可以选模板（待做），包括空白、阅读笔记、实验记录、会议纪要。
- **搜索**：标题和正文。
- **整理**（待做）：
  - 删除，移入回收站，可以恢复；
  - 移到其他项目或收集箱；
  - 导出 Markdown；
  - 多选后批量操作。

**状态**：

- **没有笔记**：引导新建，并介绍模板；
- **搜索无结果**：提供清除搜索。

**现状**：部分。已有列表、搜索、新建和编辑。还没有：

- 删除笔记；
- 分组、标签、排序和模板；
- 论文笔记的汇总（目前论文笔记只能在文献页里看）。

## 笔记编辑页（部分）

**定位**：写笔记，并把它和论文、运行、文件连起来。

**入口**：笔记库点笔记；概览“最近笔记”；搜索结果；右侧栏“笔记”。

**布局**：

- **顶部**：返回、标题、保存状态、更多菜单；
- **中间**：编辑区；
- **底部**：来源栏。

**显示内容**：

- **正文**：Markdown 实时预览，支持数学公式、图片、表格、任务列表、代码块；
- **标题目录**；
- **来源**：论文页码、文件、运行，点击跳回原处；
- **反向链接**（待做）：哪些笔记或稿件引用了这篇笔记；
- **标签**（待做）。

**操作**：

- **编辑工具栏**：粗体、斜体；插入标题、列表、任务、引用、链接、代码、公式、表格、分割线；插入图片；撤销、重做、查找替换；切换源码模式。
- **插入图片**：粘贴或拖入，图片保存在本机。
- **添加当前来源**：把正在看的论文页、选中的文字或运行加为来源。
- **链接其他笔记**（待做）：输入 `[[` 选择要链接的笔记。
- **让 AI 改写或总结**（待做）：结果先预览，确认后再写入。
- **删除、移动、导出**（待做）。

**状态**：正在保存、已保存到本机、保存失败。保存失败时保留草稿，并提供重试。

**现状**：部分。已有编辑、来源和自动保存（停止输入 0.9 秒后保存）。还没有反向链接、`[[` 双向链接、标签和删除。

## 右侧栏笔记速记（已有）

**定位**：在任何页面随手记一笔，不用离开当前工作。

**入口**：右侧栏的“笔记”标签；状态栏的笔记开关；快捷键 Mod+Shift+O。

**行为**：

- 记到当前项目的笔记里，和笔记库里的是同一批；
- 在“笔记”一级页面里，右侧栏不再显示笔记，避免同一篇笔记出现两次；
- 在项目中心打开时，记到收集箱。
