## 每个页面的写法

| 项       | 写什么                               |
| -------- | ------------------------------------ |
| 定位     | 一句话说明这个页面解决什么问题       |
| 入口     | 从哪些地方能进来                     |
| 布局     | 页面分成哪几块                       |
| 显示内容 | 每块显示什么                         |
| 操作     | 用户能做什么                         |
| 子页面   | 从这里能去哪些页面和弹窗             |
| 状态     | 空、加载、出错、无权限等情况怎么显示 |
| 现状     | 已有、部分或待做，以及和设计的差距   |
