# 写作

把文献、笔记和实验结果写成论文。左侧导航的“写作”入口现在是“LaTeX 论文撰写”的占位页；下面是目标设计。代码里已有未接入界面的稿件和引用视图原型，可以在此基础上实现。

## 稿件列表（待做）

**定位**：管理项目里的全部稿件：论文、报告、投稿版本。

**入口**：左侧导航“写作”；概览的快捷操作“新建稿件”。

**显示内容**：

- **每份稿件**：名称、类型（LaTeX 或 Markdown）、模板、页数或字数、最近一次编译的结果、更新时间；
- **工具栏**：新建稿件、关联已有的 LaTeX 目录、搜索。

**操作**：

- **新建稿件**，可选模板：
  - 空白 LaTeX；
  - 常见会议和期刊模板；
  - Markdown 报告。
- **打开、重命名、复制为新版本、归档**。

**子页面**：稿件编辑页、新建稿件弹窗。

**状态**：没有稿件时，介绍写作页能做什么，并给出“新建稿件”。

## 稿件编辑页（待做）

**定位**：写稿、编译、预览，并随时引用项目里的文献和实验结果。

**入口**：稿件列表；概览；搜索结果。

**布局**：

- **左侧**：文件树（tex、bib、图片）和章节大纲；
- **中间**：源码编辑器；
- **右侧**：PDF 预览；
- **底部**：编译日志。

**显示内容**：

- **源码**：LaTeX 语法高亮；输入 `\cite`、`\ref` 时自动补全；
- **PDF 预览**：编译后显示，源码和 PDF 可以互相定位；
- **编译日志**：错误和警告，点击跳到出错的行。

**操作**：

- **编译**：使用本机的 TeX 环境；没有安装时，引导安装或使用内置的编译器。
- **插入引用**：搜索文献库，选中后自动写入参考文献文件。
- **插入图表**：从运行产物里选图片或表格，并记住它来自哪次运行。
- **版本**：提交、对比两个版本。
- **导出**：PDF、源码压缩包。
- **AI 协助**：
  - 润色选中的段落；
  - 检查引用是否都在文献库里；
  - 根据文献库起草相关工作。

  AI 的修改先显示差异，确认后才写入。

**状态**：

- **没有 TeX 环境**：说明怎么安装；
- **编译失败**：在日志里标出错误；
- **引用找不到**：标出缺失的条目。

## 参考文献（待做）

**定位**：稿件的参考文献直接来自文献库，不用手工维护 bib 文件。

**显示内容**：稿件引用到的论文、引用键、缺失或重复的条目。

**操作**：

- 从文献库添加引用；
- 更新条目信息；
- 把文献库里有、但 bib 文件里没有的条目补进去。

## 图表（待做）

**定位**：把实验结果变成稿件里的图和表。

**显示内容**：运行产物里的图片和表格，每一项都标明来自哪次运行、用的什么配置。

**操作**：插入稿件；运行更新后提示稿件里的图已过期，可以一键替换。
