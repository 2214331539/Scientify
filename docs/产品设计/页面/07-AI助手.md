# AI 助手

在每个页面旁边的研究助手。在项目里，它通过内置的 Codex Agent 读论文、读写笔记、在实验目录里执行命令和运行实验；在项目外，它只做快速问答。

## 入口与布局

**入口**：

- 右侧栏“AI 助手”标签、状态栏的 AI 开关；
- 快捷键 Mod+Shift+L 打开，Mod+Shift+N 新建对话；
- 阅读页选中文字后点“提问”；
- 划词翻译浮窗的箭头按钮；
- 概览的“问 AI”。

**布局**：

- **顶部**：对话标题（点开是对话历史）、新建对话、更多菜单（任务类型、查看当前材料、模型设置）、当前模式标识；
- **中间**：消息、执行记录、审批卡、关联的运行；
- **底部**：输入区，包括材料标签、附件、技能、模型、权限、发送或停止、补充指令。

## 两种模式（要求明确可见）

| 模式     | 什么时候用                                                                     | 能看到和能做什么                                                                                                                      |
| -------- | ------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------- |
| Agent    | 在项目里（任何页面），且模型连接支持 Agent（OpenAI 协议、Ollama）              | 列出和读取项目里的全部论文（每次 8 页，可以接着往下读）、搜索论文、读写笔记、在实验目录里执行命令和运行实验、Git 操作、控制内置浏览器 |
| 快速问答 | 项目中心和收集箱；划词翻译浮窗；模型连接不支持 Agent（Anthropic、Gemini 协议） | 只能看到发给它的材料：当前页、选中的文字、附件。不能读写文件                                                                          |

**设计要求**：

- **模式始终可见**（已有）：输入框右侧显示“Agent”或“快速问答”，悬停说明能看到什么；快速问答不显示权限按钮。
- **划词对话转到项目里时改用 Agent**（已有，2026-11-05）：在侧栏继续一个从划词翻译开始的对话时，只要在项目里就改用 Agent，并把划词的原文、译文和之前的问答带过去。2026-11-03 定位的“读 PDF 只能看到一页”主要就是这种对话一直停留在快速问答。
- **当前论文直接可读**（已有，2026-11-05）：阅读页把打开的 PDF 文件名放进材料，Agent 可以直接按页读取；问整篇论文时要求从第 1 页读到最后再回答。
- **需要全文时给出入口**：快速问答模式下，问题涉及整篇论文时，提供“用 Agent 读全文”按钮。
- **PDF 附件**：
  - PDF 在项目文献库里：改为引用这篇论文，由 Agent 按页读取；
  - 不在文献库里：明确提示“附件只包含前 N 页（共 M 页）”，并提供“加入文献库后读全文”。
  - 现在的做法是只取前 12000 个字。

## 材料

**自动附带**：当前项目和页面，打开的文件、论文和页码、网址，以及选中的文字。每条消息可以选择不附带。

**查看当前材料**：弹窗列出这条消息会附带的全部材料，以及上一次发送时的提示。

**附件**：每条消息最多 4 个。图片不超过 8 MB，PDF 不超过 20 MB，文本和代码文件不超过 2 MB。

## 工具与权限

**Agent 能用的工具**：

- **文献**：列出论文、按页读取、搜索论文。2026-11-05 起所有项目对话都有，不再只限文献页开始的对话；之前的旧对话保留原来的工具，在文献页会提示新建对话；
- **笔记**：列出、读取、修改已有笔记；
- **实验**：在受管理的环境里启动、查看、停止运行，读取结果；Git 查看和操作；
- **浏览器**：列出、打开、读取网页，网页搜索；
- **通用**：执行命令、修改文件。

**权限模式**（每个对话单独设置）：

- **询问**：在沙箱里运行，只能改当前工作区；越权、执行 Git 操作或修改笔记前都先审批。
- **完全允许**：不使用沙箱，可以联网、访问工作区外的文件，不再逐项审批。

**审批卡**：允许、本会话允许、拒绝、中止任务。Git 操作和笔记修改没有“本会话允许”。

## 技能

在输入框输入 `/skills`，最多选 4 个技能。技能来自工作区的 `.agents/skills` 文件夹或 Scientify 自带的技能。技能只能在 Agent 模式下使用。

## 模型

- **模型菜单**：
  - 当前连接的验证状态和可选模型；
  - 其他已保存的连接；
  - “配置其他模型”。
- **模型设置**：
  - 连接名称、模型提供方、接口协议、服务区域、服务地址、API 密钥（只保存在本机）；
  - 测试连接，获取模型列表；
  - 分别验证聊天能力和 Agent 能力；
  - 使用 Scientify 官方模型时需要先登录。

建议把模型设置同时放进全局设置的“AI 模型”分区（见[设置与数据](09-设置与数据.md)）。

## 对话管理

- **对话历史**：最新的在前，可以重命名、删除。
- **后台任务条**：显示其他对话的状态（运行中、等待审批、待保存），点击切过去。切换对话或收起侧栏都不会中断任务。
- **关联运行**：AI 启动的运行显示在对话里，可以打开运行详情、查看日志或停止。

## 状态

| 情况               | 显示                             |
| ------------------ | -------------------------------- |
| 连接验证失败       | 说明原因，提供重新验证和模型设置 |
| 连接断开           | 提供恢复连接                     |
| 旧对话缺少新工具   | 提示新建对话                     |
| Windows 沙箱未配置 | 提供“配置 Windows 沙箱”          |
| 对话保存失败       | 保留内容，提供重试               |

## 能力边界

| 能做                                                      | 做不到或有限制                                   |
| --------------------------------------------------------- | ------------------------------------------------ |
| 读项目文献文件夹里的全部论文，每次 8 页、可以连续读到最后 | 扫描版 PDF（没有 OCR）、超过 50 MB 的 PDF        |
| 读写代码目录、执行命令、启动和停止受管理的运行、Git       | 询问模式下不能写工作区以外的文件，命令默认不联网 |
| 读取和修改已有笔记                                        | 不能新建笔记                                     |
| 用内置浏览器搜索、打开和读取网页（每页最多约 16000 字）   | 网页登录和验证码需要用户自己处理                 |
| 每个对话只操作自己的项目和绑定的目录                      | 不能访问其他项目；项目中心和收集箱里只能快速问答 |

“完全允许”模式不使用沙箱，可以联网和访问工作区以外的文件。

## 现状与差距

大部分已实现。差距：

- **快速问答读不到全文**：项目外（收集箱、划词浮窗本身）的问答仍只看到当前页和选中的文字；
- **Agent 不能新建笔记**，只能修改已有笔记；
- **PDF 附件只取前 12000 个字**；
- **模型设置只在 AI 面板里**；
- **权限胶囊上的“Permission”没有翻译**。
