# 实验

管理项目里的实验。每个实验有自己的目的、代码目录和 Python 环境；每次运行都留下可复现、可比较的记录。

**整体布局**：

- **实验活动栏**：最左侧的窄栏。上面是实验列表、代码、搜索、版本、运行记录、Worktree；下面是后台任务、Python 环境。
- **命令栏**：除实验列表外都有，包括当前实验、运行配置、保存全部、运行、停止。
- **底部状态栏**：当前分支、变更数、Python 解释器、新建终端。

## 实验列表（已有）

**定位**：看全项目的实验，进入其中一个。

**入口**：左侧导航“实验”（默认显示这一页）；快捷键 Mod+Shift+E；概览“实验动态”。

**显示内容**：

- **卡片或表格**：名称、目的、Python 版本、代码目录、当前解释器、最近一次运行、运行中的任务数、更新时间；
- **默认实验**：每个项目自动有一个“默认实验”；
- **工具栏**：搜索、显示已归档。

**操作**：

- **新建实验**：弹窗填写名称、目的、代码来源、目录。代码来源有三种：新建空目录、关联已有目录、新建 Worktree。
- **打开**：进入这个实验的代码页。
- **重命名**、**归档或恢复**、**移除**（有任务在运行时不能移除）。

**子页面**：实验详情、代码、运行记录、新建实验弹窗。

**状态**：没有实验时引导新建。

## 代码（已有）

**定位**：在实验目录里写代码、运行和排查问题。

**入口**：实验列表“打开”；活动栏“资源管理器”；快捷键 Mod+Shift+P。

**布局**：左侧资源面板，中间编辑器，底部面板，顶部命令栏。

**显示与操作**：

- **资源管理器**：新建文件、全部折叠、刷新、筛选文件，以及文件树。
- **搜索**：可区分大小写、全词匹配、正则表达式。结果显示“路径:行号”和预览；一次最多 500 个文件、200 条结果。
- **编辑器**：
  - 文件标签，未保存的标签有标记；关闭未保存的标签时，可以选择保存并关闭、保留草稿或取消；
  - 保存、重新读取、撤销、重做、查找、替换、自动换行；
  - Markdown 可以切换源码、分栏、预览；
  - 磁盘上的文件被别处改过时，可以查看磁盘内容、另存一份或重试。
- **底部面板**：
  - 终端：多个会话，可选 PowerShell、cmd、bash、zsh、Python 交互环境，可分屏，可中断；
  - 日志：实时显示运行输出；
  - 产物：预览运行生成的文件。

**运行的过程**：

1. 选择运行配置，点“运行”。
2. 第一次运行时依次确认三件事：信任这个目录、保存未保存的文件、选择 Python 解释器。
3. 日志在底部实时显示，结束后自动生成一条运行记录。

**现状**：已有。还没有：断点调试、Notebook、代码补全和跳转（语言服务）。

## Python 环境（已有）

**定位**：为实验准备和管理 Python 环境。

**入口**：活动栏底部“Python 环境”；状态栏的解释器按钮。

**三个标签**：

- **环境**：信任目录并检测 Python；选择或手动填写解释器；新建 venv 或 Conda 环境；打开终端。
- **依赖**：安装、升级、卸载包；按 requirements 安装；可编辑安装；按 environment.yml 更新 Conda 环境；已安装包的列表。
- **任务**：环境相关任务的列表，可以停止，查看命令和日志。

## 运行记录（部分）

**定位**：每次运行的完整记录，用来复现和比较。

**入口**：活动栏“运行记录”；实验详情；AI 回答里的运行链接；通知。

**显示内容**：

- **表格**：运行名、状态、来源（AI 实验、本地运行、手动记录）、更新时间、关键指标；
- **筛选**：按状态、按来源；还有搜索；
- **比较**：最多选 4 条并排比较。

**运行详情**（L3）分四个标签：

- **结果**：指标、实验方案、配置与参数、结论、退出码和耗时；
- **日志**；
- **产物**：预览文件，可以从 JSON 导入指标；
- **环境与版本**：命令、参数、目录、Worktree、分支、提交、平台、Python、执行权限，以及发起运行的 AI 对话。

**操作**：新建手动记录、编辑记录、再次运行、比较。

**待做**：删除记录、指标图表（多次运行的曲线对比）、导出为表格。

## 运行规则

这些规则适用于所有运行，不管是在代码页点“运行”、在运行记录里“再次运行”，还是 AI 启动的。

**状态**：

- 界面上的状态：排队、启动中、运行中、正在停止、成功、失败、已取消、已中断。
- 程序正常退出就是“成功”，没有产物也可以是成功；科研结论由用户自己填写，程序成功不等于假设成立。
- 结果整理失败（例如指标解析失败）单独提示，不改写运行本身的状态。

**后台与并发**：

- 切换页面、项目、AI 对话，或收起侧栏，运行都继续。
- 后台任务列表按项目分组，分 AI 任务、实验运行、环境任务三类，每条都能停止，点击回到所属的运行。
- 同时最多 8 个运行；终端最多 32 个；环境任务最多 8 个。

**停止**：

- 运行行、日志标题、运行详情、AI 对话里的运行卡片，用的是同一个“停止实验”。
- 点停止后立即显示“正在停止”，等进程真正结束再显示结果；长时间停不下来时提供“强制结束”，并说明没写到磁盘的数据可能丢失。
- **停止 AI 对话不会停止它启动的实验**。对话里提示“AI 已停止，1 个实验仍在运行”，并保留“停止实验”按钮。
- 关闭应用时有运行中的实验，提供“返回继续”和“停止任务并退出”两个选择。

**意外退出**：重新打开后，结果无法确认的运行标为“已中断”，保留日志、命令和已有产物；不会自动重跑。“再次运行”生成一条新记录。

**日志**：

- 代码页底部和运行详情显示同一份日志。
- 停在底部时自动跟随新输出；往上翻后暂停跟随，提示“有新输出”。
- 长时间没有输出时显示“运行中，最后输出于某时”，不显示假的进度百分比。
- 错误输出不等于失败，以退出码为准。
- 日志显示最后 256 KB；一次运行的日志超过 64 MB 时停止运行，并明确提示截断。
- “让 AI 排查”附带运行配置、环境摘要、失败处附近的日志，以及用户选的文件，发送前可以看到范围。

**列表**：

- 按时间倒序，运行中的排在最前；
- 没有指标显示“未记录”，不显示 0；手动记录标为“手动”；
- 运行中的记录只能查看、重命名和停止，不能删除或改配置；
- 删除（待做）默认只删记录，可以另外勾选清理日志和产物，清理前列出路径和大小；代码和原始数据不随记录删除。

**指标**：

- 来源只有三种：手动填写、导入 CSV 或 JSON（先预览字段再确认）、程序写出的结构化指标文件（后续）；
- AI 从日志里推测的数值只能作为“待确认”，不直接记为指标；
- 空值、解析失败、NaN 分别说明，不转换成 0。

**产物**：只收集这次运行声明的输出目录（`SCIENTIFY_RUN_DIR`）；文件后来被改动或删除时标为“内容已变化”或“文件缺失”；预览不执行任何代码。

**比较**：

- 选 2–4 条；可以设一条为基准，只看不同的部分；
- 只有指标名称、单位、数据划分和评价方式都相同时才高亮最好的值，否则标为“可比性未确认”；
- 图表只用真实的指标数据，不用模拟曲线填空。

**再次运行**：复制当时的配置，显示和当时相比代码、环境有哪些变化，然后生成新记录；原记录保留。运行开始时记下提交和未提交的改动，但不给记录贴“完全可复现”的标签。

**空状态与异常**：

| 情况                           | 显示                                                   |
| ------------------------------ | ------------------------------------------------------ |
| 实验目录里没有文件             | 当前目录的位置，以及新建文件、关联已有目录、让 AI 起步 |
| 没有运行记录                   | “尚无运行记录”，提供运行和新建手动记录                 |
| 目录或入口文件失效             | 原路径和原因，历史记录仍可查看；提供重新关联           |
| 没有 Python 环境或依赖安装失败 | 缺什么、正在用的解释器、安装日志；提供重试             |
| 没有指标或产物                 | “本次未登记指标”“未发现输出目录里的产物”，不编造结果   |
| AI 不可用                      | 手动运行照常可用，只在 AI 助手里报错                   |

成功和失败用状态和状态栏标记提示，默认不弹出对话框；只有冲突、删除和权限这类需要用户选择的情况才用弹窗。后台任务结束不抢焦点、不自动跳转。

## 版本（已有）

**定位**：在实验目录里使用 Git，不用离开应用。

**入口**：活动栏“版本”；状态栏的分支按钮。

**五个标签**：

- **更改**：已暂存和未暂存的文件，可以暂存、取消暂存、还原（需确认）；并排显示差异；填写说明后提交。
- **提交历史**：搜索提交，查看每次提交的改动。
- **分支**：新建、切换、删除（需确认）。
- **Stash**：保存（可以包含未跟踪的文件）、应用、弹出。
- **Worktree**：新建（新分支或已有分支）、打开为实验、移除。

**状态**：目录还没有初始化 Git 时，提供“初始化 Git 仓库”。

**现状**：已有本地操作。还没有远程操作（推送、拉取、获取、合并）和冲突解决。

## 弹窗

- **新建实验**：名称、目的、代码来源、目录。
- **运行配置**：名称、可执行程序、参数、工作目录；可以删除配置。
- **信任目录**：第一次在某个目录运行代码前确认。
- **后台任务**：所有项目正在运行的任务，可以查看或停止。
- **产物预览**：查看运行生成的文件。
- **Git 相关**：新建分支、保存到 Stash、新建 Worktree。
