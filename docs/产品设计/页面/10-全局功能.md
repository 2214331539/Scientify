# 全局功能

不属于某一个页面、在整个应用里都能用的功能：搜索与命令面板、通知中心、首次使用引导、划词翻译、快捷键、帮助，以及托盘和窗口行为。

## 搜索与命令面板（L4，部分）

**定位**：一个入口找到任何对象、执行任何命令。

**入口**：

- 快捷键 Mod+K；
- 项目工作区顶栏中间的搜索框（已有，2026-11-07）；
- 项目中心顶部的搜索框只筛选项目库，不是这个面板。

**布局**：窗口中间的浮层。上面是输入框，中间是分组的结果，底部是操作提示（方向键选择、回车打开、Esc 关闭）。

**显示内容**：

| 范围       | 现在                             | 目标                                                        |
| ---------- | -------------------------------- | ----------------------------------------------------------- |
| 项目       | 名称、研究问题，包括已归档的项目 | 同左                                                        |
| 论文       | 文献文件夹里 PDF 的文件名（11-07 起） | 文献文件夹里的全部论文：标题、作者、文件名；之后加 PDF 全文 |
| 笔记       | 项目笔记和收集箱笔记的标题、正文 | 同左，再加论文笔记                                          |
| 实验和运行 | 不支持                           | 实验名称和目的、运行名称和结论                              |
| 稿件       | 不支持                           | 稿件名称和正文                                              |
| 代码文件   | 不支持                           | 当前实验目录里的文件名（Mod+P 快速打开）                    |
| AI 对话    | 不支持                           | 对话标题                                                    |
| 命令       | 不支持                           | 输入 `>` 进入命令模式，见下文                               |

每条结果显示标题、包含关键词的摘录、所属项目；最多显示 30 条。

**命令模式**（待做）：输入 `>` 后列出可以执行的命令，每条显示快捷键。例如：

- 打开某个一级页面、切换项目、回到项目中心；
- 新建笔记、新建实验、新建稿件、导入论文；
- 运行当前配置、停止运行、新建终端；
- 新建 AI 对话、打开设置、切换主题。

**操作**：

- **回车打开**：进入对象所在的项目，并直接定位到这个对象；
- **范围切换**（待做）：当前项目或全部项目，在项目里默认搜当前项目。

**状态**：

- **还没输入**：显示最近打开的对象和最近用过的命令（待做；现在显示“输入关键词”）；
- **没有结果**：说明搜索范围，并提供“在全部项目里搜索”；
- **结果太多**：提示“只显示前 30 项，请缩小关键词范围”（已有）；
- **对象所属项目已不存在**：标为不可打开（已有）。

**现状**：部分。快捷键和顶栏都能打开；论文按文件名搜（项目里搜当前项目，项目中心搜全部项目）；没有实验、运行、代码、AI 对话和命令。

## 通知中心（待做）

**定位**：集中显示需要知道或需要处理的事情，不打断当前工作。

**入口**：项目工作区顶栏的通知按钮，有未读时显示数量；项目中心首页的“待处理”。

**布局**：从顶栏展开的面板，分“需要处理”和“动态”两组，按时间倒序。

**事件**：

| 事件               | 分组     | 点击后去哪里       |
| ------------------ | -------- | ------------------ |
| AI 任务等待审批    | 需要处理 | 对应对话的审批卡   |
| 运行失败           | 需要处理 | 运行详情的日志     |
| 同步冲突           | 需要处理 | 同步面板           |
| 登录过期           | 需要处理 | 登录页             |
| 数据迁移失败       | 需要处理 | 设置的“数据与备份” |
| 运行结束           | 动态     | 运行详情           |
| 后台的 AI 任务完成 | 动态     | 对应对话           |
| 被邀请加入项目     | 动态     | 团队空间           |
| 订阅有新论文       | 动态     | 新论文收件箱       |
| 有新版本           | 动态     | 设置的“关于”       |

**规则**：

- “需要处理”的事件处理完后自动消失，“动态”可以标为已读或清空；
- 应用不在前台时，运行结束和等待审批另外发系统通知，可以在设置里关闭；
- 通知不弹出模态框；页面底部的短提示只用于当前操作的结果，例如“已保存”。

**现状**：没有通知中心。运行状态在实验页和后台任务里；AI 后台任务在 AI 助手的任务条里；同步冲突在设置里。

## 首次使用引导（待做）

**定位**：第一次打开时，几分钟内走通一次“读文献、记判断、跑实验”。

**入口**：第一次启动时自动出现；帮助菜单“重新查看引导”。

**步骤**：

1. **欢迎**：一句话介绍 Scientify，以及“读文献、记判断、跑实验、写论文”的工作流。
2. **基本偏好**：界面语言、主题；显示数据目录的位置，可以更改。
3. **连接模型**（可以跳过）：选择提供方、填写密钥、测试连接；或者登录使用 Scientify 官方模型。
4. **开始**：打开示例项目、新建项目，或关联已有的文献和代码文件夹。

**示例项目**：两三篇开放获取的论文、一篇带来源的笔记、一个可以直接运行的 Python 实验和它的一次运行记录。不配置模型也能体验阅读、笔记和运行。

**规则**：每一步都可以跳过；不强制登录。

## 划词翻译（已有）

由内置的 Yita 提供，在任何应用里都能用。

**翻译浮窗**：

- 在任意应用里选中文字后出现；也可以在托盘选“翻译剪贴板”，或按 Ctrl+Shift+T；
- 显示原文和译文，可以切换语言、只看原文或译文、解释、纠错、固定、移动和缩放，译文逐字显示；
- 底部输入框可以直接提问，打开 AI 问答浮窗。
- 语言、原文/译文、固定和关闭控件放在正文卡片上方独立的悬浮工具条，保留 Scientify 的字体、主题和控件反馈。工具条与正文属于同一个原生窗口，一起移动。以划词结束时的鼠标位置为锚点；屏幕右侧或底部空间不足时向左/向上避让。
- 拖动后记住窗口相对于锚点的偏移，下一次划词沿用；跨 DPI 使用逻辑像素换算。自动避让不覆盖记忆的位置。

**AI 问答浮窗**：

翻译窗加载时使用紧凑卡片，按选中文本确定宽度，流式输出时保持宽度不变、按实际文字增长高度，超出屏幕可用高度后内部滚动。底部保留发送、打开 AI 对话、跳转 Scientify 同会话入口；显示采用淡入。紧凑布局待本轮验收。

- 保留 Yita 原来的问答界面；
- 箭头按钮把对话转到 Scientify 的 AI 助手：是同一个对话，不会重复发送，也不会覆盖正在写的草稿；
- 第一次提问时绑定当前项目或收集箱，之后不会悄悄改绑；切到别的项目时，提示回到所属项目；
- 关闭浮窗后回答继续，在 Scientify 里查看。
- AI 回复在原生浮窗中渲染 Markdown 标题、强调、列表、引用、代码、表格与链接；复制和记录保留原始内容。上滑阅读历史时，流式回复不强制拉回底部。

**设置**：设置里的“划词翻译”分区和托盘菜单控制同一份配置，开关状态保持一致。浮窗的外观跟随 Scientify 的主题和标志。

**退出**：系统托盘右键菜单提供“退出 Scientify”，走现有未保存内容与后台任务保护；取消后保留应用。

**设计要求**：从浮窗转到项目的文献页或代码页里继续时，对话改用 Agent，才能读到整篇论文（见 [AI 助手](07-AI助手.md)）。

## 快捷键（已有）

Mod 在 Windows 上是 Ctrl，在 macOS 上是 ⌘。下面的按键都可以在设置的“快捷键”分区修改。

| 范围    | 操作         | 默认按键    |
| ------- | ------------ | ----------- |
| 全局    | 全局搜索     | Mod+K       |
| 全局    | 打开 AI 助手 | Mod+Shift+L |
| 全局    | 新建 AI 对话 | Mod+Shift+N |
| 全局    | 打开笔记     | Mod+Shift+O |
| 全局    | 打开文献库   | Mod+Shift+R |
| 全局    | 打开实验     | Mod+Shift+E |
| 全局    | 打开代码     | Mod+Shift+P |
| 编辑器  | 加粗         | Mod+B       |
| 编辑器  | 斜体         | Mod+I       |
| 编辑器  | 保存文件     | Mod+S       |
| 编辑器  | 查找         | Mod+F       |
| AI 助手 | 发送消息     | Mod+Enter   |
| AI 助手 | 中止任务     | Esc         |

划词翻译的“翻译剪贴板”是 Ctrl+Shift+T，在翻译设置里修改。

**建议补充和调整**（待做）：

- Mod+1 到 Mod+5 切换概览、文献、笔记、实验、写作；
- Mod+, 打开设置；Mod+/ 打开快捷键速查；
- Mod+P 在代码页快速打开文件；
- “打开代码”现在是 Mod+Shift+P，和 VS Code 打开命令面板的习惯冲突，建议改用其他按键。

## 托盘与窗口（已有）

- **托盘**：只有一个 Scientify 图标。菜单有打开主窗口、启用或暂停划词、翻译剪贴板、翻译设置、修复取词。
- **单实例**：再次启动时唤起已经打开的窗口，不会开第二个。
- **窗口大小**：项目中心默认 1100×740，最小 800×560；项目工作区最小 1000×680。
- **关闭窗口**：有未保存的内容时先提示保存。
