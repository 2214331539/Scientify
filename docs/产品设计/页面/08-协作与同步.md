# 协作与同步

一个人在多台电脑上、或者几个人围绕同一个研究项目，共享文献、笔记和实验代码。Scientify 保持本地优先：论文阅读、AI、Python 环境和实验运行都在本机完成，服务器只负责账号、成员和同步。

“我的项目”“团队项目”两个页面见[项目中心](01-项目中心.md)；登录页见同一篇的“账号与登录”。

## 基本概念

| 概念       | 说明                                                    |
| ---------- | ------------------------------------------------------- |
| 个人项目   | 只保存在本机，不需要登录                                |
| 云端项目   | 服务器上有一份，同一账号的其他设备和项目成员都能同步    |
| 角色       | 所有者、编辑者、审阅者、查看者                          |
| 冲突副本   | 两台设备同时改了同一内容时，本机那一份另存的副本        |
| 自托管服务 | 团队自己部署的协作服务，在登录页或“设置 → 协作”填写地址 |

## 云端项目的来源（已有）

- **新建团队项目**：团队项目页的“新建团队项目”，用新建项目向导，可以同时邀请成员。
- **个人项目开启多设备同步**：我的项目里的项目菜单“在多台设备上同步”，项目 ID 不变，项目仍在“我的项目”；新建项目向导的第二步也可以勾选。
- **个人项目共享给团队**：项目菜单“共享给团队”，或团队项目页的“共享本机项目”。项目 ID 和本机文件夹不变，项目移到“团队项目”。
- **项目设置“同步与成员”**：待做，见[概览](02-概览.md)。
- **在另一台设备上打开**：登录同一账号后，我的个人同步项目在“我的项目”里以半透明封面显示，团队项目在“团队项目”里标“未下载”，点击下载并打开。第一次同步会取回整个项目，文献放到“文档/Scientify/项目名”。
- **被邀请加入**：所有者邀请你的手机号后，你下次登录时项目自动出现在团队项目里，首页“待处理”提示“你已加入”。通知中心待做。

## 成员面板（L4，部分）

**定位**：查看和管理一个云端项目的成员。

**入口**：团队项目页右侧的项目详情；项目设置“同步与成员”（待做）；通知里的邀请（待做）。

**显示内容**：

- **成员列表**：部分隐藏的手机号、角色、加入时间，标出“我”；
- **待注册的邀请**：部分隐藏的手机号，标为“待注册 · 角色”；
- **设计补充**（待做）：显示名称、最近同步时间。

**操作**：

| 操作                                                                     | 谁能做           | 现状                               |
| ------------------------------------------------------------------------ | ---------------- | ---------------------------------- |
| 邀请成员：手机号加角色；号码还没注册时保留邀请，对方第一次登录后自动加入 | 所有者           | 已有                               |
| 修改角色                                                                 | 所有者           | 已有（界面用重新邀请同一号码实现） |
| 移除成员、撤销邀请                                                       | 所有者           | 已有                               |
| 退出项目                                                                 | 所有者以外的成员 | 已有（本机副本转为个人项目）       |
| 转让所有者                                                               | 所有者           | 待做                               |
| 删除云端项目                                                             | 所有者           | 待做（服务端也还没有）             |

**状态**：

- **非所有者**：只显示列表，管理按钮隐藏，并说明“只有所有者可以管理成员”；
- **离线**：显示上次的列表，管理操作不可用。

## 角色与权限

| 角色   | 能修改的内容     | 管理成员 |
| ------ | ---------------- | -------- |
| 所有者 | 全部             | 可以     |
| 编辑者 | 全部             | 不可以   |
| 审阅者 | 只能改项目笔记   | 不可以   |
| 查看者 | 只接收，不能修改 | 不可以   |

**设计要求**：在项目工作区里按角色隐藏或禁用编辑操作，并在页面上说明原因，例如“你是查看者，修改不会同步”。

**现状**：权限只在服务器上检查。本机界面不按角色限制，查看者在本机改了的内容上传时会被拒绝。

## 同步什么（已有）

| 内容                                           | 是否同步                                                               |
| ---------------------------------------------- | ---------------------------------------------------------------------- |
| 文献 PDF、论文笔记和笔记图片                   | 同步                                                                   |
| 代码目录中的文件                               | 同步；跳过 `.git`、虚拟环境、`node_modules` 等，以及超过 200 MB 的文件 |
| 项目笔记、项目信息、默认实验、运行记录         | 同步                                                                   |
| AI 对话、模型密钥、终端、Python 环境、个人项目 | 不同步                                                                 |

## 什么时候同步（已有）

- **自动**：打开云端项目时、每 30 秒、本机保存后约 3 秒。
- **手动**：“设置 → 协作”里对每个项目“立即同步”。
- **断网**：照常阅读和编辑，恢复连接后自动补上。

## 同步状态的显示

**设计**：同步状态要在用户工作的地方看得到，而不是只在设置里。

| 位置               | 显示                                                                   | 现状 |
| ------------------ | ---------------------------------------------------------------------- | ---- |
| 项目工作区顶栏     | 同步图标：已同步、正在同步、离线、有冲突、同步失败。点开是同步面板     | 待做 |
| 同步面板（L4）     | 上次同步时间、等待上传的数量、最近的冲突、立即同步、打开成员面板       | 待做 |
| 我的项目、团队项目 | 云朵标记；团队项目表格的本机状态（已同步、有冲突、同步失败、未下载）   | 已有 |
| 设置 → 协作        | 登录状态、服务器地址、每个云端项目的上次同步时间、立即同步、最近的冲突 | 已有 |

## 冲突（部分）

**规则**（已有）：

- **两边同时修改**：两份都保留。远端版本沿用原名，本机版本另存为“冲突副本”。
- **一边删一边改**：保留修改的那一份。
- **项目信息和默认实验**：以远端为准。

**冲突处理（设计，待做）**：

- 产生冲突时发通知，同步图标显示“有冲突”；
- 同步面板里列出冲突：名称、两份各自的修改时间和设备；
- 每条冲突可以打开对比视图，并选择保留本机、保留远端或两份都留；
- 处理完的冲突从列表里消失，冲突副本按选择删除或保留。

**现状**：冲突副本会生成，最近的冲突列在“设置 → 协作”里。还没有对比视图和处理操作。

## 历史版本（待做）

服务器为每个文件和记录保留最近 20 个版本。设计上在笔记编辑页、代码编辑器和论文笔记的更多菜单里提供“历史版本”：列出版本的时间和修改人，可以预览、对比当前版本、恢复。

## 状态

| 情况                | 显示                                                   |
| ------------------- | ------------------------------------------------------ |
| 未登录              | 云端项目不同步；团队空间显示登录入口；本机项目照常使用 |
| 登录过期            | 提示重新登录，本机修改保留，登录后补上                 |
| 离线                | 同步图标显示离线；修改先存本机                         |
| 服务不可用          | 说明原因并提供重试，不影响本机使用                     |
| 单个文件超过 200 MB | 这个文件不同步，并在同步面板里列出                     |
| 没有权限修改        | 说明自己的角色和能改的范围                             |

## 现状与差距

已有：手机号登录、自托管地址、云端项目、个人项目多设备同步、共享给团队、同一账号多设备同步、邀请成员、改角色、移除成员、撤销邀请、退出项目、按角色在服务器上检查、冲突副本，以及项目中心里每个云端项目的同步状态。

差距：

- **成员管理**：转让所有者、删除云端项目（服务端还没有接口）；
- **同步状态**：项目中心已经能看到，项目工作区的顶栏还没有；
- **冲突**：没有对比视图和处理操作，也没有历史版本浏览；
- **按角色限制编辑**：本机界面不限制；
- **实验数据**：非默认实验（外部目录）的跨设备对应，运行日志和产物的选择性同步；
- **Git 远程**：推送、拉取和分支；
- **大文件**：分片上传，现在单个文件上限 200 MB；
- **团队**：一个账号只能属于一个团队。
