# Scientify 桌面使用说明

写给使用者：怎样安装、日常怎样操作、数据放在哪里、现在有哪些限制。每个页面的完整设计见[产品设计](../产品设计/README.md)；从源码构建和开发流程见[项目说明](../../README.md)与[开发与验收流程](../开发流程/开发与验收流程.md)。

## 安装与启动

- **下载**：从 [GitHub Releases](https://github.com/2214331539/Scientify/releases) 下载预发布版。Windows x64 使用 NSIS 安装器；macOS 14 以上的 Apple Silicon 电脑使用 DMG，拖进“应用程序”后打开。不提供 Intel 版本。
- **Mac 首次打开**：预览版没有经过 Apple 公证。确认来源后，在“系统设置 → 隐私与安全性”里选择“仍要打开”。
- **从源码运行（Windows）**：双击仓库里的 `Scientify-MVP.cmd`，它会选择最新编译的正式版。如果旧窗口还开着，先关掉，否则只会唤起旧窗口。
- **两个窗口**：启动时是项目中心（1100×740）；打开项目后是最大化的项目工作区。点工作区左上角的品牌按钮回到项目中心，有未保存的内容会先提示。关闭项目中心即退出应用。Mac 上在工作区按 Cmd+Q，会先经过保存保护并回到项目中心。

## 界面一览

- **项目中心**：
  - 左侧导航：搜索（Ctrl K / ⌘K）、首页、我的项目、团队项目、收集箱，下面是收藏的项目；
  - 首页：最近项目、最近编辑的笔记和运行、需要处理的事（新加入的团队项目、同步冲突、失败的运行）；
  - 我的项目：个人项目的书架或列表，可以搜索、筛选（收藏、多设备同步、已归档）、排序、新建、编辑、收藏、归档、删除，也可以开启多设备同步或共享给团队；
  - 团队项目：和别人共享的项目、成员和本机同步状态；
  - 收集箱：不属于任何项目的随手笔记和快速问答；
  - 左下角：账号按钮（未登录时是“登录”）、帮助、设置；浅色和深色在账号菜单或设置的“外观”里切换。
- **项目工作区**：
  - 顶栏：返回项目中心、切换项目、亮暗切换；
  - 左侧五个入口：概览、文献、笔记、实验、写作。概览和写作现在是“开发中”的占位页；
  - 右下角：AI 助手和笔记两个图标，打开右侧栏；
  - 全局搜索：Ctrl+K（Mac 上 Cmd+K）。
- **设置**：通用（语言、显示名称）、外观（主题）、快捷键、翻译、协作、数据与备份、关于。偏好立即生效，两个窗口同步，不会翻译研究内容，也不会清空草稿。
- **快捷键**：默认按键和修改方法见[全局功能](../产品设计/页面/10-全局功能.md)。

## 文献

- **关联文件夹**：打开“文献”，点文件夹图标选择项目的文献文件夹。PDF 和笔记留在原位置，文件夹变化会自动更新。
- **整理**：
  - 点搜索或按 Ctrl+F 筛选，Esc 清除；
  - Ctrl/Cmd 点击多选，Shift 点击连选，Ctrl/Cmd+A 全选；可以批量拖动，或 Ctrl+C、X、V；按住 Ctrl/Cmd 拖动是复制；
  - 移动 PDF 时笔记跟着走；重名时报错，不会覆盖；
  - 右键可以重命名、移动、移入回收站、重新关联。
- **导入**：从文件管理器拖入文件。拖到文件夹上复制到那个文件夹，拖到空白处复制到根目录，同名自动编号。单个文件最大 150 MB；暂不支持直接拖入整个文件夹。
- **阅读**：
  - 打开 PDF 时，右侧同时打开这篇论文的笔记；
  - 底部可以切换分页和连续滚动，输入页码跳转；
  - PDF 里的目录和引用链接在文中跳转，网址用系统浏览器打开。
- **论文笔记**：第一次输入内容时才创建 `同名.notes.md`，自动保存，也可以按 Ctrl+S。选中文字可以摘录，摘录带页码链接。外部程序改过笔记时会保留你的草稿，可以重新读取或另存一份。
- **网页**：中央标签栏的“+”打开网页标签，默认是 Google。支持网址和搜索、前进后退、刷新、用系统浏览器打开，下载默认存进当前文献文件夹，最多 16 个网页标签。
- **订阅**：文献侧栏顶部切到“订阅”，管理常用网站（个人信息源），点击在网页标签里打开。“推荐”还在开发中。

## 笔记

- **项目笔记**：在“笔记”页，或右下角的笔记图标里写，两处是同一份。停止输入后自动保存，保存失败会保留草稿并可以重试。
- **来源**：笔记可以挂上论文页码、文件或运行，点击跳回原处。
- **收集箱**：在项目中心打开笔记时，记到个人收集箱，不属于任何项目。

## 实验

- **实验列表**：每个项目自动有一个“默认实验”。可以新建空文件夹、关联已有文件夹或 Worktree 作为实验；可以重命名、归档、移除登记（移除不删除磁盘文件、Git、对话和运行记录）。
- **代码**：文件树、搜索、编辑器、终端（PowerShell、cmd、Python 交互环境，可以分屏）、日志、产物。编辑器里的播放按钮保存并在终端运行当前 Python 文件。
- **运行**：
  - 选择运行配置后点“运行”，不需要配置模型；
  - 第一次在外部文件夹运行前要先信任它，有未保存的代码要先保存；
  - 脚本把结果写进环境变量 `SCIENTIFY_RUN_DIR` 指向的目录，就会显示为这次运行的产物；
  - 手动运行和终端使用你信任后的本机权限；AI 启动的运行在沙箱里执行。
- **Python 环境**：检测或选择解释器，新建 venv 或 Conda 环境，安装、升级、卸载依赖。
- **运行记录**：按状态和来源筛选；选 2–4 条比较，缺失的指标留空，不显示 0；可以新建手动记录，或按原配置“再次运行”。
- **版本（Git）**：暂存、提交、最近 100 条历史、本地分支、Stash、Worktree。还不支持克隆、拉取、推送、合并和冲突解决。
- **上限**：同时最多 8 个运行，日志显示最后 256 KB，单次日志超过 64 MB 时停止运行；终端最多 32 个；应用意外退出后，运行中的记录标为“中断”，不会自动重跑。

## AI 助手

### 配置模型

打开右下角的 AI 助手图标，点底部的模型胶囊，选“配置其他模型”。

1. 选择服务：OpenAI、Anthropic、Gemini、DeepSeek、通义千问、Moonshot、硅基流动、OpenRouter、Ollama 或自定义服务。预设会自动填好地址；自定义服务要填完整的接口地址并选择协议。
2. 填写 API 密钥（Ollama 可以不填），点“测试连接”获取模型列表。
3. 选择模型后保存。保存前会发一条简短的测试消息，不带任何研究材料。

密钥保存在本机数据目录，目前没有加密，不会随项目同步。也可以登录后使用 Scientify 官方模型。

### AI 能做什么

- **在项目的文献页或代码页**，并且模型连接使用 OpenAI 协议或 Ollama 时，AI 以 Agent 方式工作：
  - 列出和按页读取项目里的论文（每次 8 页，可以接着读，单个 PDF 最大 50 MB），在论文里搜索；
  - 读写笔记；在实验目录里执行命令、启动运行、使用 Git；
  - 用内置浏览器搜索和读取网页。后台浏览不会切走你正在读的 PDF。
- **其他情况**只能快速问答，只看得到发给它的材料：当前页面、选中的文字和附件。
- **已知问题**：从划词翻译浮窗转过来的对话会一直停留在快速问答，问整篇论文时只看得到当前页。需要读全文时，请在文献页里新建一个对话。修复方案见 [AI 助手](../产品设计/页面/07-AI助手.md)。
- 旧对话保留原来的工具。提示缺少新工具时，新建对话即可。

### 材料与附件

- **当前材料**：对话菜单“查看当前材料”可以查看并关闭自动附带的材料；每条消息下的“本轮材料来源”列出实际发送的内容。
- **附件**：把图片、PDF、Markdown、Python 或文本文件拖进输入框，或直接粘贴。每条消息最多 4 个；图片不超过 8 MB；PDF 不超过 20 MB，只取前 20 页、最多 12000 个字；文本不超过 2 MB。扫描版 PDF 没有文字，暂不支持 OCR。

### 权限

输入框左下角模型胶囊右侧的权限按钮：

- **询问**（默认）：在沙箱里运行，工作区内的读写不用逐次批准；越权操作和 Git 写操作会在对话里弹出审批卡。
- **完全允许**：不使用沙箱，可以访问工作区外的文件和网络，不再显示审批卡。

权限按对话保存，新对话不会继承。任务进行中不能切换。

### 快捷命令

在输入框行首输入 `/`：

| 命令          | 作用               |
| ------------- | ------------------ |
| `/permission` | 打开权限菜单       |
| `/skills`     | 选择技能，可以搜索 |
| `/model`      | 选择模型或配置连接 |
| `/new`        | 新建对话           |
| `/context`    | 查看当前材料       |
| `/stop`       | 停止当前任务       |

**技能**：项目技能放在 `<工作区>/.agents/skills/<技能名>/SKILL.md`。每条消息最多选 4 个技能，只能在 Agent 方式下使用。

### 其他

- 回答过程中可以继续输入“补充指令”；停止按钮只停止当前任务。**停止对话不会停止它启动的实验**，实验要在运行卡片上单独停止。
- 每个对话的未发送草稿分别保留，但重启应用后不保证恢复。
- 拖动 AI 面板的左边界调整宽度，双击复位；窗口窄于 900 时面板浮在内容上方。

## 划词翻译

- 在任何软件里选中文字，出现翻译浮窗；也可以在托盘菜单选“翻译剪贴板”，或按 Ctrl+Shift+T。
- 浮窗可以切换语言、解释、纠错、固定、移动和缩放；底部输入框可以直接追问。
- 问答浮窗的箭头按钮把对话转到 Scientify 的 AI 助手，是同一个对话，不会重复发送。
- 在“设置 → 翻译”或托盘菜单里启用或暂停划词。

## 协作

- **登录**：左下角“登录”，用手机号和短信验证码登录。团队自己部署的服务，在登录页的“使用自托管协作服务”里填写地址。
- **多设备同步**：在“我的项目”的项目菜单里选“在多台设备上同步”。另一台电脑登录同一账号后，这个项目出现在“我的项目”里，点击下载。
- **团队项目**：在“团队项目”里新建，或把我的项目“共享给团队”。所有者在右侧详情里邀请成员、改角色、移除成员；成员可以退出项目，本机副本保留为个人项目。
- **同步的内容**：文献 PDF、论文笔记、项目笔记、代码文件（跳过 `.git`、虚拟环境和超过 200 MB 的文件）、运行记录。AI 对话、模型密钥、终端和 Python 环境不同步。
- **同步时机**：打开项目时、每 30 秒、保存后约 3 秒；也可以在“设置 → 协作”里立即同步。断网时照常使用，联网后自动补上。
- **冲突**：两台设备同时改了同一内容时两份都保留，本机那份另存为“冲突副本”。
- **成员**：所有者可以按手机号邀请编辑者、审阅者或查看者。

详见[协作与同步](../产品设计/页面/08-协作与同步.md)。

## 数据与文件

**应用数据目录**：

- **Windows 正式版**：安装目录旁的 `ScientifyData/`，记录在其中的 `workspace/` 子目录。安装位置必须可写，应用不会悄悄改存到 C 盘。
- **Mac 正式版**：`~/Library/Application Support/Scientify/ScientifyData/workspace/`。
- **位置清单**：`scientify-storage.json` 记录当前和待迁移的位置。Windows 上放在安装目录旁；Mac 上放在 `~/Library/Application Support/Scientify/`。
- **开发版**：使用单独的 `ScientifyDevData/`，不会碰正式数据，见[开发与验收流程](../开发流程/开发与验收流程.md)。

**文件放在哪里**：

- 文献 PDF 和论文笔记留在你关联的文献文件夹里；Scientify 在文献文件夹的 `.scientify/library.json` 里记录论文的稳定标识；
- 没有关联文件夹的实验代码放在数据目录的 `projects/` 下；关联了文件夹的直接编辑那个文件夹；
- 覆盖项目文件前，最近一次的磁盘版本会保留在数据目录的 `recovery/files/`。

**备份**：

- **JSON 导出不包含 PDF 和源码**，只有记录和附件索引；
- 完整备份需要在应用关闭后，复制整个数据目录以及每一个关联的文件夹；
- 导入 JSON 前会自动备份当前记录；“恢复最近备份”会另存当前的主文件。文件不会随着记录恢复而回滚。

**更改数据位置**：“设置 → 数据与备份 → 更改位置”，选择一个空文件夹。退出应用后，下次启动时迁移：先复制、逐个文件校验，再切换位置并清理旧目录。迁移前可以取消。凭据、托管代码、运行结果、AI 历史和浏览器资料都会一起迁移；关联的外部文件夹不移动。

**旧版本数据**：

- Windows 正式版第一次启动时，会自动迁入旧的 `%APPDATA%/com.scientify.desktop/workspace/`；目标位置已有数据时停止，不自动合并；
- Mac 上旧的 `com.scientify.desktop/` 数据也会在第一次启动时迁入；
- Electron 旧版：先关闭旧应用，在“设置 → 数据与备份”选“复制旧数据”，只能迁入空的数据目录，旧数据不变。

**Mac 的网页资料**由系统 WebKit 管理，更改数据位置不会把网站登录状态带到新位置或另一台 Mac。

## 当前限制

- **页面**：概览、写作和订阅推荐还是占位页。
- **文献**：没有 OCR、PDF 高亮和批注，没有全文检索；全局搜索只覆盖项目、旧版文献记录和笔记。
- **实验**：没有断点调试、测试发现、Notebook 和远程运行；Git 没有远程操作和冲突解决界面。
- **协作**：没有冲突对比和历史版本界面；单个文件最大 200 MB；外部目录的实验不跨设备对应。
- **草稿**：未保存的代码草稿只在应用运行期间保留，意外退出可能丢失；笔记有自动保存。
- **文件操作中断**：无法自动回退时会保留 `.scientify/operation.json` 并停止写入，需要人工核对。
- **大小**：文本文件最大 2 MB，文献 PDF 最大 150 MB；一个文献文件夹最多 10000 项、32 层。
- **发行**：Windows 安装包没有签名，Mac 是预览版；没有自动更新。平台差异见[跨平台适配路线](../技术方案/跨平台适配路线.md)。
