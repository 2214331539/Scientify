# 前端工作区重构：第一阶段

更新日期：2026-09-24

本文件确定本轮前端实现边界。与旧文档中的“四个一级入口”“固定三栏”或首页功能卡片规则冲突时，以本文件为准；现有数据与业务能力继续沿用。

## 1. 产品结构

Scientify 以项目为工作上下文，界面围绕正在阅读、编辑和记录的材料组织。

```text
Top Bar       Scientify · Project ▾       Search     AI     Research Notes
─────────────────────────────────────────────────────────────────────────
Left Rail    │ Main Workspace                          │ Optional Panel
             │                                         │
Overview     │ Workspace · Views                       │ AI / Notes
Literature   │ ┌──────────────┬──────────────────────┐ │
Notes        │ │ Resources    │ Document tabs        │ │
Experiments  │ │              │ Editor / Reader      │ │
Paper        │ │              │                      │ │
Files        │ └──────────────┴──────────────────────┘ │
             │                                         │
Settings     │                                         │
─────────────────────────────────────────────────────────────────────────
Status Bar
```

- **Top Bar**：品牌、当前项目切换、全局搜索、AI、Research Notes。
- **Left Rail**：固定工作区入口；底部提供个人偏好、数据与备份、关于。
- **Main Workspace**：承载材料和编辑任务。资源列表属于当前工作区，可收起、调宽，不是额外一级导航。
- **Optional Panel**：按需显示 AI 或快速笔记；AI 不占据默认布局。
- **Projects**：项目外的管理视图，使用搜索、筛选和项目表格，不展示功能入口卡片。

项目切换器支持筛选、打开已有项目、新建项目、返回项目列表及当前项目设置。切换项目后恢复该项目的工作位置。

## 2. 导航与页面职责

| 一级入口 | 二级视图 | 中央内容 |
| --- | --- | --- |
| Overview | 无 | 项目信息、继续工作、最近活动、下一步 |
| Literature | Library / Subscriptions | 文献列表、阅读器、订阅条目 |
| Notes | 无 | 当前项目笔记列表与编辑器 |
| Experiments | Code / Runs / Changes | 代码编辑、实验记录、Git 变更 |
| Paper | Manuscript / References | 论文文件编辑与预览、参考文献 |
| Files | All files | 项目文件树与文件编辑器 |

导航配置集中在 `src/components/navigation/workspaces.ts`。用户可见名称为 Paper，内部工作区标识继续使用 `writing`，避免为界面命名重写已有业务。

Files 复用项目文件能力；它不建立另一份文件存储。文件标签与编辑缓冲区继续由现有编辑器运行时管理。

## 3. 项目首页

首页回答两个问题：上次做到哪里、下一步做什么。

- **Project**：项目名称、研究问题、研究方向及已填写的阶段。
- **Continue working**：已打开的论文或代码路径、当前项目的真实文献、笔记与实验记录；点击后定位到对应资源。
- **Recent activity**：依据文献、笔记、实验记录的创建和更新时间生成最近条目。
- **Next steps**：复用项目待办，支持新增与完成。

没有数据时显示简短空状态与必要操作，不填充示例任务、统计数字或虚构运行状态。实验“进行中”等状态来自手动记录，不能表示系统正在执行实验。当前 Recent activity 是资源状态摘要，不是完整事件日志；文件修改历史不在本阶段伪造。

## 4. AI 与笔记

### AI

- 启动时关闭 AI 面板，通过顶栏图标打开。
- 面板按顺序显示 Current Context、Current files、Conversation、输入区。
- 当前材料来自工作区发布的 `WorkContext`：项目、模块、资源、路径、正文或选区、PDF 页码。
- Current files 只呈现当前明确提供的资源，不假定已读取整个项目。
- 输入提示为 `Ask about this project...`；模型设置保留在输入区附近。
- 是否附带材料由用户控制，发送仍需明确操作。

### Notes

- Left Rail 的 Notes 用于集中整理；Top Bar 的 Research Notes 用于边读、边写、边记录。
- 每个项目保留一个笔记编辑实例。中央笔记与右侧笔记改变的是呈现位置，不创建两份草稿。
- 在 Notes 工作区中，笔记占据中央，仍可另外打开右侧 AI。
- 切换模块或收起面板保留当前编辑状态；保存继续复用现有自动保存与未保存保护。
- 来源快照与回到来源的能力继续保留。

## 5. 组件与状态归属

| 目录 / 文件 | 职责 |
| --- | --- |
| `src/components/layout/` | `AppShell` 管布局槽位与尺寸；`Sidebar` / `Panel` 管区域；`TopBar` 管项目切换与全局操作 |
| `src/components/primitives/` | `Button` / `Input` / `Textarea` / `Dropdown` / `Tooltip` / `Badge`，页面统一复用 |
| `src/components/navigation/` | 一级 Rail、入口配置、二级视图定义 |
| `src/components/workspace/` | `WorkspaceFrame` 管二级视图与资源区；`Section` / `ResourceList` / `ActivityList` / `TreeView` 组织内容 |
| `src/components/ai/` | `ContextPanel`、`AssistantComposer`；辅助操作只准备输入，由用户确认发送 |
| `src/app/App.tsx` | 组合工作区、导航状态、项目位置恢复、上下文路由与全局对话框 |
| `src/shell/GlobalDock.tsx` | 保持项目级 AI / Notes 会话，控制笔记中央与侧边呈现 |
| `src/workspaces/` | 各工作区现有内容与操作；Overview 的展示数据由 `home-model.ts` 派生 |
| `src/features/` | 笔记、AI 会话、项目、文献等已有交互与业务逻辑 |
| `src/editor/`、`src/stores/`、`src/platform/` | 编辑缓冲区、持久化状态、原生与浏览器后端能力 |

布局组件通过属性接收内容与回调，不直接读写业务文件。新增工作区先定义导航与上下文，再组合现有功能组件；不要在 Rail 或 Top Bar 中堆积领域逻辑。

UI 会话使用 `scientify.ui.v2`，兼容读取旧版布局记录，按项目保留工作区、二级视图、已选文献及文件路径。AI 启动关闭规则优先于旧版的展开记录。业务数据沿用原存储，不因布局变化迁移。

## 6. 视觉约束

- 白色与灰阶承载层级；图标统一单色，语义状态使用克制的强调色。
- 小尺寸标题、细分隔线、小圆角、紧凑工具栏和列表；阴影仅服务浮层。
- 删除营销文字、解释型副标题、彩色图标块和功能入口卡片。
- 保留真实资源摘要、保存状态、运行记录状态、错误及必要约束。
- 选中、悬停、键盘焦点与禁用状态保持清晰。
- 复用现有设计令牌、组件和样式工具，不引入新 UI 框架。

## 7. 开发边界

**第一阶段：本轮实现。** 重构 Shell、导航、首页和辅助面板呈现；将现有功能接入新容器，保留既有后端、数据模型、编辑缓冲区与未保存保护。现有项目、文献、笔记、代码、实验记录、论文编辑能力持续可用。

**第二阶段：后续迁移。** 在新结构内逐模块迁移现有页面和交互到统一组件层，逐步收敛旧页面样式。跨资源恢复、真实活动历史、实验执行、原生 TeX 编译等能力按后续需求单独确定范围；新增能力必须有对应数据来源与生命周期，不能先以占位交互冒充已实现功能。

本文件描述实现结构与范围，不作为测试、构建或发布结果记录。

2026-09-24 组件体系更新：页面控件已迁入共享 primitive，首页、笔记、实验与搜索采用共享分区或列表，文件树统一为 TreeView；业务能力沿用。后续组件开发遵循 [Workspace UI](../../src/components/README.md)，不再为每个页面定义独立控件皮肤或功能卡片。
