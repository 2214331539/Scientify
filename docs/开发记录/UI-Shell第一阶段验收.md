# UI Shell 第一阶段验收

日期：2026-09-24

## 交付范围

- 顶栏项目选择、全局搜索、AI 与研究笔记；六入口 Left Rail；工作区内可折叠资源栏。
- Overview 展示真实的继续工作位置、材料更新与待办；项目管理、文献和订阅改为紧凑列表。
- AI 启动关闭，按需展示当前项目、当前材料和对话。
- Notes 支持中央与侧栏编辑，同一项目复用同一个编辑实例。
- Files 复用现有文件和编辑会话；UI 会话升级到 v2，兼容旧记录。
- 白灰层次、单色导航、小圆角与细分隔线；现有业务、技术栈与数据格式沿用。

结构及后续迁移边界见 [前端工作区重构：第一阶段](../架构设计/前端工作区重构-第一阶段.md)。

集成测试覆盖：旧版会话中的 AI 展开记录不会自动打开新面板；AI 材料按项目隔离；笔记保存失败的草稿在中央、侧栏和项目切换后保留；Files 不提前读取全部文件；文件跳转后正确恢复二级视图；首页继续阅读优先选择已选文献。

本轮浏览器验收使用独立预览数据。桌面 release 已构建，未替换或关闭用户正在运行的旧进程，也未在该进程内执行原生端到端复测。本轮没有更改 Rust 业务逻辑。

## 启动新版

关闭现有 Scientify 窗口，然后双击 `F:\Project\Scientify\Scientify\Scientify-MVP.cmd`。

本轮可执行文件：`F:\Project\Scientify\Scientify\target\ui-shell\release\scientify.exe`。

新旧 release 使用相同应用标识和 `%APPDATA%/com.scientify.desktop/workspace/` 数据目录，无需迁移。启动脚本优先选择上述独立构建。若旧窗口仍在运行，单实例机制会唤起旧窗口。
