# 全局主题与语言

## 使用

Projects 和 Workspace 顶栏提供亮暗按钮及「中 / EN」按钮，点击直接切换，无需展开设置菜单。顶部搜索框已移除；个人偏好中仍提供主题及语言完整选项（包括跟随系统）。

- 主题：浅色、深色、跟随系统。
- 语言：简体中文、English。
- 即时生效、自动记忆，窗口间同步。默认中文和跟随系统。
- 既有用户首次升级沿用原主题。切换不提交工作区 revision，不触发研究数据覆盖，也不清空编辑草稿。

## 实现

沿用已有设计变量和明暗 Logo。界面文案统一从 `src/i18n/messages.json` 读取，覆盖项目管理、六个工作区、导航、按钮、设置、弹窗、加载状态、错误提示及可访问标签。插值用于数量、路径和页码；日期跟随语言。

偏好单独保存在应用 WebView 的 `scientify.preferences.v1`，使用 storage 事件和 `ui-preferences-changed` Tauri 事件通知。后者做值校验，并携带窗口实例来源标识以忽略自身的延迟回声；不将收到的事件再次广播。同步不修改科研数据库，也不重新加载隐藏管理窗口的数据快照。

用户生成的名称、正文、文件内容、模型回答不自动翻译；业务状态使用原有稳定值，显示标签中英切换。CodeMirror 仅更新可访问名称，不重建编辑实例。

## 边界

- 原生 Windows 文件对话框的系统按钮遵循操作系统语言；应用提供的过滤器采用 PDF / Scientify JSON 中性名称。
- PDF 纸张和研究正文不做自动反色或翻译。
- 未知外部服务诊断原样显示；应用自身的已知错误提供中英翻译。
- 外观与语言属于设备偏好，不包含在工作区 JSON 导出中。
- 原生窗口同步由事件测试覆盖；本次未关闭用户正在使用的旧版执行桌面人工切换。
