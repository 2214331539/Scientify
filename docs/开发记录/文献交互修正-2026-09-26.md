# 文献交互修正 · 2026-09-26

范围：目录工具栏搜索、外部文件拖入、PDF 阅读模式及默认网页搜索。承接 [文献模块 v0.4](文献模块v0.4-Tauri交付.md)，保留当前 Tauri / React 技术栈。

## 最终交互

- 目录工具栏在文献库/订阅导航下方，目录树独立滚动。点击搜索或 Ctrl+F 后，工具栏原位置整行只显示输入框，文件夹路径和其他按钮隐藏。Enter 或点击外部恢复正常工具栏并保留筛选；Esc 清空筛选并退出。工具栏固定 36px，不在下方增加搜索行。
- 可将系统文件管理器中的单个或多个文件复制到文献目录。落在文件夹行上导入该子目录，落在空白区域导入根目录；同名自动编号，保留原文件，不替换既有文件或笔记。目录内部原有移动、Ctrl 拖动复制继续使用。
- 底部阅读工具提供“分页阅览 / 连续滚动”切换。连续模式可用滚轮跨页阅读，页码随阅读位置变化；前后页按钮、页码输入与笔记页码链接同时可用。切换保留当前页和页内位置，记忆阅读模式。只为当前页和视口附近页面创建 canvas/text layer，远处保留尺寸占位。
- 默认关键词搜索改为 `https://www.google.com/search?q=...`，包含 `site:` 等检索表达式；直接输入网址仍访问该网址，新标签默认打开 `https://www.google.com`。已打开的旧搜索页面不会自动改写。浏览器运行时是 Windows WebView2，基于 Chromium；搜索引擎与渲染内核是两层不同能力。

## 实现边界

目录搜索和拖放由 LocalLiterature 管理，TreeView 仅增加拖放目标标识。外部拖入通过浏览器 File API 读取用户拖入的内容，以 Tauri 二进制 IPC 传给 `library_import_bytes`；不授予前端任意源路径读取权限。中文文件名经 ASCII JSON header 传递，后端验证项目、文件名、目标目录、PDF 内容及大小，原子写入并更新稳定绑定。

PDF 页面绘制抽为 PdfPageSurface，PdfReader 继续拥有文档、页码、缩放、阅读模式与来源上下文。连续模式使用单个 IntersectionObserver 管理邻近页面，渲染取消与 text layer 清理沿用 PDF.js 生命周期。

每个拖入文件上限 150 MiB，暂不支持拖入整个文件夹。批量导入逐个处理，发生错误时保留已成功导入的文件并显示完成数量。推荐/订阅能力仍未启用。
