## 使用路径

1. Projects 打开项目，进入「文献」。文件夹按钮选择真实目录；目录与项目独立关联。
2. 从树打开 PDF，中央 PDF 标签组与右侧论文笔记标签组独立操作。笔记在首次输入后写为相邻 `同名.notes.md`，900ms 自动保存，支持 Ctrl+S、Markdown 预览、摘录选文及页码返回。
3. 目录支持搜索、Ctrl+F、新建文件夹、右键菜单、复制/剪切/粘贴和拖放。PDF 与主笔记成对重命名、移动、复制或回收；副本拥有新的 paperId。
4. 中央「+」创建空白网页。支持网址/关键词、前进/后退、刷新/停止、新窗口链接转标签、系统浏览器打开和原生下载保存；默认下载目录是该项目文献库。
5. 订阅只提供浏览器入口；推荐与个人信息源显示“尚未启用”。旧资料入口保留元数据 UI；菜单“迁移旧文献”显式复制 PDF 并导出笔记，原记录和原附件保留。

## 文件协议与恢复

- 应用数据目录下 `literature-roots.json` 保存 projectId → 绝对根目录。
- 文献目录下 `.scientify/library.json` 保存版本 1 索引，包含稳定 paperId、相对 PDF 路径、笔记路径与 SHA-256 指纹。
- 递归扫描拒绝越界、保留名、符号链接/junction，忽略 `.scientify`、`.git`、原子写入临时目录。目录最多 10,000 项 / 32 层；PDF 最大 150 MiB；UTF-8 笔记最大 2 MiB。
- 同一服务内磁盘事务串行执行。操作前写 `.scientify/operation.json`，目标存在时拒绝覆盖；Windows 移动使用不替换目标的 MoveFileExW。操作失败尝试回退，回退未完成时保留清单并拒绝后续写入。
- 回收先建立配对恢复包及 `restore.json` 再交给系统回收站。系统恢复得到的是恢复包，需按清单放回原路径，不宣称能自动还原项目索引。
- 外部 PDF 重命名仅在指纹一一对应时自动重关联；多份相同 PDF 或目标笔记冲突需人工重新关联。外部删除 PDF 保留原笔记。
- 外部笔记修改通过内容 revision 检测；冲突保留内存草稿，支持重读或另存副本。JSON 导出不含新目录内容；备份需包含整个文献目录及 `.scientify`。
- 进程崩溃后的事务恢复尚无自动 UI。发现 operation.json 时先备份目录、核对原/目标文件与清单，再恢复；不要直接删除清单继续写入。

## 原生浏览器与窗口约束

网页使用真实 Tauri/WebView2 child webview，无 iframe。Capabilities 仅授予 `main`、`workspace` webview；不能按 window 通配授权。远程标签以 `remote-UUID` 命名，无本地文件、模型、shell 等应用权限；导航与子请求拒绝内部协议/应用地址，权限请求默认拒绝。

网页使用独立持久化 browser-profile，登录 cookie 留在该 profile；当前不提供账号同步或资料清理 UI。网页正文、相邻论文笔记及登录态不作为 AI 上下文。原生保存对话框决定下载目的地，不自动执行下载文件。第三方站点登录兼容性仍取决于站点/WebView2。

前端负责呈现区域和遮挡状态，Rust 限制原生视图的窗口边界。几何换算使用 DOM viewport 与窗口逻辑尺寸，兼容 WebView 缩放；设置/菜单出现或离开文献时隐藏网页，工作区销毁时关闭其网页视图。停止/下载导致的正常导航取消不再作为网页失败。

Projects 和 Workspace 各有持久化 UI profile，共享同一 Rust 数据服务。窗口先显示加载状态，数据就绪后隐藏 Projects；30 秒未就绪回退。主题/语言通过启动参数及事件同步。升级时旧 UI profile 中的工作区布局、标签、阅读位置可能需要重新打开；原 JSON、PDF、源码和笔记不改变。

## 本轮边界

- 本地目录与原生浏览器只在 Tauri 桌面版启用，HTTP 预览继续使用旧文献界面。
- 全局搜索、首页最近活动和旧引用选择仍基于 workspace JSON；新目录提供模块内搜索，不伪造全局统计。
- 目录操作期间遇到未保存笔记会要求先完成保存；未保存草稿仅在当前进程保留。
- 笔记使用轻量文本编辑器与 Markdown 预览；无 PDF 批注、OCR、实时翻译或自动推荐。
- 未逐一验收第三方论文站点、SSO、验证码、代理、超大下载、多显示器 DPI 切换与所有下载取消路径；网页新窗口链接转标签的 GUI 验收未完成。没有使用真实账号登录。
- 本轮发布本地可执行构建，不签名、不上传、不配置自动更新。
