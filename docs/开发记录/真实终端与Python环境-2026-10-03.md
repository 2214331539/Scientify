## 权限与存储

外部实验目录首次执行前确认信任，信任保存于本机 workspace/execution-trust.json，独立于导入的工作区 JSON。应用创建的 projects 直接子目录默认可信。可信终端、Python 准备和手动运行按本机用户权限执行，可访问网络与本机文件；这是 IDE 的可信执行，不是 OS 沙箱。AI 继续使用 Codex 沙箱和内联审批，AI 正式运行的网络仍关闭。

Python 绑定存在实验的 python 字段；正式运行和终端保存环境快照。环境任务记录及日志在 workspace/environment-tasks/<id>/；缓存和临时目录在数据容器的 cache/pip、cache/conda、cache/uv 和 tmp。创建的 venv/Conda prefix 默认在实验根；用户已有解释器不搬迁。Windows 本地命令隐藏启动，并使用 Job Object 管理进程树。

终端最多保留 32 个，输出为 2 MiB 环形缓冲；授权读取返回原始字节的 base64 和游标，单次最多 256 KiB。环境任务最多同时 8 个，日志超过 64 MiB 停止，界面读取尾部 2 MiB。正式运行继续使用既有 8 个并发限制及独立产物目录。

## 手动验收

使用可丢弃项目及目录，不使用真实研究资料作夹具。本机需有 Python；Conda/Git 按对应场景安装。无需配置任何模型。

1. 打开研究项目，进入实验管理，新建 A 和 B 两个空目录实验。检查卡片/列表切换、卡片详情、搜索和长名称显示；切换布局后实验数及历史不变化。
2. 打开 A，点击左侧环境图标或底部 Python 入口。检测基础 Python，使用 venv 创建 .venv；在任务页检查真实输出，成功后点击“使用此环境”。B 重复操作，确认 prefix 不同。已存在 .venv 再创建应拒绝覆盖。
3. A 的依赖页安装一个测试包，例如 rich；刷新包列表。B 独立环境中不应出现该包。再通过 requirements.txt 安装依赖，确认任务记录、退出码和失败日志；系统解释器安装应有确认。
4. A 新建 train.py，填写以下代码，保存后点击编辑器的播放按钮。底部出现真实 Python 终端，逐步输出，结束后可回看；切到 B、文献或 AI 面板后 A 的执行身份不改变。

```python
import argparse
import json
import os
from pathlib import Path
import sys
import time

parser = argparse.ArgumentParser()
parser.add_argument("--steps", type=int, default=12)
args = parser.parse_args()
print("Python:", sys.executable, flush=True)
score = 0
for step in range(args.steps):
    score += sum(n * n for n in range(1000))
    print(f"step {step + 1}/{args.steps}: {score}", flush=True)
    time.sleep(0.2)
output = Path(os.environ.get("SCIENTIFY_RUN_DIR", "results"))
output.mkdir(parents=True, exist_ok=True)
(output / "metrics.json").write_text(
    json.dumps({"score": score, "steps": args.steps}), encoding="utf-8"
)
print("Result:", output / "metrics.json", flush=True)
```

5. 新建运行配置：程序 python，参数 ["train.py", "--steps", "12"]，工作目录 .。从顶部 Run 启动正式运行。Logs 显示真实输出，Artifacts 中有 metrics.json，Runs 可查看实际解释器、权限、退出码和 Git 信息，并导入数值指标。开发终端的结果默认在代码根/results，正式运行写独立 SCIENTIFY_RUN_DIR，二者不要混淆。
6. 新建 PowerShell/cmd 终端，执行 python -c "import sys; print(sys.executable)"；解释器应对应启动时的实验选择。Python REPL 中执行 input("name: ")，输入文字应正常返回。用编辑器运行含 input() 的文件也应可输入。
7. A 和 B 分别执行持续循环脚本或参数 --steps 300。切换实验后可独立查看输出；A Ctrl+C 只停止 A，B 继续。隐藏终端面板后 B 继续，终止按钮才结束对应终端进程。切回文献页等待任务结束后，关闭保护应自动解除。
8. A 活跃期间尝试归档、移除或产品 Git 切分支，确认有保护；B 的独立操作继续可用。普通空闲 shell 不锁死 Git。选择另一个解释器后，新终端用新环境，旧终端仍显示并使用旧环境。
9. 外部目录首次执行询问信任，拒绝不启动。检查环境创建、安装、终端和正式运行全过程没有外部控制台闪现。新建本地 HTTP 服务，用同一终端或浏览器访问 127.0.0.1，确认可信手动执行支持本地网络。
10. 配置模型后另验全局 AI：在 A 的新代码会话读取当前 Python，启动正式运行并查询真实结果；切到 B 新建另一会话，不能改绑 A 的旧会话。中止聊天不停止已经启动的正式运行。
