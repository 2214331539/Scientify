# Projects 启动页重构

日期：2026-09-26。依据用户提供的书本封面参考图，在 F 盘 Tauri 主线上重构 Projects 启动界面。

## 页面与交互

- 左栏：Scientify 品牌、个人空间、团队协作空间；进入团队区后展示团队导航。底部头像和“登录”为静态展示，没有登录请求或假登录状态。
- 右侧顶部：当前空间搜索、网格/列表切换、原生窗口控制。保留可拖动区域及关闭保护。
- 中央：默认书本封面，显示项目名称、研究方向和更新时间；虚线封面新建项目。列表提供同一批项目及操作。显示方式保存在独立 UI 偏好中。
- 封面右上角菜单：编辑、收藏、归档/恢复、删除。支持键盘焦点、上下键和 Escape。项目筛选提供全部、收藏、归档与排序。
- 左下角：直接复用 AppearanceControls；主题、图标动效及跨窗口偏好同步与 Workspace 一致。设置、备份和关于入口保留。
- 新建项目默认轮换克制的封面色，可在编辑表单中自定义。已有项目颜色和原字段保留。

## 项目与团队数据

继续使用原 schema 3、Zustand 串行保存、revision 与原子写入，不引入账号服务或新数据库。

项目创建、编辑与归属调整复用 ProjectForm。查询按当前空间过滤名称、研究问题和研究方向。删除先确认，保存成功后才从界面移除；失败保留项目和所有记录，允许重试。删除会移除项目所属的笔记、实验、任务、对话及对应订阅/活动，解除共享文献关联；不会删除磁盘项目目录、文献目录或 PDF 附件。需要撤销已保存删除时，可使用现有数据备份恢复流程。

团队支持创建、编辑、查询、进入和删除。删除团队将项目移到个人空间。当前“团队协作空间”是本地团队项目组织；在线成员邀请、权限和同步尚未接入，表单明确说明此边界。

## 代码边界

- `AppShell` 增加 launcher 布局变体；Workspace 沿用原布局。`App` 继续拥有导航、弹窗、存储与关闭保护。
- `ProjectSidebar`：品牌、空间导航、静态账号和全局控件。
- `ProjectLibrary`：搜索/筛选、网格/列表、团队目录和删除确认。
- `ProjectActions`：共享项目菜单、键盘与焦点行为。
- `model.ts`：项目/团队删除的数据规则、封面色及文字对比度。
- 清除旧项目侧栏样式，复用 Button/Input/Dropdown/Modal/WindowControls/BrandMark。
