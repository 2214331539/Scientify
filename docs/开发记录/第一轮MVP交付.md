## 本轮 UI 优化

参考 Oleafly 的主题变量、按钮、侧栏和编辑器截图，统一为白色内容面、浅灰导航面与少量青绿色强调。一级导航、二级视图和内容标签使用不同选中样式；三列首行统一为 40 px，顶栏 48 px，局部工具栏 36 px。

项目列表、概览、文件树、代码语法、论文预览、PDF 工具栏、AI 首次使用与笔记编辑均已调整。深色主题采用对应语义变量；保留键盘焦点。AI 快捷建议只填入草稿，发送由用户操作。

公共样式规范见 [UI 结构与风格规范](../架构设计/UI结构与风格规范.md)。本次修改前的源码副本位于项目 `.test-artifacts/ui-before-oleafly.zip`。

## 启动与数据

关闭旧窗口后运行 [Scientify-MVP.cmd](../../Scientify-MVP.cmd)。启动器优先选择 release，避免单实例机制唤起旧窗口。

release 与 debug 的数据目录独立。需要迁移时按 README 的完整目录复制说明处理，勿覆盖已有数据。JSON 导出不包含 PDF 与项目源码。
