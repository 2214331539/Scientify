# Electron 退役

2026-09-24，经确认，Scientify 全面转向 Tauri 2 + React。

## 已移除

- `electron/`：主进程、preload 与旧业务服务。
- `renderer/`：旧页面、业务模块、样式及生成的 PDF.js vendor 资源。
- `preview.cjs`：旧 Node HTTP 预览服务。
- `tests/`：仅针对旧 Electron/renderer 的测试与过期验收说明。当前测试保留在 `src/`、`crates/` 和 `src-tauri/`。
- `scripts/setup.cjs`、`scripts/check.cjs`、`scripts/fixture.cjs`：旧资源复制、语法检查与手工夹具脚本。
- `README.electron.md`、旧 `UI信息架构.md`、`package-lock.json`。
- `package.json` 中的 Electron 主入口、依赖、`legacy:*` 与 `test:legacy` 命令，以及 pnpm 的 Electron 安装脚本许可。

## 保留

- Rust 工作区迁移与回归测试：读取并复制用户旧数据，不依赖 Electron 源码或运行时。
- `scripts/prepare-pdf.mjs` 与 `public/pdfjs/`：当前 Tauri/React 阅读器仍需要的离线资源。
- `Scientify.cmd`：Tauri 开发入口；`Scientify-MVP.cmd`：已构建桌面程序入口。
- `.preview-data/`、`.tauri-data/`、用户 AppData、外部项目目录：属于数据，不随源码退役删除。
- 历史迁移文档保留并标记状态，避免把历史计划当作当前命令。

`pnpm-lock.yaml` 是唯一 JavaScript 依赖锁文件。间接依赖 `electron-to-chromium` 来自 Babel/Browserslist，用于浏览器版本映射，不是 Electron 运行时。

## 验证

- `pnpm install --frozen-lockfile`、`pnpm check` 通过。
- 前端 17 个测试文件、67 项测试通过。
- `cargo test --workspace --locked`：23 项测试通过，包含旧数据迁移。
- `pnpm build` 通过；分包大小提示仍存在，与本次退役无关。
- 主线源码、构建配置及启动脚本没有对已删除模块的引用。
- Tauri release 构建通过，输出为 `Scientify/target/ui-shell/release/scientify.exe`；默认目录的首次构建因正在运行的 EXE 被 Windows 占用而失败，因此改用独立输出目录，未关闭现有应用。`Scientify-MVP.cmd` 会选择最新构建。
