# 实验管理与执行身份第一批

本批按照 [实验管理与 Python 开发说明](../产品功能文档/实验代码版本管理页面说明.md) 的第一批交付顺序实施。研究项目现在可以登记多个真实代码目录，每个实验分别保存运行配置，文件与 Git 使用相同目录解析，新的 Agent 线程与正式运行记录具有实验归属。

## 实现范围

- “实验”内部新增管理表及左侧入口。新建空目录、关联已有目录/worktree、搜索、打开、重命名、归档/恢复和移除登记均接入持久化。
- 新空目录位于当前应用数据的 `workspace/projects/experiment-<uuid>`，与其他实验的托管根并列；外部目录不搬动。
- 同一真实根、父子重叠根和内部凭据/缓存根不能登记为独立实验。后端校验绝对路径、真实路径及目录链接，文件 API 不能只靠前端传任意根来访问其他项目。
- `schema: 3` 兼容迁移为每个旧项目创建默认实验，保留原目录和配置。迁移不移动代码、不安装环境、不重置聊天；初始化标识避免移除后自动重建默认实验。
- 实验选择持久化；各目录的标签、草稿、选区及撤销沿用现有文件会话。配置按实验保存，日志列表按实验过滤，旧手动记录仍可在默认实验查看。
- 新 AI 线程及正式运行由后端根据实际根推导实验标识。已有聊天保持原生 thread/cwd；切换实验不迁移它的记忆或执行目标。引用材料返回时先恢复实验选择，避免打开其他目录的同名文件。
- 有活跃 AI/正式运行时，不能移除、归档或改变对应实验根。重命名及其他实验操作继续可用。移除登记保留代码、Git、聊天和运行记录；已登记 worktree 先移除实验登记才能由 Git 删除工作目录。
- Git 子目录检查不再自动扩大文件根；文件编辑保持原边界，完整仓库管理要求关联仓库根。

## 验收步骤

使用可丢弃测试目录；不要把用户现有仓库当演示数据。

1. 打开已有项目，进入实验管理，确认出现默认实验，原配置和代码可用。重启再打开，默认实验不重复。
2. 新建空目录实验，再关联另一个测试仓库。在每个目录创建同名 `train.py`，写入不同内容。
3. 在 A 留下未保存草稿，切到 B 修改同名文件，再返回 A，确认内容、草稿和配置分别保留。
4. A、B 分别启动简单配置。切换实验后输出列表只显示对应运行；后台任务仍能独立查看和停止。
5. 在 A 新建 AI 会话并启动任务，切 B 新建第二个会话。确认第二个会话使用 B；返回第一个会话仍操作 A。切换不会复制记忆或取消另一任务。
6. 活跃任务期间尝试移除或归档对应实验，应拒绝；重命名及独立实验的管理仍可用。
7. 结束任务后归档、恢复、移除登记。磁盘文件不被删除；重新登记该目录不会静默把旧聊天绑定到新的实验身份。
8. 尝试重复登记同根、大小写别名、父子目录、内部数据或另一项目已有根，验证错误反馈且没有文件覆盖。
9. 从旧 AI 材料链接返回 A 的文件，确认不会打开 B 中同名文件；从运行入口返回时定位对应实验。

## 验证与边界

自动测试覆盖迁移幂等、删除后不重建、独立配置/草稿、Windows 路径比较、原生目录隔离和活跃 Agent 保护。新增 IPC 测试使用真实临时目录，经过生成的 Tauri ACL 验证准备、登记前拒绝访问、登记后读写和另一项目拒绝访问。

验证结果：`pnpm check`、`pnpm format:check` 通过；`pnpm test --maxWorkers=4` 为 42 个文件、208 项测试全部通过。`cargo test --workspace` 通过，新增原生 IPC 与活跃会话保护测试分别通过；最后补跑 `cargo test -p scientify-core --test workspace`，13 项全部通过，包含旧项目 `updatedAt: null` 的兼容迁移。`git diff --check` 无空白错误。仓库文档本地链接检查为 69 条、0 断链。

`pnpm tauri build --no-bundle` 成功，生成 `target/release/scientify.exe`（15,563,776 字节）及配套 `target/release/codex.exe`，引擎版本为 0.158.0。本次为 Release 可执行程序构建，未生成安装包、未自动启动桌面应用。Vite 仍有既有大块体积提示，Rust 链接器有导出库提示，均未阻止构建。

浏览器验证管理页、重命名、归档/恢复及代码导航；桌面文件/执行能力须在桌面版验收。真实模型的两个目录并行任务仍需要用户使用其服务商补验，不把本地夹具等同于模型验收。

本批没有交互终端、Python 自动发现/venv/Conda、克隆、完整 Source Control 侧栏、LSP、调试或测试发现。管理页的 Python 列如实显示“未配置”；下一批接入真实 PTY 和 Python 环境。当前 Git common-dir 锁及外部 shell 的协调范围没有扩大，独立代码根不等同于操作系统或依赖环境隔离。
