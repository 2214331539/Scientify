# UI 统一与 AI 关闭保护修复

本轮沿用 [UI/UX 标准](../UI-UX/README.md)，针对切页与点击反馈不足、后台刷新卡顿，以及 AI 中止后窗口仍被关闭保护阻挡的问题进行修复。

## 关闭问题

复现了空闲会话回收与另一会话输出重叠的竞态：回收期间会话被标记 saving；另一会话的 emit 将其注册为待处理任务，随后回收删除内存对象，却未清理 workspace store 的任务标记。界面已经没有该任务，但关闭保护仍看到它。

[AgentRuntime](../../src/features/assistant/agent-runtime.ts) 在回收成功后显式清理该会话的关闭标记，并合并重叠轮询，防止重复回收。没有将真正运行的任务、待保存结果或文件保存保护绕过。独立终端/正式运行仍须在对应入口停止；中止 AI 对话不会自动停止它先前创建的正式运行。

## UI 与动效

- 控件圆角统一 4px，菜单/对话框统一 8px，实验卡片保留 8px。标题字距归零，错误长文本允许换行。
- 按下即时加深背景，释放后恢复 120ms 过渡；移除按钮和导航文字缩放，以及悬停临时改变圆角。
- 一级导航使用同一个指示条移动 160ms；重复点击当前页面不重放切页。实验卡片/列表切换使用移动底板及 160ms 局部淡入。
- 切页直接提交 React 状态，移除整页 View Transition 截图。标题与工具栏使用可取消的局部淡入，编辑器、PDF、终端正文不参与；不为动效重建编辑会话。
- 实验详情和 AI 执行记录使用同款 Lucide 箭头及原生 details/summary，展开即时、箭头旋转 160ms。明暗主题和减少动态效果沿用共享语义变量。

## 性能

Python/终端状态快照未变化时不发布新 store 状态，避免每秒无意义地重绘实验工作区。AI 历史消息按实际正文与角色进行 React memo，流式输出不重复解析所有历史 Markdown；消息独立订阅语言偏好，避免缓存后语言标签不更新。

## 手动补验

1. 使用新构建打开可丢弃项目，快速切换五个一级入口、实验管理与代码页；观察选中即时更新、局部短淡入，文件光标、草稿和终端任务继续保留。
2. 打开 AI，启动两条独立会话，完成/中止其中一条；等待一分钟让空闲会话回收，同时让另一条输出。两条都结束并保存后，应能关闭窗口。
3. 若仍有正式运行、Python 安装任务、开发终端或未保存结果，应保留真实保护。分别停止并保存后重试；不能把关闭阻挡消失当成任务已经被终止的证据。
4. 检查浅色/深色、键盘 Tab/Enter/Escape 和 Windows 减少动画设置。

本次未测量真实 WebView2 设备帧率，未对用户真实服务商重新发请求，也没有自动启动或关闭用户应用。本轮不新增调试、测试发现或完整 SCM 入口。
