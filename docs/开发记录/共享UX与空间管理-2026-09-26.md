# 共享 UX 与空间管理

日期：2026-09-26。仓库：Scientify / Tauri。范围：公共交互与启动页，不增加研究业务功能。

## 页面变化

- 顶部移除全部项目、收藏、归档筛选与排序；按更新时间显示当前空间项目。归档项目保留在集合中并带状态，仍可右键恢复。
- 个人空间中的项目支持右键 / Shift+F10 重命名、编辑、删除；不修改左侧个人空间本身。
- 团队空间在侧栏显示为小卡片，支持右键修改和删除；创建入口为虚线卡片。进入团队区直接显示选中团队的项目书架，无独立团队目录页。无团队时的创建按钮打开团队表单，不误建个人项目。
- 删除团队把项目转入个人空间；删除项目保留磁盘文件与文献附件。失败保持原数据和确认窗口，允许重试。
- 底部工具只保留设置与主题切换；数据备份和关于归入设置分类。静态头像仍无登录行为。

## 共享实现

- [motion.css](../../src/styles/motion.css) + [tokens.css](../../src/styles/tokens.css)：120/160/200/240ms 反馈与柔和减速，菜单退出 100ms；主题图标、树箭头和分段视图选中底板一致。
- [Menu](../../src/components/primitives/Menu.tsx)：项目、团队和文献目录复用。视口边缘限制、外部点击/滚动/失焦关闭、方向键/Home/End、Escape/Tab 与焦点恢复。视觉退出立即 inert / aria-hidden，快速重开清除旧计时。
- 原生 select 使用 CSS base-select 渐进增强，保持原选项、表单与键盘行为；支持的内核统一 picker 样式和过渡，不支持时保留系统选择器。
- [Modal](../../src/components/Modal.tsx) 统一进入动效、遮罩、焦点和未保存确认；显式 autoFocus 在 showModal 后执行，嵌套弹窗退出后再恢复最初触发点。关闭/保存即时执行，不复制表单来做退出效果。
- [prompts](../../src/components/prompts.tsx) 取代应用内的 confirm/prompt，保留取消返回值与异步保护。原生窗口重复关闭请求合并；OS 文件选择器和浏览器 beforeunload 仍使用系统界面。
- 右侧辅助工具只动画化自身进入，不改变文件/笔记会话，不逐帧修改正文宽度。

## 边界

本轮不宣称 Windows 原生 GUI 或帧率验收通过；实际画面验收在 Chromium 浏览器完成。reduced motion 有代码规则和组件回归，未修改用户的 Windows 动效设置。团队仍是本机组织方式，无在线同步和成员服务。表单/辅助栏关闭即时，菜单与增强 select 才保留退出过渡。
