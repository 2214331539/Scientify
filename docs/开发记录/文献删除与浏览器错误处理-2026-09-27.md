# 文献删除与浏览器错误处理

日期：2026-09-27。

## 单个 PDF 与笔记

- 文献目录条目和已打开的 PDF 标签均可右键 →「移入回收站」。订阅侧栏显示时，也可从 PDF 标签操作。
- 确认框显示文件名；删除 PDF 同时回收对应 `.notes.md`、移除文献索引、关闭阅读和笔记标签、释放笔记会话。标签上的 × 和 Delete 键仍仅关闭标签。
- 有未保存或正在保存的笔记时阻止文件操作；操作期间笔记区域暂停输入。回收失败会恢复文件与索引。
- 回收包带 `restore.json`，包含原路径及原索引。未完成回退保留 `.scientify/operation.json` 并阻止后续写入，避免覆盖恢复证据。
- 外部文件管理器造成的 PDF 缺失仍保留重新关联能力；应用内明确删除会注销绑定，避免相同内容的其他 PDF 意外继承笔记。

## 原生浏览器

Windows 使用 WebView2。默认沿用 Windows 系统代理配置，不把 WinHTTP 的“直接访问”结果视为 WebView2 未走代理的证据，也不把系统 PAC、分协议代理和绕过规则简化成单个地址。

可选 `SCIENTIFY_BROWSER_PROXY=http://host:port` 或 `socks5://host:port` 在创建浏览器前显式覆盖；默认无需设置，不保存到仓库，不支持含账号密码的代理 URL。更改此覆盖后需要重启应用。

WebView2 的 `IsSuccess=false` 既可能表示网络错误，也可能表示 HTTP 4xx。现在结合 HTTP 状态和 `WebErrorStatus` 区分网站限流、代理认证、DNS、连接、证书及其他错误；正常取消不报错，旧导航完成事件不覆盖新导航。

HTTP 429 等响应保留网页显示，让用户能看到并自行完成网站要求的验证。前端不再因为 `tab.error` 隐藏原生网页，也不在地址或错误变化时反复 hide/show。对话框覆盖、窗口隐藏和离开文献页面仍隐藏原生视图。

新标签首页和关键词搜索均使用 Google。网站验证码、共享代理出口限流由网站决定；本次不绕过验证、不关闭证书检查。

依据：[Microsoft 导航完成事件](https://learn.microsoft.com/en-us/microsoft-edge/webview2/reference/win32/icorewebview2navigationcompletedeventargs)、[Microsoft 代理参数说明](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/webview-features-flags)、[Google 异常流量说明](https://support.google.com/websearch/answer/86640?hl=zh-Hans)。
