# 协作文献初始化同步

## 完成内容

- 项目绑定后首次打开文献页，客户端会扫描当前文献目录。
- 尚未建立索引的 PDF 会先建立本地绑定，保留现有文件路径和论文笔记关系。
- PDF 通过 OSS 的 SHA-256 去重上传，文件内容不经过协作 API 中转。
- 导入操作和非空论文笔记按小型 JSON 变更写入本地 outbox，并在每条变更写入后持久化。
- 应用中途退出后，下一次打开会继续处理未完成项目；重复初始化不会重复排队相同路径的操作。
- 初始化成功后，普通同步负责增量变更；远端无法安全应用的变更继续留在 inbox 并在文献页提示。
- 本地冲突会记录服务端版本号，可以选择以本地版本为基础重试，或明确保留本地并移除待同步操作。
- 远端延期变更可以明确忽略并保留本地，避免冲突长期停留在计数器中。

## 边界

初始化只处理当前已绑定的本地文献目录，不上传 API Key、绝对路径或实验运行环境。服务器只保存项目成员、同步元数据和 OSS 对象元数据，PDF 内容存放在 OSS。
