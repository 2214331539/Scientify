# 设置界面与切换稳定性

## 参考实现

阅读本机 Oleafly 的 `src/components/layout/SettingsModal.tsx`（约 1150–1235 行）、`src/components/settings/AppearanceSection.tsx`、`src/components/settings/SettingsToggleRow.tsx`、`src/components/ui/use-modal-accessibility.ts`，以及语言切换测试。

采用固定弹窗尺寸、固定宽度分类导航、右侧独立滚动、实时设置和焦点保护的组织方式。沿用 Scientify 自身的 React 组件、HTML dialog 和数据服务；不加入尚不存在的拼写检查、下载器或编译引擎设置。

## 改动

- 顶栏只保留主题切换，语言入口移至“设置 → 通用”。
- 主题按钮取消 aria-pressed 常驻选中样式，hover/active 也保持透明底。两个图标保留固定占位，使用短透明度/旋转过渡；键盘焦点环保留，减少动态效果规则继续生效。
- 主题和 document.lang 在绘制前更新。项目选择器、笔记入口、项目列表筛选等控件有稳定占位，减少语言文本长度导致的外壳伸缩。
- 设置统一为通用、外观、数据与备份、关于四类；原数据和关于入口直接进入对应类别。
- Modal 增加可选 sidebar/heading/className，普通表单弹窗不受影响。设置使用固定外框、稳定滚动槽、语言说明预留行高；语言变化不重放打开动画。
- 个人资料草稿由设置弹窗持有，切换类别不丢失；保存失败可重试，关闭/退出有未保存保护；存在草稿时数据替换保持禁用。
- Modal 卸载时显式恢复到打开它的控件，使用 preventScroll 防止关闭时页面跳动。
