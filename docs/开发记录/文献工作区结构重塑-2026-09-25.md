# 文献工作区结构重塑

## 页面结构

```text
App 顶栏
├─ 48px 全局导航
├─ 文献左侧资源边栏              ┬─ 文档标签 A / B / 空白页 / ＋
│  文献库 | 订阅                 │
│  导入 PDF / 收录信息            │  PDF 或文献信息可视化
│  搜索 / 阅读状态筛选            │
│  项目根目录                    │  PDF 浮动翻页 / 缩放
│    └─ 文献资源                 │
│  当前文献状态 / 信息编辑        │
└─ App 全局状态栏，右下角 AI / 笔记
```

去掉文献区跨栏标题、资源展开/收起按钮、中央文献表格工具栏及文献数量底栏。保留资源边界拖拽；文献库/订阅按钮与右侧标签栏对齐。

左侧树是当前项目文献的逻辑资源树，支持折叠和键盘导航，不代表移动 PDF 到磁盘目录。本轮未新增实体文件夹或文献移动能力。搜索涵盖题名、作者、备注和文件名。

订阅只切换边栏，当前为空白；右侧已打开页面和 AI 上下文保持。原订阅页面组件移除，历史订阅数据、解析器和后端获取接口保留，未清空数据。

## 标签与阅读

- 点击文献打开标签；重复打开选择已有标签。
- ＋新增空白页，随后从左侧选文献填入该页。切换标签、关闭当前/后台标签、全部关闭均可用。
- 关闭标签不删除文献或附件；关闭当前标签选择相邻标签。
- 标签按项目存入现有 UI session；恢复时过滤无效、重复及其他项目的资源。
- 首页继续工作、搜索、笔记来源仍可打开对应文献并合并进标签集合。
- PDF 页码沿用本地阅读位置记录；缩放和滚动保留于当前应用进程，切换标签后恢复。跳转来源页优先于旧缓存。
- 阅读器只挂载当前 PDF，切换时释放旧渲染任务，避免每个标签都常驻一套 PDF worker/canvas。

## 导入与编辑

导入 PDF 后先保存文献索引，成功后直接打开阅读标签；作者、摘要等通过左侧“文献信息”编辑。失败时保留待保存索引，重试不重复复制 PDF。文件选择/复制过程进入既有 pending 操作保护；取消不生成文献记录。

`PaperForm` 从原页面拆出，继续使用原保存校验、附件接口与未保存保护。右侧无 PDF 的条目只呈现标题、作者、摘要、备注等信息。
