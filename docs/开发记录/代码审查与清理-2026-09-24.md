## 边界与后续

- Vite 仍提示部分 JavaScript 分包大于 500 kB；属于后续加载性能优化项，本次没有通过提高警告阈值掩盖它。
- Windows 链接器输出创建导入库的信息，被 Rust 显示为 linker_messages 警告；release 构建成功。
- Rust 文件保存有内容版本校验和原子替换，但不能与任意外部编辑器形成跨进程事务；校验至替换之间仍有很短的外部写入窗口。
- 浏览器适配器基于 localStorage，尚无跨标签页事务锁；原生桌面持久化具有独立的进程锁和提交序列化保护。
- 本次未调用用户真实模型服务、未发出真实 arXiv 请求，也未通过实际桌面窗口操作验证关闭/拖拽。网络适配使用本地测试服务验证；窗口行为由现有模拟测试覆盖。
- 未修改用户研究数据、浏览器预览记录或旧版数据目录。测试使用独立夹具和临时目录。

测试通过不代表不存在其他缺陷；上述范围外的真实服务兼容性、长时间使用及大规模数据性能仍需后续验证。
