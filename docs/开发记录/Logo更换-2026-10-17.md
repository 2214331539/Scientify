# Logo 更换为“开箱”

素材来源：[docs/营销思路/Scientify-Logo-Kit](../营销思路/Scientify-Logo-Kit/README.md)。标志由双半脑加 S 形留白，换成一只打开的箱子和一颗从箱口升起的圆点。品牌定义中描述标志的段落已同步改写，见 [品牌定义](../营销思路/品牌定义.md)。

## 对应关系

| 位置 | 素材与实现 |
| --- | --- |
| 顶栏、Projects 启动页（BrandMark） | `public/brand/scientify-{light,dark}.png`，取自 app/{light,dark}/scientify-96.png；浅色主题为墨黑单色，深色主题为白色箱体配荧光绿圆点 |
| 浏览器标签 | `public/favicon.ico`，取自 web/favicon.ico |
| Windows 程序、窗口、任务栏、安装包 | `src-tauri/icons/icon.ico`，由 `scripts/prepare-icons.mjs` 从 `src-tauri/icons/source/` 生成，11 帧，256 px 在前 |
| 其余平台图标 | `pnpm tauri icon` 由 desktop/dark/scientify-1024.png 生成，iOS 与 Android 背景色为 #111A17 |
| README 头图、UI 示例页、`docs/营销思路/logo.png` | 素材包内文件原位更新，引用路径不变；logo.png 换成白底墨黑新标志 |

## 变化

- 默认程序图标由浅色底板改为深色底板：白色箱体加荧光绿圆点。荧光绿在白底上对比度不足，浅色背景一律用墨黑单色版。
- 素材包新增 SVG 母版（svg/、web/favicon.svg）和可重复执行的生成脚本 source/build.mjs；PNG 和 ICO 文件名与旧版一致，现有引用无需修改。source/ 下旧版的 original-logo.png、master-transparent.png、generation-prompt.txt、build.cjs 仍在原处，已不再使用。
- BrandMark 素材由 48 px 改为 96 px。启动页侧栏显示 32 CSS px，48 px 素材在 2 倍屏会被放大。
- 未修改应用代码和打包配置。

## 验证

- 素材包 validation.json：71 个 PNG、6 个 ICO 的尺寸、RGBA、帧顺序和标志居中检查全部通过。生成时曾在同一页面并发截图，导致 ICO 小尺寸帧取到其他尺寸的局部；已改为逐张渲染、ICO 复用同尺寸 PNG，并增加居中检查。修复后重新核对了 `icon.ico` 的 11 帧和 `favicon.ico` 的 3 帧。
- `node scripts/prepare-icons.mjs` 输出 256 / 192 / 128 / 96 / 64 / 48 / 40 / 32 / 24 / 20 / 16 px。
- `cargo test -p scientify --lib runtime_window_icon_uses_high_resolution_frame` 通过：嵌入新图标后，运行时窗口图标解码为 256×256。
- 未重新构建桌面程序，也未在安装后的快捷方式、托盘里实际查看。

运行中的窗口需重启才会使用新图标；Windows 已固定的旧快捷方式可能保留图标缓存，可取消固定后从新版程序重新固定。macOS 图标沿用整幅底板，没有按 macOS 图标网格留白，适配 macOS 时需要另行导出。
