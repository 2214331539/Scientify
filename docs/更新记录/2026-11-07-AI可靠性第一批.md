# 2026-11-07 内置 AI 改为本地 Agent

- **状态**：验收中
- **提交**：2026-11-11 与搜索、笔记回收站一起提交，基于 `3c5bec8`
- **数据**：数据格式没变。附件记录多了两个可选字段：附件保存的路径、快速问答读取的 PDF 页数。数据目录下新增两个文件夹：`workspace/inbox`（收集箱对话的工作目录）和 `workspace/agent/attachments`（对话附件）

## 原则

2026-11-07 定：内置 AI 就是一个本地 Agent，和单独使用 Claude Code、Codex 一样。任何地方都是 Agent；附件就是文件；内置工具是帮手，不禁止它用自己的办法；只留两条底线：询问模式下写工作目录以外、联网要先审批，不往文献文件夹里写临时文件。

## 改了什么

- **收集箱也是 Agent**：项目中心收集箱里的对话不再是快速问答，在数据目录下的收集箱文件夹里工作，能读附件、新建和修改收集箱笔记、执行命令。收集箱没有内置浏览器。
- **附件交给 Agent**：拖进来的文件存到这个对话自己的文件夹，把完整路径交给 Agent，由它读全文。PDF 用内置阅读器按页读，其他文件用它自己的办法读。每个文件最多 100 MB。
- **放宽读 PDF 的规定**：以前禁止 Agent 用命令行或 Python 读 PDF；现在优先用内置阅读器，读不了（比如扫描件）可以用自己的办法，只是不往文献文件夹里写临时文件。
- **Agent 能新建笔记**：比如“把总结存成笔记”。询问模式下先弹“请求新建笔记”审批卡；写入后笔记列表立即刷新。只对新对话生效。
- **设置里的“AI 模型”**：列出所有连接，显示默认连接和聊天、Agent 的验证结果；可以设为默认、编辑、删除、新建。编辑用的是 AI 面板里同一个表单。
- **快速问答只剩一种情况**：模型连接本身不支持 Agent（Anthropic、Gemini 协议）。这时附件仍取前面的文字，标签写明“前 N/M 页”。
- **文字精简**：权限菜单说明、几条提示横幅、模型表单的说明改短；阅读页底部不再常驻提示；“Permission”译为“权限”；收集箱里的“快速问答”改叫“AI 对话”。

## 已知问题和遗留

- 本机用到 Windows 沙箱的测试报“windows sandbox: registered Core process has no package identity”，退回改动前的代码也一样，是本机 Codex 沙箱服务的状态问题，不是这次的改动；以 CI 结果为准。验收时如果 Agent 执行命令失败并出现这句话，也是同一个原因。
- 对话删除后，它的附件文件还留在数据目录里。
- 收集箱没有内置浏览器，需要查网页时请在项目里问。
- 划词浮窗本身仍是快速问答；转到 AI 助手后才是 Agent。
- 已有的旧对话保留开始时的工具：比如 11-07 以前的对话没有“新建笔记”。
