## 问题

182 账号在 Mac 上看到的文献数量和项目归类都和 Windows 不同。原因：

| 位置           | 情况                                                                                 |
| -------------- | ------------------------------------------------------------------------------------ |
| Windows 正式版 | Proactive、Foundation、Agent Memory 都是个人项目，从没开过多设备同步，改动一直没上传 |
| 云端           | 只有 11-02 用开发版测试时传上去的 Proactive（当时转成了团队项目，30 篇 PDF）         |
| Mac            | 拉到的就是这份旧的 Proactive，放在团队项目里；“我的项目”是空的                       |

原来的设计是个人项目默认只在本机，要在项目菜单里手动“在多台设备上同步”，而且只有打开的项目会同步；这和“同一账号所有设备一致，只有不同账号才协作”不符。

## 改了什么

| 变化                   | 说明                                                                                                                                                                                                                       |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 登录后所有项目自动同步 | 本机每个项目都自动发布到账号；云端已有同 ID 的项目直接关联。去掉“在多台设备上同步…”菜单、对话框和新建项目时的勾选框                                                                                                        |
| 我在的项目都自动出现   | 另一台电脑上的个人项目、别人共享给我的团队项目，都自动加到本机并在后台下载；去掉所有“下载”按钮                                                                                                                             |
| 同步全在后台           | 云端列表每分钟刷新，变更序号变了的项目立刻同步（另一端的修改一般一分钟内到达）；所有项目每 5 分钟再同步一轮。去掉“立即同步”“刷新”按钮、“已连接协作服务 · 刚刚刷新”、项目同步面板里的“等待上传”“已跟踪内容”和“关闭本机同步” |
| 按成员归类             | 只有自己的是“我的项目”；有其他成员或待加入的邀请才是“团队项目”                                                                                                                                                             |
| Windows 的 Proactive   | 沿用开发数据 11-02 的同步记录作为共同起点，第一次同步能正确合并，不产生大批冲突副本（用户手动复制）                                                                                                                        |
| 独立登录页             | 没登录时应用只显示登录页（第一次打开、退出登录后），不能跳过；验证码登录、密码登录、注册、忘记密码；去掉自托管服务入口。服务端新增 `/v1/auth/password-login`、`/register`、`/reset-password`                               |
| 设置：账号、协作       | 新增“账号”页（手机号、设置或修改密码、退出登录）；“协作”页只列团队项目、我的角色和成员，去掉服务器地址、协作开关和连接状态                                                                                                 |
| 空文件上传失败         | 第一轮同步时空的 `train.py`、`python.py` 上传 OSS 返回 HTTP 411：请求体为空时没有带 Content-Length。现在上传总是带上（`sync.rs` 的 `put_blob`）                                                                            |
