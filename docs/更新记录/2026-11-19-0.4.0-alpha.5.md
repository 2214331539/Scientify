# 2026-11-19 0.4.0-alpha.5：导入文献库、高亮批注、云主机

- **状态**：Windows 已发布（安装包和更新清单在 OSS，装着旧版的 Windows 电脑在应用里更新）；Mac 下次一起打包。更新清单只放一个版本，所以 Mac 在补上之前收不到更新
- **来源**：alpha.4 之后的两批需求（11-18 晚 UI 打磨，11-19 迁移与新模块）
- **提交**：`d117da7` 翻译窗口跨屏缩放、`38f84f2` 标题栏和小球、`46a39e8` 数据位置、`f9dc7bf` 导入文献库、`d624dcc` 高亮批注、`35e458f` 首次导览、`3f8af57` 终端与共享卡片、`068acc6` 云主机、本记录所在提交（版本号）

## 改了什么

| 方面       | 内容                                                                                                                       |
| ---------- | -------------------------------------------------------------------------------------------------------------------------- |
| 导入文献库 | 从 Zotero（自动找到数据文件夹）、BibTeX、RIS 导入；分类变文件夹，PDF 按内容去重，笔记、高亮带过来，另写 references.bib     |
| 阅读器     | 选中文字出现工具条：五色高亮、下划线、批注、复制、摘录到笔记、问 AI；批注列表；高亮存在论文记录里，随同步                  |
| 云主机     | 新模块：系统 OpenSSH 连接（读 ~/.ssh/config，密钥被拒时要密码），资源管理器、打开文件夹、编辑保存、主机上的终端            |
| 首次导览   | 聚光灯式导览，帮助 → 功能导览可重看；全新安装时欢迎步骤可选数据位置                                                         |
| 共享       | “共享与同步”改成标题栏按钮下的卡片：邀请、头像、改角色、撤销邀请、移出、冲突、同步状态                                     |
| 终端与面板 | 终端浅色和深色配色加最低对比度；底部面板拖顶边调整高度                                                                     |
| 数据位置   | 设置里显示正常路径（不再有 `\\?\`）；新设备的同步文献放在数据目录 `Literature` 下；“使用已有数据”                          |
| 界面       | 标题栏只留图标并加浏览器入口；订阅页去掉；标签页顶部黑线去掉；小球动作更丰富；实验侧栏底部路径去掉                         |
| 修复       | 翻译窗口在不同缩放的两块屏幕上大小正确；实验的“打开文件夹…”从当前实验目录开始                                              |

| 编号 | 怎么做                                                     | 应该看到什么                                                 | Windows | Mac |
| ---- | ---------------------------------------------------------- | ------------------------------------------------------------ | ------- | --- |
