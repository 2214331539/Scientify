## 一、回答更像 ChatGPT

| 方面       | 做了什么                                                                                                             |
| ---------- | -------------------------------------------------------------------------------------------------------------------- |
| 代码块     | 语法高亮，右上角显示语言和“复制”按钮                                                                                 |
| 图表和图片 | AI 生成并保存在本机的图片（图表、示意图）直接显示在回答里，点一下在中间放大看；网上的图片仍然不加载                  |
| 本机文件   | 回答里的文件链接、写成代码的绝对路径都能点，点了在当前模块中间打开预览                                               |
| 思考过程   | 模型给出思考摘要时，回答上方显示“已思考 N 秒”，展开能看到摘要；思考时实时显示                                        |
| 本轮文件   | 这一轮新建、修改、删除了哪些文件，显示成卡片，点了在中间打开                                                         |
| 写法约定   | AI 被告知：提到文件时用绝对路径写成链接，生成的图存成 PNG/SVG 后嵌进回答，交互式图表另存 HTML 并给链接，代码块标语言 |

**中间预览本机文件**：图片、PDF、CSV/TSV 表格、Notebook、Markdown、代码和文本直接显示；HTML 用系统浏览器打开（这样图表脚本才能运行）。只能打开项目自己的文件夹（实验代码、写作、AI 工作区、代码文件夹）里的文件，顶部可以“用系统程序打开”。

## 二、自定义指令

- **设置 → AI 模型 → 自定义指令**：希望 AI 了解你什么、怎样回答（例如研究方向、常用工具、回答详略），所有对话都参考。
- **项目设置 → 给 AI 的项目说明**：这个项目的数据在哪、指标怎么算等，只在这个项目里参考，随项目同步到其他设备。
- 内置 Agent 和快速问答都用；对新对话生效。它们不能放宽审批、沙箱和文件夹规则。

## 三、四档权限

| 档位     | 做什么                                             | 什么时候问你                     |
| -------- | -------------------------------------------------- | -------------------------------- |
| 只读     | 读文件、检索、回答；不改文件，也不执行会写入的命令 | 不问；要写的操作直接失败         |
| 询问     | 在沙箱里工作，可以联网（新对话默认）               | 每条不确定安全的命令、每次改文件 |
| 自动     | 在项目的文件夹里自己改文件、运行命令               | 只在超出文件夹范围时             |
| 完全访问 | 不用沙箱                                           | 不问                             |

- **以后都允许**：审批卡在 Codex 给出命令前缀时（例如 `pip install`）多一个“以后都允许”，以后同类命令不再询问。
- **注意**：以前的对话保存的是“询问”，现在“询问”比以前更谨慎（以前的行为相当于现在的“自动”）。嫌问得多可以在输入框旁把这个对话改成“自动”。

## 四、重新生成和编辑

- 最后一条回答下面有“重新生成”，最后一条问题下面有“编辑问题”。
- 重新生成：原样再问一次；编辑：问题回到输入框，改完发送。两种都会替换这条问题和之后的回答。
- 内置 Agent 会把引擎里的对话历史也退回到这条问题之前（`thread/revert`）；**文件不会回退**，AI 上一轮改过的文件还在。这个版本之前的对话没有记录轮次，重新生成时引擎会保留旧的历史。

## 五之二、界面打磨（11-17 晚，同在 0.4.0-alpha.3）

用户看了第一版后指出：路径里总出现 `\\?\`、`file:///`，链接和正文一个颜色，网页要跳到外部浏览器，对话页不够成熟。改了：

| 方面     | 做了什么                                                                                                                                                                                                   |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 路径     | 应用里显示的路径去掉 Windows 的 `\\?\` 前缀（实验文件夹列表、运行目录等）；回答里的本机文件一律显示成“图标 + 文件名”的蓝色标签，鼠标停留看完整路径，不再出现长路径和 `file:///`；AI 也被要求只用文件名链接 |
| 链接颜色 | 回答里的链接和文件用蓝色（三套配色各一种），和正文区分                                                                                                                                                     |
| 中间预览 | HTML 在内置浏览器里打开（图表脚本能运行，只能读同一文件夹的资源）；Word（.docx）在应用里排版显示；PowerPoint（.pptx）按页显示文字和图片；PDF、图片、表格照旧；老格式 .doc/.ppt/.xls 提示用系统程序打开     |
| 用户消息 | 右侧浅灰圆角气泡；“本轮材料来源”只在鼠标停留时出现                                                                                                                                                         |
| 回答     | 全宽排版，复制、重新生成在鼠标停留时出现；标题、表格、行内代码的样式重做                                                                                                                                   |
| 过程     | 每轮的思考、计划、步骤和差异收进回答上方的一行：进行中显示“正在搜索网页… · 12 秒”，结束后是“已处理 4 分 28 秒 ›”，点开看细节；本轮文件卡片放在回答下面                                                     |
| 时间     | 间隔超过 30 分钟或跨天时，中间显示“今天 13:54”“昨天 09:05”                                                                                                                                                 |
| 对话导航 | 问题有 3 个以上时，右侧出现一列小横杠，鼠标停留显示问题内容，点击跳到那里，当前位置的横杠颜色更深                                                                                                          |
| 回到最新 | 往上翻时底部出现圆形箭头，点一下回到最新消息                                                                                                                                                               |
| 输入框   | 圆角卡片，输入时有轻微阴影；左下角“+”可以选文件和图片（以前只能粘贴或拖进来）；发送按钮改成圆形                                                                                                            |
