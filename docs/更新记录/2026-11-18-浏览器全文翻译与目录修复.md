## 一、修了什么

| 问题                      | 原因                                                                                                          | 改法                                                                                                                                       |
| ------------------------- | ------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| 浏览器从 Chrome 变成 Edge | 内核一直是 WebView2（和 Chrome 同为 Chromium）；11-17 把首页和地址栏搜索从 Google 改成了必应，页面风格像 Edge | **设置 → 通用 → 浏览器搜索引擎**可选 Google、必应、百度，默认恢复 Google；没有代理、打不开 Google 时可以改成必应或百度                     |
| 二级网页点不进去          | 从 AI 回答或文档打开的网页叠在中间，没有标签栏；要求“新窗口打开”的链接会在后台新建一个看不见的文献标签        | 中间预览里这类链接直接在当前页打开，可以用后退回来；文献页的浏览器照旧开新标签                                                             |
| 右键删除对话后列表收起    | 右键菜单打开时主动关掉了对话列表                                                                              | 重命名或删除完成后，对话列表在原处重新打开                                                                                                 |
| Vinci2 没有目录           | 这篇 PDF 自带书签，但书签里只有论文标题一条；目录逻辑是“有书签就用书签”，于是不再识别正文章节                 | 超过 3 页的文档只有一条书签时，改为从正文识别章节，识别不到才保留那条书签；以前存下的这种目录打开时重新识别；页边的 arXiv 编号不再算作标题 |
| 论文笔记栏拖不宽          | 论文旁的笔记栏最宽 500 像素                                                                                   | 和 AI 栏一样，可以拖到只给论文留 360 像素                                                                                                  |

Vinci2 修好后识别出 1–7 章、附录 A–C 和参考文献；还会多出两条表格表头里的“Method”，暂不处理。

## 二、全文翻译

- **入口**：文献树里右键论文 → **全文翻译**，在论文旁的笔记栏打开“译文 · 论文名”标签，和论文笔记并排。
- **翻译**：点“开始翻译”后，按页取出论文文字，切成约 1800 字的段，用当前 AI 模型每次翻三段；每翻完一段就保存，进度条显示“正在翻译 N/M 段”，可以停止；切到别的标签翻译也不中断。
- **结果**：一篇 Markdown，每页一个小标题“第 N 页”，点了跳回 PDF 那一页；术语第一次出现时附英文原文。
- **绑定和同步**：按论文 id 存在应用数据的 `note-assets/<项目>/translations/<论文 id>.md`，论文移动、改名不影响；和文档附件一起同步到同一账号的其他设备。
- **限制**：扫描版 PDF 没有文字，不能翻译；中途出错（例如额度用完）会停下并保留已翻译的部分，“重新翻译”从头开始。
