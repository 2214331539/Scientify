## 一、AI

| 功能         | 做了什么                                                                                                                                                                       |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| MCP 工具     | **设置 → AI 模型 → MCP 工具**：添加 MCP 服务，可以是本机命令（命令、参数、环境变量），也可以是网址；能单独停用或删除。对新任务生效，AI 能用这些服务提供的工具（例如读 Zotero） |
| 撤销本轮修改 | 最后一轮的“本轮文件”卡片后面有“撤销修改”，确认后把这一轮改过的文件恢复原样：修改的改回去，新建的删掉，删除的恢复（连同文件夹）。下一轮会告诉 AI 文件已恢复                     |
| 错误上报     | 应用里没接住的错误（报错和未处理的异步失败）自动发给服务器，后台 **系统 → 错误** 查看。**设置 → 数据与备份 → 发送错误报告**可以关掉，默认开                                    |

**撤销的边界**：

- 只撤销 AI 用改文件工具做的修改；AI 通过运行命令或脚本写出的文件不在这一轮的差异里，撤销不了；
- 任何一个文件在这一轮之后又被改过，整次撤销都不执行，什么也不改；
- 二进制文件跳过；一轮的差异超过 60 KB 时不提供撤销；
- 只会改项目自己的文件夹里的文件。

**错误报告里有什么**：报错信息和调用栈（路径里的系统用户名替换成 `~`）、应用版本、系统和架构、设备标识（服务器只存它的哈希）、登录时的账号。不含文件内容。同一个错误每次启动只报一次，每次启动最多 20 条；服务器按“错误 + 版本”合并计数，每个地址 10 分钟最多收 30 条；标为已处理后再出现会重新变成未处理。

## 二、文档对齐飞书

| 功能       | 做了什么                                                                                                                                                        |
| ---------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 表格工具条 | 光标在表格里时上方出现工具条：上下左右插入行列、删除行列、合并和拆分单元格、标题行和标题列、对齐、单元格背景色、删除表格                                        |
| 附件       | 任何文件都能拖进、粘贴或用“/文件”插入，显示成带文件名和大小的卡片，点了在中间预览；附件随项目同步（选文件最大 200 MB，拖入或粘贴最大 50 MB）                    |
| 粘贴链接   | 粘贴网址先变成链接，下方小条可以改成“标题”（网页标题）、“卡片”（标题、摘要、站点和配图），或“导入为文档”（网页正文变成子页面，开头注明来源）；也可以“/链接卡片” |
| 链接小条   | 光标落在链接上时显示去向（网页显示网址，文档链接显示页面标题），可以打开、复制、编辑、移除；Ctrl/⌘ 点击直接打开。**以前文档里的链接点了打不开，这次一起修了**   |
| 复制链接   | 块菜单和页面菜单都有“复制链接”；粘贴到文档里显示成页面标题，点开跳到那一页并把那个块滚到中间、短暂高亮                                                          |
| 封面       | 页面标题上方“添加封面”，8 种浅色渐变或上传图片，鼠标停留可以更换或移除；两台设备同时改时和标题、图标一样合并                                                    |
| 导出 Word  | 页面菜单和左侧页面菜单都有“导出 Word”：标题、各级标题、列表（编号会重新开始）、待办、引用、高亮块、代码、表格（含合并单元格）、图片和链接；WebP 图片转成 PNG    |

## 三、没做和需要你决定的

- **Codex 升级（0.158.0 → 0.169.0）没做**：要下载新版引擎并实际运行来核对接口变化，这一步需要你同意或在你的电脑上执行；接口有变化时要同步改应用里的对接代码；
- **错误上报的服务端要部署**才会生效：服务器启动时自动建两张新表（迁移 2），后台多一个“错误”页；没部署时应用发出的报告会被丢弃，不影响使用；
- 导出 Word 里的公式按 LaTeX 原文写出（没转成 Word 公式），页面封面不进 Word；
- 文档外部的链接（比如在 AI 回答里）点 `scientify://` 链接还不能跳转，只在文档里有效。
