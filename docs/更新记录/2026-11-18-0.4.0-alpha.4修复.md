# 2026-11-18 0.4.0-alpha.4：内测反馈修复

- **状态**：两个平台已发布（11-18 16:08）：安装包和更新清单在 OSS，官网已部署；装着 alpha.3 的电脑在应用里更新
- **来源**：0.4.0-alpha.3 内测后的反馈
- **提交**：`a1fe5f9` 共享、`9f5d72d` 同一目录多个 AI 对话、`c8b56a0` 对话细节、`61bd6d6` 翻译窗口、本记录所在提交（额度文字和版本号）

## 修了什么

| 问题                       | 原因                                                                             | 改法                                                                                     |
| -------------------------- | -------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| 个人项目点“共享”没反应     | 个人项目都开了同步，标题栏的“共享”打开的是同步面板，里面没有共享操作             | 个人项目打开“共享到团队”对话框；团队项目的面板改名“共享与同步”，所有者可以在里面邀请成员 |
| 同时让 AI 分析两篇论文报错 | 同一目录同一时间只允许一个 AI 回合，文献页的对话都在 AI 工作区，第二个对话被拒绝 | 同一目录可以同时跑多个 AI 对话；AI 或实验在跑时仍不能做 Git 写操作                       |
| AI 执行过程自动展开        | 运行时默认展开                                                                   | 始终默认收起，点开才看                                                                   |
| 用户消息下有“本轮材料来源” | —                                                                                | 去掉                                                                                     |
| 右键对话列表会收起         | 右键时先关掉了列表                                                               | 右键菜单弹出时列表保持展开                                                               |
| 翻译窗口还是大             | 上次常见情况只窄了 20 像素                                                       | 正文 14 号字，宽度 300/360/420，最高 380                                                 |
| “本周期已用”被看成周额度   | 这是按月的套餐额度，“本周期”容易读成“本周”                                       | 改为“本月已用 X / Y 点”，旁边照旧显示哪天恢复                                            |

**额度说明**：官方模型只有按月的套餐点数和每日上限，没有周额度。后台“套餐与额度”管每月点数，用户详情里可以赠送额度、调单日上限和解除限流。
