- **数据**：不涉及。只改版本号、发布流程和文档，数据格式不变；从 0.3.0-alpha.2 或 alpha.3 升级不需要迁移，更新前照常备份数据目录

## 改了什么

- **两个仓库同步**：同一个 `main` 推到 Tsingyu-x-THU/Scientify-Desktop（私有，团队开发）和 2214331539/Scientify（公开）。公开仓库上次更新停在 0.3.0-alpha.2（2026-10-04），这次补上了之后的全部提交。
- **Release 只在公开仓库发布**：发布工作流只在 2214331539/Scientify 运行；版本标签推到 Scientify-Desktop 不会触发发布。
- **Windows 版由 GitHub Actions 构建并发布**，macOS 版改为由维护者在 Apple Silicon Mac 上构建，检查后补充到同一个 Release。
- **版本号升到 0.3.0-alpha.4**：`v0.3.0-alpha.3` 标签已经存在并指向较早的提交，按规定不复用、不移动。
- **发布说明更新**：协作功能按现状描述；macOS 数据目录改为正确的 `~/Library/Application Support/Scientify/ScientifyData`；本机构建的 macOS 包如实说明做过哪些检查；指向更新记录。
- **文档**：《版本发布与分支管理》《开发与验收流程》、AGENTS.md 改为双仓库推送、只在公开仓库发布；补充 macOS 本机构建和上传的步骤。

**0.3.0-alpha.4 相对上一个公开版本（alpha.2）的主要变化**：

- **协作**：独立的登录页，手机号登录；团队协作空间；同一账号的多台设备同步云端项目（文献、笔记、代码文件、运行记录）；邀请成员；默认连接官方协作服务。
- **划词翻译**：内置 Yita 翻译浮窗和问答浮窗，问答可以转到 AI 助手的同一个对话；系统托盘。
- **文献**：订阅里的个人信息源和网页收藏；PDF 缩放和图层出错时页面不再空白。
- **笔记**：实时预览的 Markdown 编辑器、笔记图片；AI 可以读写笔记，修改前逐项审批。
- **设置**：可以自定义快捷键。
- **AI**：连接验证失败不再把对话降为纯聊天；Git 操作和笔记修改逐项审批。

## 已知问题和遗留

- **macOS CI 的 `cargo test` 不通过**：从 PR #3 起一直如此（退出码 101），和这次改动无关，Windows 发布不受影响。失败日志只有仓库管理员能看，可以在 Mac 上用 `gh run view 41593146358 -R 2214331539/Scientify --log-failed` 读取。修好之后在下一个版本发布。
- macOS 安装包没有 Developer ID 签名和 Apple 公证，Windows 安装包没有代码签名，首次打开会有系统提示。
- 本机构建的 macOS 包没有经过 GitHub Mac runner 上的启动和覆盖安装数据保留验证；这项验证脚本会改动真实数据，只能在临时 runner 上运行。
