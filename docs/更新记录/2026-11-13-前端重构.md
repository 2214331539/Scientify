# 2026-11-13 前端重构

- **状态**：开发完成，待 Windows / Mac 实机验收
- **依据**：[整体重设计方案（第三版）](../UI-UX/2026-11-13-整体重设计方案.md)和[交互原型](../UI-UX/演示/整体重设计/index.html)
- **原则**：
  - 只做后端已有的功能；后端没有的数据不在界面上编造；
  - 业务组件（PDF 阅读器、笔记编辑器、代码编辑器、Git、终端、AI 面板）保留逻辑，只换外壳和样式；
  - 每个阶段结束时类型检查、全部测试、格式检查都要通过，应用可以正常使用。
- **数据**：不改数据格式；收集箱、项目收藏的数据保留在工作区里，只是界面不再显示。

## 已完成的改动

- **配色**：`src/styles/tokens.css` 换成石墨、纸、夜三套；设置 → 外观的“配色”可选跟随系统、石墨、纸、夜（跟随系统时白天用所选浅色配色，晚上用夜）。
- **一个窗口**：桌面版只开主窗口，项目在主窗口里打开；主窗口获得原项目窗口的实验、终端、Git 权限，关闭时一并结束终端、Python 检查和内置浏览器标签；窗口默认 1440×900，最小 1000×640。
- **外壳**：`src/shell/` 新增标题栏、两级侧边栏、通知、外框；原首页的待处理事项（新加入的团队项目、同步冲突和失败、一周内失败的运行）进通知；“共享”按钮在已同步项目上打开原同步面板，在本机项目上打开共享对话框。
- **去掉**：首页、收集箱入口、项目收藏入口、概览、状态栏、图标导航栏、旧顶栏。
- **快捷键**：Ctrl J（⌘J）打开或收起 AI；Ctrl \（⌘\）显示或隐藏侧边栏。
- **项目中心**：书本封面改成 7 种中性色（旧的鲜艳颜色映射过去），封面上是方向、名称和研究问题；去掉收藏筛选、收藏菜单和封面角标；有已归档项目时才出现“进行中 / 已归档”；搜索移到工具栏；在其他设备上的项目单独列在书架下面，可直接下载；页面标题区的重复窗口按钮去掉。
- **文献**：文献库 / 订阅切换和目录树在项目里放进侧边栏（离开文献立即撤出）；第一个标签固定为“文献库”，显示当前文件夹的文档表格（名称、文件夹、笔记、读到、大小），双击或回车打开，↑↓ 选择；表格和目录树共用拖放、复制粘贴和右键菜单；“导入”按钮和拖入文件用同一套导入逻辑。目录树保留文件：多选、拖到文件夹、复制粘贴这些文件操作都在树上，测试也覆盖它们，与原型“侧边栏只放文件夹”不同。
- **订阅**：去掉后端没有的“消息推荐（开发中）”入口。
- **笔记**：
  - 笔记模块改成左列表、右页面：列表是搜索、新建和笔记（标题、更新时间、去掉 Markdown 记号的摘要），页面是大标题加居中的正文；侧边栏是“全部笔记”和“回收站”。
  - 右侧栏里的笔记仍是单列，和笔记模块是同一个编辑器，切换位置不丢草稿。
  - 自动保存，状态只写“已保存 / 正在保存… / 未保存 / 保存失败”；笔记模块里去掉“保存”和“添加当前来源”按钮（来源取自当前笔记本身，在模块里没有意义），右侧栏保留。
  - 修好渲染后的列表项之间的大空隙（渲染块继承了编辑器的换行规则）。
  - 主区窄于 680 时只显示一栏，编辑时左上有返回。
- **实验**：
  - 顶部文字页签：实验、代码、版本、记录、环境；搜索、worktree、后台任务是右侧的小图标按钮。“运行”页签改名“记录”，避免和右上角的“运行”按钮重名。
  - 侧边栏列出实验（圆点是最近一次运行的状态），右侧的“+”新建实验；当前实验的代码文件、搜索、Python 环境在侧边栏下半部分。标题行的“当前实验”下拉在应用里不再出现。

- **写作**：原先挂“开发中”占位页，现在接上已有的写作模式文件编辑器；去掉“尚未接入 TeX 编译器”的提示行；有页签时不再重复显示“写作”。

- **AI**：空对话时提示居中，配一个图标；回到项目中心时右侧栏一并收起（原先会留在项目中心）。
- **新建项目向导**：“第 1 步，共 2 步”改成步骤条。
- **对话框**：遮罩变浅。
- **样式清理**：删掉旧顶栏、图标导航栏、状态栏、项目切换浮层、首页、收集箱的样式；页面标题行、表格、搜索框、分段筛选、状态圆点成为共享样式（`sf-page`、`sf-table`、`sf-search-field`、`sf-segmented`、`sf-state`）。
- **文档**：[视觉与布局](../UI-UX/01-视觉与布局.md)按新规范重写；[组件标准库](../UI-UX/02-组件标准库.md)补上外壳组件和“侧边栏资源槽”规则；UI-UX README 和组件 README 同步。

## 代码整理（11-14，提交 d108a72 之后）

合成一个窗口以后，原来“项目中心窗口 + 项目窗口”的代码已经没有入口，这次一并删掉：

- **前端**：`App` 的窗口模式只剩 `main`（桌面）和 `browser`（预览、测试）；删掉打开第二个窗口、第二个窗口就绪、项目列表刷新、深链接参数这几段，以及“正在打开项目”的等待框；关闭窗口一律按退出处理。删除 `ProjectsWindow.tsx`、`WorkspaceWindow.tsx`、`platform/windows.ts`。
- **Rust**：删除 `windows.rs`（`open_project_window`、`workspace_window_ready`、`show_projects`）和 `projects-window` 权限组；托盘的“显示”“退出”、再次启动时唤起、划词转交 AI、应用接口的来源检查都只认主窗口；主窗口关闭时照常结束终端、Python 检查和内置浏览器；权限组只对 `main` 窗口开放。
- **测试**：双窗口的 4 项测试换成 1 项“一个窗口里进出项目”；关闭保护的 2 项改用主窗口；Rust 测试里原来的第二个可信窗口 `workspace` 改为 `main`，“别的窗口不能接管”改由一个不受信任的窗口验证，删掉两窗口共读数据的断言。
- **其他死代码**：旧图标导航用的 `workspaceItems`、封面文字色 `coverInk`、旧顶栏的明暗切换按钮 `AppearanceControls` 和它的样式、Rust 里只给第二个窗口用的 `webview_profile::window`。
