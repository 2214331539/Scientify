## 发布了什么

| 平台             | 文件                                            | 大小   | SHA-256                                                            |
| ---------------- | ----------------------------------------------- | ------ | ------------------------------------------------------------------ |
| Windows x64      | `Scientify_0.3.0-alpha.5_windows_x64_setup.exe` | 164 MB | `1994f170e745fcb2b71327bca6cd3a770d2c4e68a24b0fa696bae289131383b7` |
| macOS Apple 芯片 | `Scientify_0.3.0-alpha.5_macos_arm64.dmg`       | 172 MB | `80863ca9cabde46fa8f950e8192db80064d09a01abea863f0ff529530a153511` |

- **下载地址**：官网下载页 https://124.221.115.83/scientify/download/ ，按钮指向 OSS 北京区 `soundingx-download-package/scientify/latest/` 的固定文件名，流量走 OSS，不走服务器。`scientify/0.3.0-alpha.5/` 下另有带版本号的安装包和 `SHA256SUMS_<平台>.txt`。
- **怎么出的**：Windows 在本机 `pnpm tauri build --bundles nsis`，Mac 由用户在 Apple 芯片的 Mac 上构建并 `stage-release.mjs` 后发来（核对过和 Mac 上算出的 SHA-256 一致）。两个都用 `scripts/publish-installer.mjs` 上传，上传后匿名检查过能下载。
- **安装包变大了**：比 0.3.0-alpha.2 的 76 MB / 98 MB 大，因为写作页的 LaTeX 引擎和预装宏包随安装包附带。
- **官网**：版本号、日期、两个平台各自的校验值文件；更新日志的“下一版”改为 0.3.0-alpha.5；下载页的“不需要注册”改为“第一次打开用手机号登录”。
- **没做的**：GitHub Releases 还没有这一版（上面仍是 0.3.0-alpha.4）；安装包没有签名，也没有在干净的电脑上做覆盖安装的验证（CI 的安装检查只在 GitHub Actions 上跑）。
