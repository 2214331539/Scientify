| AI 自己从 GitHub 下载 Tectonic 编译，在稿件里留下 log、pdf        | AI 不知道写作页自带 TeX                                                                                                                                   |

## 改了什么

| 变化                     | 说明                                                                                                                                                                                                                     |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| AI 每一轮跟着页面工作    | 实验页在当前实验的代码目录，写作页在当前稿件的文件夹（没有稿件时是项目文件夹），其他页面在项目文件夹；代码对话在别的页面仍留在自己的代码目录。文献文件夹永远不再是工作目录；询问模式下也不能往里写                       |
| AI 知道自己在哪里        | 每一轮附上：用户所在页面、打开的文件（完整路径）、项目文件夹、各实验代码目录、稿件文件夹、文献文件夹（只读），以及“代码放实验、论文放稿件、编译交给写作页，不要自己下载 TeX”的约定。对话和页面不一致时也照样带上当前页面 |
| AI 写完文件立刻看得到    | 一轮结束后，没有未保存修改的已打开文件重新读取，文件树刷新                                                                                                                                                               |
| 写作页自动认出稿件       | 项目文件夹下的子文件夹里有含 `\documentclass` 的主文档（优先 `main.tex`），就自动登记为稿件。“从写作中移除”的不会再自动加回，手动“使用项目里的 LaTeX 文件夹”后恢复                                                       |
| 稿件打开就是左源码右 PDF | 第一版验收时写作页停在“项目文件”视图（之前没有稿件时选的），只显示普通文件，没有编译和 PDF。现在在“项目文件”视图里打开稿件里的文件会切到那篇稿件；新识别出的稿件自动选中；稿件第一次打开时自动编译一次，右侧直接显示 PDF |
| 实验和写作分开           | 默认实验的文件树不再显示稿件文件夹                                                                                                                                                                                       |
| 稿件登记随项目同步       | 之前只有稿件文件夹里的文件同步，“哪些文件夹是稿件、用什么编译器”只在本机，另一台电脑要重新登记。现在随项目信息同步；旧版本发来的项目信息里没有稿件时保留本机的，不会被清空                                               |
| 标签和 × 是一个整体      | 选中和悬停时整个标签一起高亮，× 在标签内部，只在悬停或选中时出现                                                                                                                                                         |

运行、Git 工具、技能和目录锁仍属于对话绑定的目录，所以两个对话可以像以前一样同时工作。
