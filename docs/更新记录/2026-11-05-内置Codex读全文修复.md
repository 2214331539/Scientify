## 原因

11-03 定位的“读 PDF 只能看到一页”，这次查了正式数据里的 14 个对话和 Codex 的运行日志：

- **划词对话一直是快速问答**：14 个对话里 9 个是从划词浮窗转来的。这类对话在项目里继续时仍只发当前页的文字（最多 12000 字），模型看到的就是“一页”。
- **代码页开始的对话没有文献工具**：只能用命令行转 PDF，在询问模式的沙箱里经常失败。
- **看不出当前模式**：分不清 AI 是没去读，还是读不到。
- **Agent 本身能读全文**：11-04 的日志里，文献页的 Agent 把一篇 33 页的论文从第 1 页读到了最后。

## 改了什么

- **划词对话在项目里改用 Agent**：从划词浮窗转来的对话，在项目里继续时改用 Agent，并带上划词的原文、译文和之前的问答。
- **所有项目对话都能读论文**：代码页开始的新对话也能列出、读取和搜索论文。
- **当前论文直接可读**：阅读页把打开的 PDF 交给 Agent，不用先找文件。
- **读完再答**：问整篇论文（总结、方法、实验、结论等）时，Agent 从第 1 页读到最后再回答；没读完不能说读了全文。
- **显示当前模式**：输入框右侧显示“Agent”或“快速问答”，悬停说明能看到什么；快速问答不显示权限按钮。
- **旧对话提示改短**：“这个旧对话不能读论文，新建对话后可以读全文。”

## 已知问题和遗留

- 项目外（收集箱、划词浮窗本身）仍是快速问答，只看到当前页和选中的文字；“用 Agent 读全文”的入口还没做。
- Agent 只能修改已有笔记，不能新建笔记。
- 扫描版 PDF 没有文字（还没有 OCR），超过 50 MB 的 PDF 不读。
- 快速问答里的 PDF 附件仍只取前 12000 个字。
