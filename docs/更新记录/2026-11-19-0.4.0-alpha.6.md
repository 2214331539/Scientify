## 改了什么

| 方面         | 内容                                                                                                                                               |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| 全文翻译     | 用 BabelDOC 翻整篇论文，排版、公式、图表和原文一致；引擎（Python、翻译程序、字体和版面模型）打进安装包，不联网安装                                 |
| 无感翻译     | 后台把文献库里每篇论文翻一次：右键打开的那篇最先，然后是新下载的，再是原有的；没额度或网络不通时悄悄暂停、过后继续；只有右键打开“全文翻译”才看得到 |
| 多设备       | 译文随同步；同一账号的设备各自在文献库里写一个认领文件，别的设备不重复翻                                                                           |
| ChatGPT 订阅 | 模型提供方新增“ChatGPT 账号（Plus / Pro）”：浏览器登录，AI 助手的请求从本机发出、用自己的订阅额度；显示套餐和用量；划词和全文翻译仍用其他模型      |
| 模型预设     | 新增豆包（火山方舟）、智谱 GLM                                                                                                                     |
| 笔记侧栏     | 笔记和译文侧栏两边都能拖到 80%，拖过 85% 自动关掉小的一边                                                                                          |
| Mac          | 从网上下载的未公证安装包，全文翻译引擎去掉下载隔离标记后运行；构建时设置 `APPLE_SIGNING_IDENTITY`，划词辅助程序用固定身份签名，授权在更新后保留    |
| 安装包       | Windows 安装包从约 172 MB 涨到约 520–590 MB（翻译引擎约 920 MB，压缩后 350–420 MB）；uv 不再随包发布                                               |
