## 改了什么

- **GitHub 上的 macOS 检查一直失败，修好了两个原因**：
  - 测试构建在 macOS 上链接失败：`tauri::generate_context!()` 在程序里调用了两次，macOS 会把 Info.plist 以固定的符号名嵌入，两份同名符号冲突（Windows 不嵌入，所以只有 Mac 报错）。现在只生成一次。
  - 窗口图标测试写死了 256 像素：macOS 用的是 512 像素的图标。改为检查图标是正方形且不小于 256 像素，原意（不能用 16 像素的小图）不变。
- **Windows 终端里 Ctrl+C 有时停不下程序，修好了**：Windows 的子进程会继承父进程“忽略 Ctrl+C”的设置。Scientify 如果是以禁用 Ctrl+C 的方式启动的（例如从某些启动器或后台任务启动），它打开的终端里按 Ctrl+C 就到不了 Python。现在打开终端前先恢复正常的 Ctrl+C 处理。GitHub 上那次 Windows 检查失败就是这个原因，本机能稳定复现，修复后通过。
- **失败原因公开可见**：两个检查工作流的 Rust 测试失败时，把失败的测试名、编译错误和断言信息写成运行页上的标注，不用管理员权限也能看到。
- **页面结构演示（待评审）**：新增 [页面结构演示](../产品设计/演示/README.md)，用接近真实的界面演示每个页面的布局和功能入口，可以切换 Windows 和 macOS，包括 macOS 原生窗口结构、独立设置窗口、菜单栏和划词翻译的授权引导；重新设计了“团队”页，去掉宣传文案。
