## 改了什么

- 界面整体打磨（方案见 `docs/产品设计/界面打磨/方案.html`，页面标题与工具栏按负责人要求保持原样）：
  - 内容区和右侧栏变成灰底上的两块白色圆角面板，中间留缝。
  - 打开的论文和文件用浏览器式标签页；右侧栏的“AI 助手 / 文档”改成分段控件；实验页侧边视图只用底色表示选中。
  - 侧栏资源区的工具按钮只在鼠标移上去时出现。
  - 空页面统一成图标、标题、一句说明和操作；实验页第一次进入显示三步引导。
  - 提示条改成浅色底加圆点，红色只用于出错。
  - 菜单统一行高、图标颜色和悬停效果。
- 模型按套餐分级：免费版只能用 DeepSeek 两个模型，GPT 系列恢复为专业版可用（服务端 11-21 已改回，留有审计记录）。免费用户在模型列表里仍能看到这些模型，选择时弹出订阅卡片，点“加入微信群开通”显示微信群二维码。
- 二维码在管理后台“套餐与额度”页上传和更换（微信群二维码 7 天失效），应用每次打开订阅卡片时从服务端读取。
- 设置 → AI 模型 一级分成“Scientify 官方模型”和“其他模型”，其他模型再分 ChatGPT 账号、API 服务商、本地模型、自定义服务；官方模型不再显示地址和密钥栏。
- 设置 → 通用 加了“名字”和“AI 模型”两项入口，左下角账号菜单加了“模型设置”；原来没有用处的本地“显示名称”去掉。
- 当前套餐不包含某模型时，对话里的提示多了“升级到专业版”。
- 用 ChatGPT 账号登录后列出套餐能用的全部模型（含 Codex 默认不列出的，标“· 更多”）。
- 内置 Codex 引擎改为打包上游完整包（含 code-mode host、Windows 沙箱程序和 ripgrep），修复 GPT-6 等模型无法执行命令。
