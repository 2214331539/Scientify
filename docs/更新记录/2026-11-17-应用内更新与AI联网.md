## 一、应用内更新

| 方面     | 做了什么                                                                                                                                                                                |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 检查     | 启动 10 秒后检查一次，之后每 6 小时一次；只有用 `scripts/build-release.mjs` 打的正式包才检查，平时自己编译的版本在“关于”里显示“开发版不检查更新”                                        |
| 提示     | 有新版本时，通知中心出现一条（铃铛上有小圆点）：“新版本 x 可用 / 已下载”，可以“下载更新”“重启以完成更新”“更新内容”“稍后”                                                                |
| 设置     | 设置 → 关于：当前版本、更新状态和下载进度、更新内容、“立即更新”“跳过这个版本”“检查更新”，以及“有新版本时自动在后台下载”（默认打开）                                                     |
| 安装     | 先走和关闭窗口一样的保护（保存论文笔记和文档、有 AI 任务时先问、未保存内容要确认），再结束 Agent、终端、Python 检查等后台进程，然后安装并重启。Windows 以被动模式运行安装包，原目录覆盖 |
| 安全     | 更新包用 Scientify 的更新密钥签名，应用里写着公钥，签名不对就不装。密钥说明见[开发与验收流程](../开发流程/开发与验收流程.md)第四节                                                      |
| 灰度     | 更新清单里有 `rollout`（0–100），按设备算是否在本轮；“检查更新”手动查时不受比例限制，设成 0 就谁都不推                                                                                  |
| 渠道     | 只有预览版一个渠道，清单在 OSS 的 `scientify/updates/preview/latest.json`                                                                                                               |
| 最低版本 | 协作服务新增 `GET /v1/client-policy`；应用的每个请求带上版本号，低于 `MIN_CLIENT_VERSION` 的请求被拒绝并提示去“设置 → 关于”更新。默认不设最低版本                                       |

**0.3.0-alpha.5 的用户**：这一版还没有更新模块，要手动从官网装一次 0.4.0-alpha.1，之后的版本就能在应用里收到。

## 二、AI 联网和回答

| 方面       | 做了什么                                                                                                                                                                                                                                       |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 沙箱联网   | “询问”档的沙箱打开网络，`pip install`、`git clone`、`curl` 能用了；写文件仍限在项目文件夹内，命令和改文件照常审批。实验的托管运行同样能联网                                                                                                    |
| 网页检索   | 新工具 `scientify_web_search`：不开浏览器标签，直接查必应，返回标题、网址和摘要                                                                                                                                                                |
| 读网页     | 新工具 `scientify_web_fetch`：直接抓网页，去掉导航、脚本和页脚，只留正文和正文里的链接；PDF 不直接读，提示改用浏览器打开                                                                                                                       |
| 论文检索   | 新工具 `scientify_search_papers`：按关键词、作者、DOI 查 OpenAlex，按 arXiv 编号或指定 arXiv 查 arXiv；返回标题、作者、年份、期刊、引用数、DOI、链接、开放 PDF 和摘要                                                                          |
| 浏览器搜索 | 内置浏览器的搜索入口和首页从 Google 换成必应（cn.bing.com）                                                                                                                                                                                    |
| 回答方式   | AI 的说明改成：涉及最新信息、事实核对时主动联网；先给结论再展开；来自网页或论文的内容在句末用链接标出处，结尾列“来源”；只引用工具真实返回的网址                                                                                                |
| 链接       | 回答里的网址点了，在当前模块的中间区域打开网页预览（带地址栏、前进后退），不再跳到文献页；预览顶部可以“在文献页打开”或关闭（Esc 也能关）。在文献模块里点仍然开成文献页的浏览器标签                                                             |
| 进度       | AI 工作时，进度行显示正在做什么，例如“搜索网页：……”“阅读网页：……”“检索论文：……”                                                                                                                                                                |
| 计划       | AI 拆的步骤显示成清单“计划 · 2/5”，做完一步勾一步                                                                                                                                                                                              |
| 改动       | 这一轮改了哪些文件，显示成“本轮改动 · N 个文件 +a −b”，展开能看每个文件的差异                                                                                                                                                                  |
| 形象       | AI 助手换成 3D 软球形象（照用户给的参考图，蜜桃色、两只眼睛）：标题栏“AI”按钮、右侧栏页签、新对话空白页、进度行、文档“问 AI”都用它；平时会眨眼，思考时抬眼看，调用工具时轻轻弹跳。说明和备选配色见 [AI 助手形象](../品牌/AI助手形象/README.md) |

- **费用**：这几个检索工具都在本机直连，不需要密钥，不扣额度。必应偶尔可能要求验证，这时 AI 会改用浏览器搜索；OpenAlex 不登记密钥时按出口 IP 共享免费额度，用户多了要申请密钥。
- **旧对话**：工具在对话开始时登记，所以新工具只在**新建的对话**里有；旧对话里 AI 会改用浏览器工具。
