# 2026-11-04 macOS 界面适配与代码边界

- **状态**：验收中；11-06 审查修正后提交到 main 并推送，macOS 需要在 Apple Silicon 设备验收。
- **范围**：原生窗口标题栏、平台 UI 边界和前端平台检测；不改变项目、文献、笔记、Agent 或同步数据格式。
- **数据**：无迁移、无清空、无正式数据写入。

## 改了什么

- macOS 项目窗口和工作区窗口使用系统标题栏与交通灯；网页端不再显示 Windows 风格的最小化、最大化和关闭按钮。
- Windows 保留现有自绘窗口控制，浏览器预览不显示任何原生窗口控制。
- macOS WebView 顶栏采用较高的内容区高度、轻量边框和更宽的触控间距；项目书架也使用独立的 Mac 顶部间距。工作区导航、AI、笔记和编辑器仍复用同一套业务组件。
- 新增 `src/platform/os.ts` 作为唯一的平台检测边界；快捷键显示和实验终端默认 shell 复用它，不再各自解析 `navigator.platform`。
- 删除/整理范围仅限重复的平台判断和不可见的 Mac 自绘窗口控制调用；没有删除仍被设置迁移或测试使用的旧数据接口。

## 11-06 审查修正

- **项目窗口的平台判断写反了**：Windows 出现了系统标题栏（自绘顶栏下面又多一条），Mac 反而没有红绿灯。已改正，并加了检查。
- **Mac 配置会整组替换主窗口设置**：平台配置按 JSON merge patch 合并，数组整体替换，原写法会丢掉项目中心窗口的尺寸、最小尺寸、居中和“禁止系统拖放”。改为完整写出，并加了检查。
- **Mac 的项目中心不再套用工作区的三行布局**。
- **实验里“运行”打开的终端在 Mac 上默认 zsh**，和终端面板一致（原来是 bash）。
- **托盘“退出”只发给目标窗口**：原来两个窗口都会收到，项目中心可能在你确认保存前先关掉。
