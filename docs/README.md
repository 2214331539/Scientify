## 维护规则

- 产品功能有变化，先改产品设计，再写代码；上线后更新页面设计里的“现状”。
- 每次更新在更新记录里写一份记录。
- 方案落地后，把仍然有效的内容并入产品设计或技术方案，过程稿不再单独保留。
- 2026-11-02 以前的开发记录、旧版页面结构、竞品调研和营销草稿已在 2026-11-03 删除，需要时从 Git 历史中查看。
