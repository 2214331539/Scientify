# Scientify 产品功能说明（目标功能）

> 本文保留功能范围；二级条目为候选功能分组，具体页面内容后续确定。页面布局与导航以 [产品页面结构](../架构设计/01-产品页面结构.md) 和 [功能与导航框架](../架构设计/02-功能与导航框架.md) 为准。

## 一、工作台结构

- **一级导航**：项目概览、研究工作台、文献库、论文订阅区、实验与代码管理、AI 助手。
- **二级导航**：随一级工作区切换，展示该工作区内的功能页面。
- **中央工作区**：位置固定，按当前一级与二级导航呈现内容；列表、详情、编辑、阅读、翻译和问答均在此完成。
- **工作区布局**：中央区域按任务使用列表、编辑器、阅读器或分栏视图；工具栏操作在当前页面完成。
- **状态保留**：切换导航后保留各工作区的筛选条件、打开内容、编辑状态与阅读位置。
- **项目上下文**：顶部切换空间与项目；各工作区使用当前项目的资料，文献库可切换全部文献与项目文献。

## 二、一级工作区与二级导航

### 1. 项目概览

**定位**：掌握当前项目的研究目标、任务进度与协作动态。默认进入「项目总览」。

- **项目总览**
  - 展示研究问题、研究方向、当前阶段、负责人及资料概况。
- **任务与里程碑**
  - 以列表或看板管理待办、负责人、截止时间、完成状态与阶段目标。
- **项目动态**
  - 按时间查看文献入库、研究记录、实验运行与代码提交，跳转到对应工作区。
- **成员与分工**
  - 查看项目成员、职责与任务分配。
- **项目设置**
  - 管理项目信息、成员权限、关联目录、仓库、文献集合、归档与归属。

### 2. 研究工作台

**定位**：组织研究材料，撰写研究记录、文档与代码。默认进入「文件与编辑」。

- **文件与编辑**
  - 通过目录树管理本地文件，在中央编辑器中使用多标签与分栏编辑。
  - 支持代码高亮、补全、定义跳转、格式化、问题提示与搜索替换。
- **研究记录**
  - 管理想法、假设、实验设计、决策与组会记录，支持模板、列表和状态看板。
  - 记录以 Markdown 文件及元数据保存，与文件编辑使用同一份内容。
- **文档与预览**
  - 编辑 Markdown、LaTeX，分栏预览公式、图表、引用与交叉引用。
  - 插入文献引用、实验图表与研究记录。
- **历史版本**
  - 查看文件修改历史、对比差异、还原内容。
- **写作与代码辅助**
  - 结合当前文件或选中内容进行润色、改写、代码解释、脚本生成与报错分析。
  - 在中央分栏中预览建议，确认后写入文件。
- **论文协作（待定）**
  - 关联 Overleaf 项目，查看同步状态、同步 BibTeX，并提供外部项目入口。

### 3. 文献库

**定位**：集中管理已收录文献，完成整理、阅读、翻译与理解。默认进入「信息管理」。

- **文献导入**
  - 导入 PDF、DOI、arXiv 编号、引用文件，接入 Zotero 与浏览器采集。
  - 查看导入进度，处理重复文献与导入失败项。
- **信息管理**
  - 浏览文献列表，补全与校正元数据，管理集合、标签、阅读状态及项目归属。
  - 支持检索、筛选、批量操作与重复项合并。
- **PDF 阅读**
  - 在中央阅读器中分页、缩放、全文搜索、高亮、批注与摘录。
  - 阅读笔记保留来源与页码，可关联或转为研究记录。
- **实时翻译**
  - 翻译选中文本、段落或当前页，在中央分栏中对照原文与译文。
  - 切换目标语言，保留当前文献与阅读位置。
- **AI 助手提问**
  - 围绕当前文献、选中段落或多篇文献提问，生成解释、比较与综述提纲。
  - 中央区域并列呈现文献与问答，回答附来源与页码，支持跳回原文。
- **引用管理**
  - 复制引用、导入导出 BibTeX / RIS / EndNote，向研究文档插入引用。

### 4. 论文订阅区

**定位**：发现与筛选新增论文，将有价值的文献送入文献库。默认进入「论文更新」。

- **论文更新**
  - 汇总订阅源新增论文，查看标题、摘要、来源与更新时间。
  - 按研究方向、项目、来源及处理状态筛选。
- **订阅管理**
  - 配置 arXiv 关键词与分类、Google Scholar 作者与引用、期刊 RSS、DOI 关注。
  - 设置更新频率，查看抓取状态，处理失败重试。
- **论文筛选**
  - 标记待读、忽略或分配给成员，校正文献信息、去重、下载全文并加入文献库。
  - 入库后可跳转文献库，继续阅读、翻译与提问。
- **研究简报**
  - 按日或周汇总新增论文，生成主题摘要并配置提醒。

### 5. 实验与代码管理

**定位**：管理实验配置、运行过程、代码版本与结果复现。默认进入「实验列表」。

- **实验列表**
  - 创建与筛选实验，维护研究目标、关联假设、负责人、状态和标签。
- **配置与环境**
  - 管理超参、数据划分、随机种子、配置快照、依赖、镜像与硬件信息。
- **运行与日志**
  - 查看运行命令、历史、状态、日志、耗时与失败原因。
  - 远端运行（规划）：通过 SSH 或集群提交任务，接收运行状态。
- **代码版本**
  - 管理关联仓库、分支、提交与工作区快照，查看差异、提交选定文件、回退版本。
  - 关联实验与代码提交；需要修改代码时跳转研究工作台。
- **指标与比较**
  - 展示指标曲线与趋势，对比多个实验的结果、配置、版本和随机种子。
- **产物与复现**
  - 归档模型权重、图表、报告与附件，导出环境、命令、配置及复现清单。
  - 关联 MLflow、Weights & Biases、Aim、DVC、TensorBoard 的实验记录。

### 6. AI 助手

**定位**：集中处理跨文献、文件与实验的综合研究任务。默认进入「项目问答」。

- **项目问答**
  - 在中央对话区开展多轮讨论，结合项目资料进行研究分析。
- **资料与上下文**
  - 选择参与任务的文献、文件、研究记录、实验及指标，查看引用来源。
- **任务模板**
  - 复用文献综述、写作润色、代码分析、实验比较、复现清单与审稿回复模板。
- **会话与成果**
  - 管理历史会话，保存回答为研究记录，导出结果或预览文件修改。
- **模型配置**
  - 切换本地或云端模型，设置项目默认模型与连接参数。

**助手协同**：文献库、研究工作台等工作区内的 AI 页面直接使用当前材料；一级「AI 助手」承接跨模块任务，并可继续已有会话。回答保留来源，文件修改经预览确认后写入。

## 三、全局入口与公共能力

### 1. 空间与项目入口

- 顶部入口：切换个人或团队空间，创建、搜索、收藏、归档与切换项目。
- 账号与团队：管理个人资料、成员邀请、角色权限、共享资源与项目模板。

### 2. 全局工具

- 搜索与快捷操作：跨项目检索文献、文件、记录、实验与对话，支持命令面板与自定义快捷键。
- 通知与协作：评论、回复、提及、桌面通知、邮件摘要与操作历史。

### 3. 应用设置

- 数据管理：本地存储、离线使用、附件管理、云端同步、冲突合并、备份恢复与导入导出。
- 集成管理：配置代码托管、文献服务、论文协作与实验平台的账号和连接。
- 安全管理：数据加密、密钥管理、外发权限与操作审计。
- 偏好与扩展：主题、语言、键盘导航、减弱动效、插件与适配器。

全局入口位于顶部或设置区，六个科研工作区保持为固定的一级导航。
