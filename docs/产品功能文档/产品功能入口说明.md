## 项目管理

打开应用后的项目书架用于选择和管理研究项目。支持搜索、网格/列表切换、创建、编辑、收藏、归档及删除项目。空间侧栏切换个人与团队空间；团队目前是本机组织方式，不代表在线协作已经启用。

进入项目后，左侧只保留五个一级入口。没有独立 Files 页面；代码文件在实验区管理，论文文件在论文区管理。

## 五个主页面

| 页面 | 作用 | 主要入口 |
| --- | --- | --- |
| Overview / 概览 | 找回当前项目进度与下一步工作 | 研究问题、继续工作、最近材料、待办、项目设置 |
| Literature / 文献 | 管理并阅读研究文献 | 文献目录、搜索、PDF 标签、相邻论文笔记、网页标签、订阅入口与旧资料 |
| Notes / 笔记 | 整理项目研究笔记 | 笔记列表、新建、正文编辑、来源返回；与右侧笔记栏共享编辑会话 |
| Experiments / 实验 | 管理多个实验、修改代码、配置 Python、管理 Git、运行并记录结果 | 实验卡片/列表；左侧文件/搜索/Git/Runs/worktree/Python；顶部实验选择及运行，底部终端/日志/产物及解释器状态栏 |
| Paper / 论文 | 编辑论文草稿与引用材料 | Manuscript 文件树与编辑器、Markdown 分栏/预览、References 项目引用 |

文献的目录、PDF、原生网页和本地文件访问需要桌面版。订阅推荐、在线团队同步和账户登录尚未接入。

## 实验管理

从“实验”一级入口进入，代码页左侧试管图标可返回列表。支持搜索、新建空目录、关联已有目录或 worktree、打开、重命名、归档/恢复和移除登记。已有项目自动生成“默认实验”，代码不搬动，原运行配置保留。托管新目录位于当前数据目录的 `workspace/projects/experiment-<id>`；关联外部目录保持原位置。

同一实际目录和父子重叠目录不能重复登记为独立实验。默认卡片布局，可展开详情；页头切换垂直列表并记住偏好。卡片显示所选 Python 和正式运行/终端/环境任务活动数。归档或移除前需结束该实验的 AI、运行、终端及环境任务；移除登记保留磁盘文件、Git、聊天及运行历史。

## 实验 Code 页面

| 位置或入口 | 作用 |
| --- | --- |
| 左侧图标栏 | 切换文件、搜索、Git、Runs 和 worktree；底部进入后台任务及环境配置，文件入口可折叠资源区 |
| 左侧文件树 | 打开项目脚本、配置、数据文本等；支持文件名筛选、新建、刷新与折叠所有文件夹；显示当前 worktree 路径 |
| 左侧搜索 | 检索当前目录的文本或未保存缓冲，支持大小写、全字与正则；结果定位到代码，搜索可停止 |
| 编辑区标签 | 切换已打开文件，标记未保存；关闭标签不删除文件，未保存时经过保存保护 |
| 新建文件 | 在项目内创建文件；已有文件不被静默覆盖 |
| 编辑区 | 使用真实代码编辑器修改文件；切换视图保留草稿与编辑会话 |
| 保存 | 保存当前文件；外部版本冲突时保留草稿，可重读或另存副本 |
| 编辑按钮 | 撤销、重做、文件内查找/替换和自动换行；沿用 CodeMirror 的选区与撤销历史，显示行列位置 |
| 保存全部 | 只保存当前 worktree 的草稿；不会顺带保存其他目录 |
| 当前实验下拉框 | 切换登记实验；各实际目录的文件标签和草稿独立保留，旧会话与任务继续使用原目录 |
| 运行配置下拉框 | 选择执行配方；末项可新建配置 |
| 配置图标 | 编辑配置名称、可执行程序、参数和相对工作目录，或删除配置；不改变历史运行快照 |
| 环境图标 | 打开 Python 侧栏：发现/选择/验证解释器、创建 venv 或已安装 Conda 环境、管理依赖与准备任务 |
| 编辑器播放按钮 | 先保存当前 Python 文件，再使用该实验解释器在真实终端运行；支持 input() 和 Ctrl+C |
| 运行按钮 | 桌面版直接启动本机程序，无需配置模型；外部实验先信任目录。未保存代码先确认保存，保存失败不启动 |
| 底部终端 | 真实 PowerShell/cmd/Python REPL；新建、多标签、拆分、输入、中断与终止，隐藏面板不终止进程 |
| 底部日志 | 查看所选运行的只读输出，刷新或停止该次运行；可收起、最大化及还原，不是交互终端 |
| 底部产物 | 查看运行产物目录中的文件；支持打开文本文件预览 |
| 输出选择框 | 在当前实验的运行间切换日志与产物，不影响其他任务 |
| 后台任务 | 查看各项目正在执行的实验，并独立停止；切页、切项目或关闭 AI 面板不会取消运行 |
| 底部状态栏 | 查看分支和变更数量，点击分支进入管理；切换资源区与输出面板的可见状态 |

搜索最多读取 500 个文本文件、合计 32 MiB，单文件不超过 2 MiB，最多返回 200 个匹配；大文件、已知二进制及读取失败会显示部分检索状态。没有全项目替换。文件内查找/替换不自动保存，仍需检查并保存草稿。新版入口与回归证据见 [VS Code 布局与前端修复](../开发记录/代码工作区VSCode布局与前端修复-2026-10-02.md)。

配置示例：程序填写 python 或虚拟环境解释器路径，参数填写 ["src/train.py", "--seed", "42"]，工作目录填写一个英文句点。python 使用实验当前选择的解释器；显式解释器路径按实际执行记录。参数使用 JSON 字符串数组，不自动拼接成 shell 命令。手动运行和终端按本机用户权限执行，可访问网络和本机文件；Agent 发起的正式运行保持工作区沙箱及关闭网络，两者显示真实权限。多次运行仍共享项目源文件，请避免脚本覆盖同名输出。

每次运行提供独立的 SCIENTIFY_RUN_DIR 环境变量。脚本把结果写入该目录后，产物入口才能找到它；产品不会把脚本其他目录中的文件自动认定为本次产物。

## Python 环境

左侧环境图标或底部解释器入口打开 Python 侧栏。支持检测已有解释器、填写绝对路径并验证、在实验目录创建 venv，或通过已安装 Conda 创建 prefix。创建成功并通过解释器验证后，点击“使用此环境”保存到该实验；不会自动改动其他实验或已启动进程。

依赖页可查看真实 pip 包列表，安装 requirements、editable 项目、包及升级/卸载，Conda 环境可更新 environment.yml。准备任务后台执行，有日志、退出状态和取消；失败/取消不视为环境可用。系统 Python 包修改有额外确认；共享环境被正式运行或 Python 终端占用时，先停止任务再修改依赖。pip/Conda/UV 缓存和临时目录位于应用数据容器，用户已有系统 Python/Conda 不搬迁。

## 实验 Runs 页面

| 入口 | 作用 |
| --- | --- |
| 运行表格 | 查看名称、状态、来源和时间；来源区分本地执行与手动记录 |
| 搜索与状态筛选 | 快速找到运行或手动记录 |
| 行选择 | 在右侧打开该记录详情 |
| 勾选与比较 | 选择 2 至 4 条记录，并列检查配置、结论与同名指标；缺失值显示为空，不自动补零 |
| 新建记录 | 手动登记外部实验的方案、参数、指标和结论；只保存记录，不执行代码 |
| 编辑记录 | 修改手动记录；对于本地运行，只补充方案、指标和结论，实际状态及启动配置为只读 |
| 结果标签 | 查看指标、方案、参数和结论；本地运行另显示退出码与耗时 |
| 日志标签 | 查看本次真实输出，运行中可停止 |
| 产物标签 | 查看该次运行的产物，打开文本预览；JSON 数值对象可显式导入为指标 |
| 环境与版本标签 | 查看启动时的解释器路径、参数、工作目录、平台、worktree、分支、Git 提交和变更文件列表 |
| 再次运行图标 | 使用原配置快照创建新运行；原记录保留，不覆盖历史 |

手动记录没有真实进程、日志或退出码，因此不提供这些执行标签。指标导入格式为 JSON 对象，例如 {"accuracy": 0.83, "loss": 0.12}；不会推测任意日志里的数字含义。

## 实验 Git 页面

| 入口 | 作用 |
| --- | --- |
| 更改 | 分开查看已暂存和未暂存文件；分别显示 HEAD → 暂存区、暂存区 → 工作区的文本差异 |
| 文件行的加减图标 | 暂存或取消暂存单个文件；不自动暂存其他修改 |
| 恢复图标 | 确认后用暂存区内容恢复文件，保留已暂存修改；差异变化、未跟踪文件和冲突不能直接覆盖 |
| 提交说明与 Commit | 仅提交已暂存文件；失败保留说明，切页、切项目、切 worktree 保留各自草稿，成功后清除已提交的说明 |
| 提交历史 | 查看最近 100 个提交，按说明、作者或 SHA 搜索，并查看所选 commit 的差异 |
| 分支 | 创建、切换、删除本地分支；不强制切换，不强制删除未合并分支 |
| Stash | 保存当前修改，可选择包含未跟踪文件；Apply / Pop 应用指定 stash，可能出现需要手动处理的冲突 |
| Worktree | 列出 Git 登记的目录、分支、磁盘变更和活动任务；创建、打开或移除 worktree，移除保留分支和 commit |
| 创建 Worktree 弹窗 | 默认建议数据目录内的独立目录，沿用标准 Git 分支；用户可以修改目标绝对路径 |
| 刷新 / 打开文件 | 重新读取 Git 状态；回到当前 worktree 的 Code 编辑所选文件 |
| 初始化 Git 仓库 | 非 Git 目录由用户显式初始化；托管目录不向上识别安装位置的父仓库 |

需要桌面版和 PATH 中的 Git。Git 缺失或仓库状态读取失败只影响 Git 页，已验证目录的 Code 编辑与运行仍可使用。当前不提供 clone、fetch、pull、push、merge、rebase、revert 或可视化冲突解决；历史只读取最近 100 条，二进制及大型文件没有文本差异。运行配置及 Python 选择属于实验，工作目录按实验根解析。打开另一 worktree 会选择或登记对应实验；删除已登记 worktree 前需先移除实验登记。

Git 写操作会检查目标目录的编辑草稿、文件读写、AI 与实验活动；有冲突时显示原因。不同 worktree 可以并行执行，同目录 AI 任务不会自动排队。已有会话绑定不随下拉框变化，另一目录需要新建或切换到绑定该目录的代码会话。新建代码会话提供 Git 状态工具与 Git 写入的内联审批，批准后调用与手动页相同的原生操作；旧会话保持历史及原有工具集合，需要新建会话使用新增 Git 工具。

## 运行边界

- 本地实验最多同时运行 8 个；浏览器预览禁用真实执行，不模拟成功。
- 窗口关闭前需停止后台任务并处理未保存内容。应用异常退出后的旧运行标记为已中断，不自动重新执行；这不是退出应用后继续运行的守护服务。
- 日志界面显示末尾最多 256 KiB，日志超过 64 MiB 会停止任务以保护磁盘；完整日志与执行记录保存在本机数据目录的 experiments 子目录；运行配置与结果注释沿用工作区保存。仅导出工作区 JSON 不包含运行目录和日志，完整备份需包含数据目录。
- Git 提交与变更清单不等于完整源码备份；再次运行复用配置，但执行当前磁盘代码，不承诺重现过去版本。
- Git 操作协调仅覆盖产品提供的入口和宿主工具；直接运行的 Python 文件及环境准备任务会阻止产品 Git 更换源码，空闲 shell 不锁死 Git。外部 IDE、终端和 AI 的任意 shell 命令不受这层操作锁强制约束。文件保存仍有版本冲突校验；可信手动执行使用本机权限，AI 使用 Codex 沙箱和审批。
- 托管代码存在关联 worktree 登记时，当前数据迁移会先拒绝并保留原位置；先移除关联 worktree，或将主仓库移到外部代码目录。尚未自动修复迁移后的 Git 链接。
- 终端最多保留 32 个，环境任务最多同时执行 8 个；终端保留最近 2 MiB 字节，环境任务日志界面显示末尾 2 MiB。应用退出后不恢复原 PTY 进程。
- 本轮不包含调试器、测试发现、Notebook 内核、远程执行、训练曲线或 GPU 资源调度；环境目录迁移后的重建仍待完善，不能保证搬移 venv 后全部脚本可用。Conda 创建入口调用真实命令，但完整联网创建尚需补验。长实验结束后不会自动发起模型请求。
