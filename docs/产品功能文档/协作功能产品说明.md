# Scientify 协作功能产品说明

状态（2026-11-02）：登录、同一账号多设备同步、项目成员与邀请已上线，服务部署在 `https://124.221.115.83:8443`。代码冲突对比、历史版本浏览和 Git 远程尚未提供。实现细节见[协作服务与同步技术方案](../技术方案/协作服务与同步技术方案.md)，验收记录见[更新记录](../更新记录/README.md)。

## 产品目标

协作功能让一个人在多台电脑上、或者多个人围绕同一个研究项目，共享文献、笔记和实验代码。Scientify 继续保持本地优先：论文阅读、AI、Python 环境和实验运行都在本机完成，服务器只负责账号、成员和同步。

## 登录

- **入口**：左下角“登录协作”、团队协作空间和“设置 → 协作”，打开的都是同一个全窗口登录页。
- **方式**：手机号加短信验证码。未注册的手机号验证后自动创建账号；同一号码 60 秒内只能获取一次验证码。
- **账号菜单**：登录后左下角显示部分隐藏的手机号，点开可以进入团队协作空间、打开协作设置或退出登录。退出后云端项目不再同步，本机项目和文件保留。
- **自托管**：自托管服务的地址在登录页的“使用自托管协作服务”里填写，也可以在“设置 → 协作”修改。

## 云端项目

- **创建**：在团队协作空间新建云端项目，或为个人项目“开启多设备同步”，项目 ID 不变。
- **在另一台设备上打开**：登录同一账号，在团队协作空间点“进入项目”。第一次同步会取回整个项目，文献放到“文档/Scientify/项目名”。
- **邀请成员**：项目所有者可以邀请编辑者、审阅者和查看者。邀请尚未注册的号码时会保留邀请，对方第一次登录后自动加入。

## 同步什么

| 内容                                           | 是否同步                                                               |
| ---------------------------------------------- | ---------------------------------------------------------------------- |
| 文献 PDF、论文笔记和笔记图片                   | 同步                                                                   |
| 代码目录中的文件                               | 同步；跳过 `.git`、虚拟环境、`node_modules` 等，以及超过 200 MB 的文件 |
| 项目笔记、项目信息、默认实验、运行记录         | 同步                                                                   |
| AI 对话、模型 Key、终端、Python 环境、个人项目 | 不同步                                                                 |

## 什么时候同步

- **自动**：打开云端项目时、每 30 秒、本机保存后约 3 秒。
- **手动**：“设置 → 协作”里可以对每个项目“立即同步”，并查看上次同步时间和最近的冲突。
- **断网**：照常阅读和编辑，恢复连接后自动补上。

## 冲突

- **同时修改**：两台设备改了同一内容时两份都保留。远端版本沿用原名，本机版本另存为“冲突副本”。
- **一边删一边改**：保留修改的那一份。
- **项目信息和默认实验**：以远端为准。

## 权限

| 角色           | 能修改的内容     |
| -------------- | ---------------- |
| 所有者、编辑者 | 全部             |
| 审阅者         | 只能改项目笔记   |
| 查看者         | 只接收，不能修改 |

只有所有者可以邀请或移除成员；成员可以自行退出项目。

## 尚未提供

- **冲突与历史**：代码冲突的对比视图，以及历史版本浏览。服务端已为每个文件和记录保留最近 20 个版本。
- **实验数据**：非默认实验（外部目录）的跨设备对应；运行日志与产物的选择性同步。
- **Git 远程**：推送、拉取和分支。
- **大文件**：分片上传。目前单个文件上限 200 MB。
