从这几个操作开始

  1. 切换书架与列表，打开一本研究札记。
  2. 切换 AI 和论文笔记，主阅读区域保持稳定。
  3. 点击“窄窗口”，观察资源栏收起和辅助浮层。
  4. 拖动辅助面板左边缘；聚焦分隔条后也可用方向键调整。
  5. 输入问题，体验模拟流式回复、中止与继续输入。
  6. 试试明暗主题、Ctrl/⌘ K 搜索和 Escape 关闭浮层。
