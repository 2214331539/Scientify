# 交互与动效

状态：确定的开发规则。当前已实现部分控件颜色过渡、主题图标过渡、设置弹窗进入和减少动态效果支持；其余场景按本文逐步实施。

## 1. 动效的作用

动效只解决三类问题：确认操作被接收、解释对象/区域变化、表达真实处理中状态。不为每次点击增加装饰，不让用户等动画才能工作。

业务状态决定界面，动画跟随状态。网络请求、保存、选择、关闭保护不能由 `animationend` 或定时器触发。不要把显示“成功”与实际写入混为一件事。

## 2. 固定参数

变量统一放入 `src/styles/tokens.css`。feedback/content/overlay/ease-standard 已接入主题图标和设置弹窗；其余变量及拟新增的 `src/styles/motion.css` 仍按需要实施。下表是完整规范值。

| 变量 | 值 | 用途 |
| --- | --- | --- |
| `--sf-motion-instant` | 0ms | 输入、滚动、拖动、选择、主题与语言切换 |
| `--sf-motion-feedback` | 100ms | 按钮和列表的颜色反馈 |
| `--sf-motion-content` | 120ms | 局部内容淡入、退出、折叠箭头 |
| `--sf-motion-overlay` | 160ms | 菜单、对话框进入 |
| `--sf-motion-panel` | 200ms | 辅助面板进入 |
| `--sf-ease-standard` | `cubic-bezier(0.2, 0, 0, 1)` | 进入、常规过渡 |
| `--sf-ease-exit` | `cubic-bezier(0.4, 0, 1, 1)` | 退出 |

默认位移：小浮层 4 px，辅助面板 8 px；普通按钮、导航文字、编辑正文位移为 0。常规界面过渡不超过 200ms；不得单独在页面写另一套时长或弹簧参数。

## 3. 场景契约

| 场景 | 立即发生的行为 | 允许的动效 | 禁止/注意 |
| --- | --- | --- | --- |
| 普通按钮 | 按下立即反馈；点击执行一次动作 | 背景/边界 100ms；释放恢复 | 不缩放文字，不下沉整行，不使用波纹 |
| 顶栏亮暗按钮 / 设置中的语言选择 | 状态即时切换并持久化；切换前提交根主题/语言，避免中间帧 | 主题图标局部 120ms 透明度/小角度旋转，按钮无持续底色；语言直接替换文字 | 不全页渐变、不重挂载编辑器、不让弹窗随文案缩放 |
| 一级/二级导航 | 立即更新选中和目标内容 | 普通信息区最多一次 120ms 淡入 | 外壳不移动；代码/PDF/笔记编辑区不做进出位移 |
| 文件标签切换 | 恢复对应会话、选区、滚动 | 标签底色 100ms；正文直接切换 | 不交叉创建两份编辑器；不动画化光标与选区 |
| 资源列表/表格 | 焦点与选中即时改变 | 行背景 100ms | 排序/筛选不逐行飞入；不按行数累积延迟 |
| 文件树展开 | 子节点立即可访问，保留当前焦点 | 箭头旋转 120ms | 不对大子树逐项动画；不让展开触发文件打开 |
| 右侧 AI/笔记面板 | 提交最终布局，面板可操作 | 面板自身淡入 + 向内 8 px，200ms；退出最多 120ms | 不逐帧改变外壳宽度来反复触发 PDF/CodeMirror 重排 |
| 面板拖拽 | 跟随指针或键盘调整 | 无过渡 | 拖动中不插值、不延迟、不加惯性；结束再持久化布局 |
| AI/笔记工具切换 | 切换可见工具，保留各自草稿 | 标题/工具按钮颜色反馈 | 不因为切换工具而新建会话或清空输入 |
| 非模态菜单 | 展开后可立即导航，Escape/外部点击关闭 | 进入 160ms：透明度 + 4 px；退出 120ms | 禁止从 trigger 缩放放大；焦点返回触发按钮 |
| 对话框 | 建立模态范围并定位焦点 | 遮罩淡入、对话框透明度 + 4 px，160ms | 不扩大缩小表单；确认/取消逻辑不等动画 |
| Tooltip | 悬停约 250ms 后显示，键盘焦点立即显示 | 可只淡入 100ms | 延迟属于触发规则，不作为请求或动画延迟通用值 |
| 本地保存 | 更新真实 dirty/pending/error/saved | 状态文字或小指示器更新 | 不为每次自动保存弹 toast；失败保留草稿 |
| 原生窗口交接 | Workspace 载入后才显示并隐藏 Projects | 交给 Windows 原生窗口行为 | 不给整个 WebView 缩放/飞入；超时返回 Projects |

辅助面板退出时可保留一个无交互的短暂视觉容器，但其关闭状态、焦点和可访问树立即更新。该容器不能复制一份可编辑会话。若退出实现会破坏现有 `hidden`/会话保护，首轮只做进入效果，退出直接关闭。

## 4. 状态机与异步反馈

```text
idle → 用户操作 → pending → success → idle
                         ↘ error → 用户重试 → pending
```

- 接收到操作的视觉反馈目标在 100ms 内出现；这是待测量的验收预算，不是已达成的性能声明。
- 执行时间未知时立即显示局部 pending/禁用重复提交。可在超过 150ms 后再显示 spinner，短任务无需闪出再消失的旋转图标。
- 后端完成时立即结束 pending，不为了“完整播放”而强制等待最短动画时间。
- 超过 1 秒仍未完成时提供明确文字；只有真实可中止的任务才提供取消。当前 AI 尚不支持取消，不添加无效取消按钮。
- 能量化的任务显示真实进度；不能量化时不伪造百分比或倒计时。
- 保存错误就近显示并保留输入。重复点击、快速切换项目后的旧响应不能覆盖新状态。
- 稳定空列表直接展示空态；不要对已缓存内容先清空再闪一次 skeleton。

## 5. 中断、焦点与草稿

连续点击导航时以最后一次有效目标为准，旧过渡取消或被替换，不排队播放。重复点击当前入口不重置滚动、读取文件或再次播放页面动画。

键盘焦点独立于选中项。使用方向键浏览树不自动打开文件；用户正在输入时不能因后台刷新抢走焦点。关闭菜单/弹窗后回到触发控件；关闭辅助栏后回到对应的底栏右下角图标按钮。入口已不存在时回到最近的有效区域标题或导航。

编辑缓冲、选区和撤销历史归现有会话；动画组件只处理可见性，不改变资源 key，不为播放进入效果而强行卸载再挂载整个工作区。文献分页取消旧渲染任务的逻辑必须保留。

## 6. 减少动态效果

沿用 `prefers-reduced-motion: reduce`，静态状态和操作反馈必须完整可用：

- 取消位移、缩放、淡入淡出、平滑滚动和旋转；直接到达最终状态。
- 处理中仍显示文字与可访问状态，不依赖旋转图标表示正在工作。
- hover、选中、焦点可以立即变色；不能连反馈一起消失。
- 保留已有 Tooltip 触发策略和业务自动保存防抖；它们不是应清除的装饰动画。
- 任何关闭/保存/清理逻辑在没有 transitionend 的情况下仍必须完成。

当前 `src/styles.css` 已有全局减少动态效果规则。后续 motion 样式不得通过更高优先级重新开启它。

## 7. 实现边界与性能

普通效果优先 CSS transition/keyframes；只有确实需要可取消的命令式时序时使用 Web Animations API。当前不引入 Framer Motion、GSAP 或全页转场库。

- 明确写出过渡属性；禁止 `transition: all`。
- opacity/transform 优先用于浮层，颜色用于小控件。编辑器 DOM、PDF canvas 和整个中央容器不做 transform 动画。
- 不动画化大区域 width/height、box-shadow、滤镜或模糊；不长期给所有节点设 `will-change`。
- 不在 RAF 中写业务 store、发 IPC、保存偏好或触发 React 全树更新。
- 大列表和文本层不加 stagger，不保留多个隐藏副本做过渡。
- 动效帧预算以目标机器 60Hz 下约 16.7ms 为参考。验收记录硬件、内容规模和实际现象，不把“使用 transform”当作性能已合格的证据。

## 8. 不采用的效果

页面整块滑动、卡片悬浮上升、按钮弹跳、AI 图标持续呼吸、无业务目的的循环渐变、全页模糊、文字逐字出现、光标追随光效，以及让研究内容漂移的弹簧动画。
