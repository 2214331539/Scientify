# 交互与动效

版本：1.4 · 2026-10-05。适用 Projects / Workspace 两个窗口。用户已选定 D 柔和方案。参数来源：[motion.ts](../../src/platform/motion.ts)；场景控制：[view-transition.ts](../../src/platform/view-transition.ts)；样式：[motion.css](../../src/styles/motion.css)。

## 1. 统一原则

采用接近 Apple 原生工具的短反馈、柔和减速与清晰层级。动画解释状态变化，不抢占研究内容。按钮、菜单、选择器、弹窗与辅助栏复用同一组变量，不在页面单独定义时长。

- 业务状态先更新；保存、删除、切换不等待动画结束。
- 页面在原位重叠交叉淡化，旧画面托底；浮层原位淡入淡出。正文不位移、缩放或模糊。
- 不引入动画框架，不增加循环装饰、弹跳、波纹、逐项飞入。
- 拖动、输入、光标、滚动、语言替换即时响应。

## 2. 参数

| Token                                             | 值                               | 用途                       |
| ------------------------------------------------- | -------------------------------- | -------------------------- |
| `--sf-motion-feedback`                            | 140ms                            | 控件 hover / pressed、边框 |
| `--sf-motion-content`                             | 220ms                            | 图标、树箭头、局部信息淡入 |
| `--sf-motion-navigation`                          | 320ms                            | 页面交叉淡化               |
| `--sf-motion-selection`                           | 220ms                            | 选中指示条                 |
| `--sf-motion-overlay`                             | 220ms                            | 菜单、对话框、选择器进入   |
| `--sf-motion-panel`                               | 240ms                            | AI / 笔记辅助层透明度      |
| `--sf-motion-exit`                                | 180ms                            | 菜单退出的纯视觉保留       |
| `--sf-motion-layout`                              | 320ms                            | 现有布局模式反馈           |
| `--sf-ease-standard` / `enter` / `exit` / `apple` | `cubic-bezier(0.42, 0, 0.58, 1)` | 同一缓入缓出曲线           |

`applyAppearance` 在首次绘制前将同一份参数安装为 CSS 变量；JS 切页控制器直接使用该配置。页面与浮层位移均为 0px。普通按钮、导航文字和编辑正文不位移。控件圆角 4px，菜单与弹窗圆角 8px；明暗主题共用语义颜色、细边框和浮层阴影。

## 3. 组件契约

| 场景                        | 行为与动效                                                                                                                                                                                                                                                 |
| --------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Button / 导航 / 资源行      | 140ms 背景与边框反馈；按下即时加深，disabled 不执行动作；不缩放文字                                                                                                                                                                                        |
| 工作区切页                  | React 状态即时提交；共享 ViewTransition 保留真实 DOM，320ms 交叉淡化，保持不透明底层。快速反向或转到第三页时从当前透明度与层级继续；退出层立即 inert / aria-hidden，完成后隐藏。原生网页在过渡期间隐藏，结束后由当前活动页恢复                             |
| 网格 / 列表                 | 同一选中底板移动；书架与实验管理内容使用同一 320ms 交叉淡化；点击当前模式不重放                                                                                                                                                                            |
| 亮暗切换                    | 根主题即时切换；太阳/月亮局部透明度与旋转 220ms；图标按钮无常驻底色                                                                                                                                                                                        |
| 语言                        | 即时替换界面文案；不重建编辑器或弹窗，不动画化全页尺寸                                                                                                                                                                                                     |
| Dropdown                    | 继续使用原生 select。支持 `appearance: base-select` 的 Chromium 使用统一 picker 皮肤、箭头旋转与进入/退出过渡；旧 WebView2 回退平台选择器，不影响功能                                                                                                      |
| Menu                        | 使用共享 Menu；进入 220ms，退出 180ms，均为原位透明度变化。退出立即 `inert` / `aria-hidden`，操作立即执行；快速重开取消旧清理计时，不保留第二份编辑会话                                                                                                    |
| Modal / 确认 / 文本输入弹窗 | 同一 HTML dialog、遮罩、尺寸规则与 220ms 原位进入；关闭与保存完成即时生效。本轮不保留已卸载表单来播放退出动画                                                                                                                                              |
| Tooltip                     | 指针停留 250ms 后显示，键盘焦点立即提示；140ms 淡入；Escape 关闭                                                                                                                                                                                           |
| TreeView                    | 同一个箭头旋转 220ms；子树立即可用，不逐项动画                                                                                                                                                                                                             |
| 实验详情 / AI 执行记录      | 复用原生 details/summary 与 Lucide 箭头；箭头旋转 220ms，正文立即可用，支持键盘和可见焦点                                                                                                                                                                  |
| AI / 笔记辅助栏             | 共用固定顶栏；选中下划线移动 220ms，保留的内容层淡化 240ms。退出层立即 inert / aria-hidden；不卸载会话、不重置滚动位置、不对正文位移或缩放。开关与宽度立即生效，避免 PDF/CodeMirror 连续重排。笔记进入或离开中央区时加入页面切换控制器，始终使用同一编辑器 |
| PDF / 代码 / 笔记           | 一级工作区与代码/实验管理/Git/运行记录切换保留编辑实例；文件或 PDF 标签仍由原编辑会话管理，不为动效复制第二份正文                                                                                                                                          |
| 窗口交接 / 文件选择器       | 继续由 Windows / Tauri 管理；不为原生系统对话框注入网页皮肤                                                                                                                                                                                                |

全站自定义确认和文本输入使用 [prompts.tsx](../../src/components/prompts.tsx)；脏表单确认由 Modal 内的同款嵌套对话框负责。网页退出的 `beforeunload` 提示仍由浏览器负责。

## 4. 焦点与中断

- 菜单支持方向键、Home / End；跳过禁用项。Escape / Tab 关闭并恢复触发点；点外部让目标接收焦点，不抢回原按钮。
- 右键和 Shift+F10 使用相同菜单；浮层根据视口边缘限制位置，内部可滚动。页面滚动、窗口失焦或大小变化时关闭。
- 菜单打开即隐藏原生文献网页，继续使用 `data-native-overlay` 协议；菜单退出不留下透明点击层。
- Modal 保留焦点圈定、Escape 和 busy / dirty 保护；点击遮罩与关闭按钮走相同保护，拖拽释放不误判为点遮罩。
- 原生窗口连续关闭请求合并处理；等待确认期间不重复提交退出。保存失败保留表单和错误，允许重试。
- 异步操作显示真实 pending / error；不为“播完动画”延迟成功，不伪造进度，不清空草稿。

## 5. 减少动态效果与性能

`prefers-reduced-motion: reduce` 禁用 transition、animation 和平滑滚动，包括 dialog backdrop、select picker 与箭头伪元素。页面直接切换；运行中开启减少动态效果时立即收敛到最新目标。菜单即时退出，业务防抖与 Tooltip 触发延迟保持。保存、任务和关闭保护不依赖动画完成。

禁止 `transition: all`、全页 blur、持续 will-change、逐帧写 store、宽高动画、对大量列表项的 stagger。切页只动画 opacity，结束或取消后释放临时合成提示。320ms 是动效长度，不是 FPS 或整站性能达标声明。缓存只覆盖访问过的视图；切换项目或重载数据时清理中央视图缓存，AI/笔记保持原有项目隔离机制。

## 6. 新功能接入

1. 从 Button / Input / Dropdown / Menu / Modal / Tooltip 组合交互；不要新写一套菜单皮肤。
2. 状态属于业务，浮层只处理位置、可见性、键盘和视觉保留。
3. 页面切换复用 [ViewTransition](../../src/components/workspace/ViewTransition.tsx)；列表模式使用 `sf-view-stack--flow` 保留内容的自然高度。全局快捷键、材料上下文和原生窗口显隐读取 `useActiveView`，隐藏页面不响应前台操作。
4. 按 [开发与验收](04-开发与验收.md) 检查快速操作、明暗、中英、焦点、失败恢复与 reduced motion。
