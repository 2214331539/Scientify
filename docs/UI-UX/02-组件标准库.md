# 组件标准库

以现有本地组件作为标准库。本文建立契约和扩展规则，不创建另一套平行 UI 框架。

## 1. 分层

| 层 | 目录 | 职责 |
| --- | --- | --- |
| 设计变量 | `src/styles/` | 颜色、尺寸、字体、动效变量 |
| 基础控件 | `src/components/primitives/` | 按钮、输入、选择、提示、状态标签 |
| 布局与导航 | `src/components/layout/`、`navigation/` | 外壳、面板、顶栏、工作区导航 |
| 工作区结构 | `src/components/workspace/` | 分区、资源列表、活动、树、资源区组合 |
| 业务组件 | `src/features/`、`src/workspaces/` | 项目、文献、实验等具体规则 |
| 编辑宿主 | `src/editor/`、`src/reader/` | 编辑会话、CodeMirror、PDF 渲染与交互 |

共享控件不直接读写研究 store、磁盘或模型服务。页面传入状态和回调；显示层不决定保存成功，也不自行创建第二个编辑会话。

## 2. 现有组件与使用契约

| 组件 / 源码 | 使用场景与接口 | 必须满足的行为 |
| --- | --- | --- |
| [Button / IconButton](../../src/components/primitives/Button.tsx) | `variant=primary/secondary/ghost`，`size=sm/md`，原生属性、ref、tooltip | primary 用于主要提交；工具栏用 ghost。表单中明确 type；disabled 不执行动作；图标必须有双语可访问名称和提示 |
| [Input / Textarea](../../src/components/primitives/Input.tsx) | 短输入、表单、轻量笔记；value/onChange 或原生输入契约 | 保留选区与输入法组合；校验错误就近呈现并关联输入；占位符不代替标签 |
| [Dropdown](../../src/components/primitives/Dropdown.tsx) | 原生 select，支持统一 picker 的渐进增强 | 键盘行为跟随平台；存储 value 不随翻译改变。不是任意动作菜单 |
| [Tooltip](../../src/components/primitives/Tooltip.tsx) | 图标含义、快捷键、禁用原因 | 鼠标延迟提示，键盘焦点立即可读，Escape 关闭；不承载唯一操作或必读错误 |
| [Badge](../../src/components/primitives/Badge.tsx) | 草稿、进行中、已完成等真实状态 | 不作为数量、分类或装饰容器；状态色必须有文字 |
| [Panel](../../src/components/layout/Panel.tsx) | 连续工作区，header/toolbar/footer 槽位 | 控制区域与滚动，不自行查询数据；不是有阴影的大卡片 |
| [Section](../../src/components/workspace/Section.tsx) | 内容分组、标题与局部操作 | 使用合理标题层级，保持正文对齐，不重复整个页面说明 |
| [ResourceList / ResourceRow](../../src/components/workspace/ResourceList.tsx) | 文献、笔记等资源集合 | Row 为 `li > button`，放入 List；禁止按钮中再嵌按钮。复杂多操作行使用语义列表项及并列按钮 |
| [TreeView](../../src/components/workspace/TreeView.tsx) | 项目文件层级 | 受控选中/折叠；方向键/Home/End 移动焦点，Enter 打开；焦点和选中分开 |
| [DocumentTabs](../../src/components/workspace/DocumentTabs.tsx) | 文献等文档标签，受控 tabs/activeId/onSelect/onClose/onNew | 左右键/Home/End 切换，Delete 关闭当前标签；关闭仅触发回调，不删除资源；新增/关闭后恢复有效焦点 |
| [ActivityList](../../src/components/workspace/ActivityList.tsx) | 最近研究活动 | 使用真实时间和来源；语言切换不修改记录 |
| [WorkspaceFrame](../../src/components/workspace/WorkspaceFrame.tsx) | 二级导航、资源区、内容区 | 工作区切换不拥有或清空编辑会话；选中状态即时更新 |
| [Modal](../../src/components/Modal.tsx) | 编辑项目、设置、确认等阻塞任务 | 沿用 HTML dialog；处理焦点、Escape、busy 与 dirty；关闭须经过业务保护 |
| [ResizeHandle](../../src/shell/ResizeHandle.tsx) | 面板宽度调整 | 拖动实时跟随；键盘可调；双击恢复默认；触及边界不挤坏正文 |
| [ContextPanel / Composer](../../src/components/ai/ContextPanel.tsx) | 项目上下文和 AI 输入 | 明确材料范围；快捷动作只准备问题，实际发送由用户触发 |

独立组件说明和代码例子可查 [Workspace UI](../../src/components/README.md)。共享 [Menu](../../src/components/primitives/Menu.tsx) 接收 `anchor / label / children / onClose`，只负责定位、键盘、关闭和退出视觉保留；项目与文献菜单均已迁移。确认和文本输入使用 [prompts](../../src/components/prompts.tsx) 的 `confirmAction / requestText`，返回 Promise，取消为 false / null。尚无 Toast、Skeleton 或 Storybook；按实际需要增量补充。

## 3. 每个组件都要定义的状态

| 状态 | 定义 | 反馈 |
| --- | --- | --- |
| default | 可操作、未选中 | 基础样式 |
| hover | 指针悬停 | 轻微背景/边界变化，不改变几何尺寸 |
| focus-visible | 键盘导航到达 | 明确焦点环；不可用去除 outline 代替设计 |
| pressed | 指针/键盘按下的瞬时状态 | 比 hover 更明确的底色，松开即结束 |
| selected / expanded | 持续选择或展开 | aria-current/selected/expanded 与真实状态一致；不能等动画结束才更新 |
| disabled | 动作当前不可用 | 使用原生禁用能力和可理解原因；不得只设 pointer-events |
| pending | 动作执行中 | 阻止重复提交、局部状态、保持按钮宽度；不锁死无关区域 |
| error | 失败且可恢复 | 保留输入，显示原因和重试；不抖动整个页面 |
| success | 后端已确认 | 更新对象状态；普通保存不弹全屏成功反馈 |

这些是行为契约，不要求每个组件都暴露同名 props。当前 Button 没有 `loading` 属性：调用方先用 `disabled + 状态文字`，若后续抽象共享 PendingButton，需标注新接口并迁移调用方。

## 4. 新组件的完成定义

新增组件时必须写清以下内容，可放在相邻说明或开发记录中：

```text
名称、职责、适用和不适用场景
输入 props、回调、受控状态及状态所有者
default / hover / focus / pressed / disabled / pending / error
键盘、焦点、Escape、可访问名称
空态、长内容、明暗、中英、减少动态效果
使用示例、失败/快速操作验证、未实现限制
```

先查现有组件；已有表现可通过组合实现时不新增同类组件。复杂的新通用行为优先抽共享层，页面 CSS 只处理排列和业务内容，不重定义控件皮肤。第三方编辑器内部 DOM 不受“必须使用 Button/Input”约束。

## 5. 组件展示与版本

后续建立本地开发专用的组件样例入口，集中演示上述状态；运行版不显示该入口。先覆盖 Button、输入、列表、弹窗、侧栏，再决定是否需要 Storybook。此入口本轮尚未实现。

接口变更同时更新调用方、对应契约和行为验证。破坏兼容的改动需说明替代方式；普通样式调整不需要增加流程审批或修改无关业务。
