# Scientify 整体重设计方案

2026-11-13 · 第三版（已定稿，开始重构）· 交互原型：[演示/整体重设计/index.html](演示/整体重设计/index.html)（本地直接打开，数据为虚构）

第二版按评审意见调整结构：保留项目中心作为入口；去掉首页和概览；每个项目只有文献、笔记、实验、写作四个模块，侧边栏一次只显示当前项目；AI 和笔记从右侧打开。

第三版（11-13 定稿）再做减法：去掉收集箱和收藏；标题栏不再显示同步状态和运行中的任务；去掉页面上的说明小字和快捷键提示。同时定下：合成一个窗口；写作先复用现有文件编辑器做稿件；默认配色“石墨”。

## 一、为什么现在显得不成熟

- **结构是拼起来的**：项目中心和项目工作区是两个窗口、两种外观；项目里又是图标栏加资源侧栏两列，用户不知道自己在哪一层。
- **入口没有轻重**：每页的按钮、标签、说明一样醒目，找不到“这里最该做什么”；低频操作和高频操作挤在同一排。
- **重要性被压平**：字号和留白差不多，标题、正文、元数据看不出层级；靠卡片和边框分区，页面像表单集合。
- **颜色没有职责**：封面彩色、强调色、状态色混用，每种颜色都在抢注意力。
- **交互缺少“手感”**：没有悬停才出现的行内操作、右键菜单、键盘浏览和可撤销提示。

## 二、设计原则

- **两级结构**：项目中心选项目，项目里做事。侧边栏只显示当前所在的那一级，不把每个项目的模块重复列出来。
- **每页一个主操作**：一个实心按钮放主操作，最多两三个次要按钮，其余放进“⋯”和右键菜单。
- **内容优先，工具退后**：论文、表格、代码、正文占据主区；工具在悬停、选中或按快捷键时出现。
- **颜色只表达状态**：界面用黑白灰和排版层级区分重要性；绿、黄、红、蓝只用在“完成、注意、失败、运行中”上。
- **键盘可达，操作可撤销**：Ctrl K 找一切、Ctrl J 叫 AI；删除、移动给“撤销”，不弹确认框。

## 三、信息架构

### 窗口结构

一个窗口，侧边栏随所在层级切换内容。

| 区域   | 项目中心                                                 | 项目里                                                                             |
| ------ | -------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| 标题栏 | 标志（回到项目中心）、后退前进、位置、搜索、通知           | 同左，另有：共享、笔记、AI                                                         |
| 侧边栏 | 我的项目、团队项目；账号、帮助、设置                     | 返回项目中心、项目切换器；文献、笔记、实验、写作；当前模块的资源；账号、帮助、设置 |
| 主区   | 当前页面                                                 | 当前模块的页面；文献的论文和网页用标签页                                           |
| 右侧栏 | 无                                                       | AI 助手、笔记（阅读时是这篇论文的笔记）                                            |

### 页面层级

| 层级     | 页面                                                                                                         |
| -------- | ------------------------------------------------------------------------------------------------------------ |
| 项目中心 | 我的项目（书架 / 列表）、团队项目                                                                            |
| 项目模块 | 文献、笔记、实验、写作，位置固定，不随项目变化                                                               |
| 模块资源 | 文献：文献库 / 订阅、分组、文件夹；笔记：全部、论文笔记、标签、回收站；实验：实验列表；写作：稿件、参考文献 |
| 详情     | 论文阅读、内置浏览器、笔记编辑、实验的运行 / 代码 / 版本 / 环境、稿件编辑                                    |
| 浮层     | 搜索与命令、设置、项目切换、共享（含同步）、通知、右键菜单                                                   |

### 去掉的页面，内容去了哪里

| 原来                   | 现在                                                            |
| ---------------------- | --------------------------------------------------------------- |
| 首页 · 最近项目        | 我的项目默认按最近打开排序                                      |
| 首页 · 继续工作        | 进入项目回到上次的位置；Ctrl K 打开时先列最近的论文、笔记、实验 |
| 首页 · 待处理          | 标题栏的通知；新邀请在团队项目页顶部                            |
| 概览 · 项目设置        | 项目切换器里的“项目设置”                                        |
| 概览 · 成员、同步      | 标题栏的“共享”；同步失败和冲突进通知                            |
| 状态栏 · 后台任务      | 实验列表里的运行状态点；运行页签                                |
| 收集箱                 | 去掉；AI 和笔记只在项目里用，已有的收集箱数据保留在数据里不删   |
| 收藏的项目             | 去掉；我的项目按最近打开排序                                    |
| 状态栏 · AI 和笔记开关 | 标题栏右侧                                                      |

### 和现在界面的对照

| 现在                                                          | 改后                                                                                 |
| ------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| 项目中心、项目工作区两个窗口                                  | 一个窗口，侧边栏两级                                                                 |
| 图标栏 + 资源侧栏两列                                         | 一列带文字的侧边栏：上面四个模块，下面是当前模块的资源                               |
| 文献目录树里同时列文件夹和 PDF                                | 侧边栏只放分组和文件夹；论文在主区表格，右边是论文信息                               |
| 实验的二级图标栏：实验管理、代码、搜索、Git、运行、任务、环境 | 侧边栏列出实验；主区四个页签：运行、代码、版本、环境；搜索在文件树上，任务在标题栏 |
| 彩色书本封面                                                  | 保留书本封面，改成低饱和中性色                                                       |
| 概览、写作是占位页                                            | 去掉概览；写作先用现有文件树和编辑器管理稿件                                         |

## 四、每页给用户的入口

| 页面        | 用户来做什么                   | 主操作             | 次要操作                                                  | 放进菜单和右键                                         |
| ----------- | ------------------------------ | ------------------ | --------------------------------------------------------- | ------------------------------------------------------ |
| 我的项目    | 找项目、接着做                 | 新建项目           | 进行中 / 已归档、排序、书架 / 列表                        | 项目设置、共享、同步、显示文献文件夹、归档、删除       |
| 团队项目    | 处理邀请、打开团队项目         | 新建团队项目       | 共享本机项目；邀请行的“下载并打开”                        | 同上；点成员头像看成员和角色                           |
| 文献库      | 找论文、开始读                 | 导入               | 问这些论文、搜索、按状态 / 年份 / 标签筛选                | 阅读、问 AI、复制引用、移动、收藏、移到回收站          |
| 阅读        | 读、划重点、摘录、问 AI        | 选中文字后的工具条 | 目录、页码、缩放、查找                                    | 专注阅读、导出标注                                     |
| 订阅        | 看新论文，挑出值得读的         | 新建订阅           | 管理订阅、全部标为已看；每行“存入文献库”                  | 在内置浏览器中打开、不感兴趣                           |
| 内置浏览器  | 在网站上找论文                 | 存入文献库         | 后退、前进、刷新                                          | 在系统浏览器中打开                                     |
| 笔记        | 写判断，引用来源               | 新建笔记           | 让 AI 处理、搜索                                          | 复制链接、移到其他项目、导出、移到回收站               |
| 实验 · 运行 | 看结果，决定下一步             | 运行（可选配置）   | 终端                                                      | 对比、写进笔记、重新运行、删除                         |
| 实验 · 代码 | 改代码、跑命令                 | 运行               | 文件树、搜索、终端 / 输出 / 产物                          | 在 VS Code 中打开、问 AI                               |
| 实验 · 版本 | 看改动、提交                   | 提交               | AI 写说明、拉取、推送                                     | 分支、Stash、Worktree                                  |
| 实验 · 环境 | 配 Python 和依赖               | 安装包             | 切换解释器、按 requirements.txt 安装                      | 更新、卸载                                             |
| 写作        | 写稿件，插入引用和结果         | 编译               | 插入引用、插入结果                                        | 导出                                                   |
| 参考文献    | 检查引用是否都在文献库         | 从文献库添加       | 导出 BibTeX；缺失行的“查找”                               | —                                                      |

阅读页选中文字后出现一条工具条：**高亮、摘录到笔记、问 AI、翻译、复制引用**。这是阅读时最高频的动作，所以不藏在菜单里。

## 五、全局交互

- **Ctrl K（⌘K）**：在当前项目里搜论文、笔记、实验，也能跳到其他项目；输入“>”只看命令。
- **Ctrl J（⌘J）**：打开或关闭 AI。AI 自动带上当前对象（论文和页码、实验和运行、代码文件、稿件），每个对象是一枚可以去掉的标签。
- **进入项目回到上次的位置**：第一次打开进入文献。
- **悬停出现行内操作，右键出现完整菜单**：列表不常驻按钮。
- **键盘浏览**：文献表格里 ↑↓ 选择、Enter 阅读、Space 显示或隐藏论文信息。
- **撤销代替确认**：删除笔记、移走论文后底部出现“撤销”；只有不可恢复的操作才确认。
- **空间不够时依次退让**：先收起论文信息，再把运行详情变成浮在表格上的抽屉；更窄时代码页收起文件树、写作页收起预览。按主区实际宽度判断，不按屏幕尺寸。
- **AI 的过程收起来**：读了哪些页、调用了什么工具折叠成一行；需要审批时在对话里出现审批卡。

## 六、视觉规范

### 颜色

三套配色共用同一组变量和层级，设置里可以切换；默认“石墨”。

| 变量   | 石墨（默认）                                   | 纸              | 夜             | 用途                         |
| ------ | ---------------------------------------------- | --------------- | -------------- | ---------------------------- |
| shell  | #F4F4F5                                        | #F1EFEA         | #0E0E10        | 标题栏、侧边栏               |
| canvas | #FFFFFF                                        | #FCFBF8         | #151517        | 主区                         |
| text   | #18181B                                        | #1D1B18         | #EDEDEF        | 标题、正文                   |
| text-2 | #52525B                                        | #5C574F         | #A3A3AB        | 说明、次要文字               |
| text-3 | #8B8B93                                        | #8F897E         | #6F6F78        | 时间、计数、元数据           |
| line   | 黑色 8% 透明                                   | 暖棕 10% 透明   | 白色 7.5% 透明 | 分隔线                       |
| accent | #18181B                                        | #23466F（墨蓝） | #EDEDEF        | 主按钮、选中                 |
| 状态   | 绿 #2F7D4F、黄 #A5650E、红 #C0392B、蓝 #3B5BDB | 同左            | 提亮的同色系   | 只用于状态点、Git 标记和差异 |

- **标志**：沿用现在的黑白“开箱”标志，放在标题栏左上角，点击回到项目中心；不用品牌色。
- **项目封面**：保留书本封面，改用低饱和中性色（石板、灰褐、灰绿等），封面上是项目名、方向和研究问题。
- **PDF 和网页保持纸色**：深色主题下不反色。

### 字体与字号

| 角色         | 字号 | 字重 | 用在哪里               |
| ------------ | ---- | ---- | ---------------------- |
| 文档标题     | 28px | 650  | 笔记标题               |
| 页面标题     | 22px | 600  | 我的项目、文献库等     |
| 区块标题     | 13px | 600  | “新邀请”“已安装的包”等 |
| 正文（阅读） | 15px | 400  | 笔记正文，行高 1.75    |
| 界面正文     | 13px | 400  | 列表、菜单、按钮       |
| 元数据       | 12px | 400  | 时间、作者、计数       |

- 界面字体：系统无衬线（Windows 用 Segoe UI 和微软雅黑，macOS 用苹方）；论文正文用衬线体；代码和数字用等宽。
- 间距以 4px 为单位：行内 8，区块之间 32，页面边距 40。
- 圆角：控件 6–7px，浮层 10px，对话框 12px。
- 阴影只给浮层和书本封面；页面里用背景层次和细线，不用投影卡片。

## 七、和 11-12 方案的关系

- **保留**：阅读区优先、面板依次退让、动效分工（反馈 120ms、面板 200ms）、AI 与笔记共用右侧栏。
- **改变**：两个窗口合成一个；绿色强调去掉；每页入口按“主操作 / 次要 / 菜单”重新分配。

## 八、落地顺序

| 阶段 | 内容                                                                                                        | 估计   |
| ---- | ----------------------------------------------------------------------------------------------------------- | ------ |
| 1    | 设计变量换成三套配色；字号、间距、按钮、列表、菜单统一成新规范                                              | 3–4 天 |
| 2    | 一个窗口的外壳：标题栏、两级侧边栏、项目切换器、Ctrl K、Ctrl J；去掉首页、概览和状态栏                      | 5–7 天 |
| 3    | 项目中心（书架、团队项目）；文献（分组与文件夹进侧边栏、表格、论文信息、标签页、订阅）              | 6–8 天 |
| 4    | 笔记；实验（侧边栏实验列表，运行 / 代码 / 版本 / 环境四个页签）；设置、共享、同步与通知浮层；右键菜单与撤销 | 6–8 天 |
| 5    | 窄窗口、键盘、无障碍、Mac 原生标题栏验收                                                                    | 2–3 天 |

写作模块现在是占位页，按这份设计另排开发，不在上面五个阶段里。

阶段 2 的“合成一个窗口”改动最大：现在的两个 Tauri 窗口、启动和单实例逻辑都要调整。也可以先保留两个窗口，只换外观，之后再合并。

## 九、已定事项（11-13）

- **合成一个窗口**：项目中心和项目在同一个窗口切换。
- **默认配色**：石墨；纸、夜在设置里切换，跟随系统时深色用夜。
- **启动时打开**：项目中心；设置里可改成上次的项目。
- **写作**：先复用实验代码页的文件树和编辑器管理 .tex、.md 稿件；编译、插入引用以后再加。
- **去掉**：首页、概览、收集箱、收藏、状态栏，以及标题栏的同步状态和运行中任务。
