# 视觉与布局

状态：新开发采用的固定基线；数值依据当前代码，新增变量需在实施时落到源码。

## 1. 外壳

- Projects 为独立窗口，默认 1100 × 740，最小 800 × 560；左侧是个人/团队空间，中央是项目集合。
- 项目中心按 2026-11-05 验收的[项目中心原型](../产品设计/演示/项目中心原型.html)实现：左侧是品牌、搜索入口、首页、我的项目、团队项目、收集箱和收藏的项目；每页的标题和主要操作在同一行，Windows 的窗口控制在这一行最右边。背景纯白，不用点阵。项目用书本封面：封面颜色来自项目设置，文字按背景亮度选择可读颜色，书签角标表示收藏，云朵表示多设备同步。我的项目有筛选（全部、收藏、多设备同步、已归档）、排序和书架/列表切换，已归档的项目默认隐藏。团队项目是表格加右侧详情。左下角是账号、帮助和设置：未登录显示“登录”并打开全窗口登录页；登录后的账号菜单含团队项目、同步与协作设置、外观、退出登录。样式在 `src/features/projects/project-library.css`。
- Workspace 打开时最大化，最小 1000 × 680；左侧 Rail、中央工作区、按需展开的右侧辅助面板保持固定职责。
- 一级入口为概览、文献、笔记、实验、论文五个。Files 入口及独立文件页面直接移除；实验与论文继续共享文件编辑能力。文献订阅归文献；论文预览归中央内容。
- Workspace 顶栏只有一行：品牌、项目切换、亮暗切换、原生窗口操作。AI/研究笔记以纯图标放在底栏右下角，替代原当前位置说明。语言放在设置的“通用”中；无常驻全局搜索框，局部资源搜索保留在所属工作区。Projects 使用上一条独立布局。
- AI 默认关闭。打开辅助面板不切换中央工作内容；笔记中央入口和侧栏复用同一编辑会话。
- 文献区不使用横跨内容的工作区标题栏及资源收缩按钮：文献库/订阅位于左侧边栏顶部，导入、搜索、筛选和文献信息也在左侧。右侧仅保留文档标签与呈现区域，PDF 翻页/缩放使用浮动阅读控件；订阅切换为个人信息源边栏，中央是内置浏览器标签。
- 不使用入口卡片、彩色模块图标、营销式大标题。列表、树、面板、编辑器是主要结构。

## 2. 尺寸与密度

单位为 CSS px，适用于默认字号；系统缩放不另行按物理像素计算。

| 项目 | 基准 | 说明 |
| --- | --- | --- |
| 顶栏 | 44 | 全局保持单行 |
| 工作区标题/标签行 | 40 | 使用 `--sf-header-height` |
| 局部工具栏 | 36 | 使用 `--sf-toolbar-height` |
| 状态栏 | 24 | 状态和短操作，不重复导航 |
| Workspace Rail | 48 | 仅图标，保留悬停提示和可访问名称；资源列表另占自身宽度 |
| 资源区 | 默认 240，范围 180–300 | 优先保留中央宽度；不强行塞入所有列 |
| 辅助区 | 默认 340，范围 300–480 | 窄布局叠放；当前 900 以下使用覆盖式布局 |
| 正文分栏 | 中央区域至少 960 | 不足时回到单栏；保留用户内容和编辑位置 |
| 控件 | sm 26 / md 30 | 顶栏按钮可为 28；文本放大时允许高度增长 |
| 细边界 | 1 | 面板之间不叠加双边框 |
| 圆角 | 控件 4 / 浮层与对话框 8 | 主工作面板无外围圆角卡片 |
| 图标 | 普通控件 15，Rail 19 | Lucide 单色；不按功能分类着色 |

间距使用 2 / 4 / 6 / 8 / 12 / 16 / 24 / 32。6 用于紧凑图标组合，12–16 用于分组，24–32 用于主要章节；不要每个页面定义一套间距。

按钮和可点击目标至少提供 24 × 24 的命中区域；紧凑分隔条可以保持 1 px 可见边界，但须有足够拖拽命中区及键盘替代。

## 3. 字体与层级

| 用途 | 大小 / 字重 | 规则 |
| --- | --- | --- |
| 工作台正文、表单 | 13 / 400 | 界面基础行高约 1.6 |
| 工具栏、辅助信息 | 12 / 400–500 | 对齐比大字号更重要 |
| 次要元信息 | 11 / 400 | 不承担关键操作或错误说明 |
| 分区标题 | 13 / 500–600 | 不重复上级页面标题 |
| 项目名称 | 18–20 / 600 | 首页主标题，不扩展为宣传式横幅 |
| 编辑器 | 按编辑体验设置等宽字体 | 使用 `--sf-font-mono`，不跟随界面动画缩放 |

长名称单行截断并提供完整名称提示；正文、错误和帮助允许换行。英文长度增长不能把关闭、保存等关键操作挤出窗口。

## 4. 颜色与图层

颜色只通过 [tokens.css](../../src/styles/tokens.css) 中的语义变量使用：

| 含义 | 变量 |
| --- | --- |
| 正文、侧栏、编辑器背景 | `--sf-surface-canvas` / `chrome` / `sunken` |
| 浮层 | `--sf-surface-raised` |
| 悬停、选中 | `--sf-surface-hover` / `selected` |
| 正文、辅助、弱化、禁用文本 | `--sf-text-primary` / `secondary` / `muted` / `disabled` |
| 面板边界、控件边界 | `--sf-border-subtle` / `control` |
| 主要操作、键盘焦点 | `--sf-accent` / `--sf-focus` |
| 真实状态 | `--sf-status-success` / `warning` / `danger` / `info` |

2026-11-03 的取值如下，修改以 tokens.css 为准，并同步检查明暗两套主题和状态组合：

| 变量 | 浅色 | 深色 | 用途 |

品牌色（墨黑 `#111A17`、荧光绿 `#C6F24E`）只用于 Logo 和品牌素材，不进入界面变量。

浅色以白/灰为主，深色使用现有深灰色板。状态色同时配文字或图形含义，不能只靠颜色区分。普通文本目标对比度至少 4.5:1，关键边界及焦点至少 3:1；这是验收要求，不代表当前全站已通过测量。

阴影只用于悬浮菜单、提示、对话框或覆盖式辅助栏。主体面板无浮起阴影。层级顺序固定为内容 → 工具栏/分隔条 → 非模态浮层 → 对话框；Tooltip 在所属对话框内建立浮层，不能逃出其焦点范围。

## 5. 主题、语言与内容

- 顶栏亮暗按钮按当前实际明暗状态直接切换，只用图标与颜色反馈，不保留选中底块。语言在设置“通用”中选择，跟随系统主题在“外观”中选择。
- 设置沿用固定尺寸、固定分类栏、右侧独立滚动的模态结构；类别或语言变化不改变弹窗外框、不重新挂载表单。长文案在内容区排版。
- 新文案使用 [i18n](../../src/i18n/README.md)。日期、数量、动态文案按语言格式化；不能用 DOM 遍历替换文字。
- 用户名称、科研正文、代码、PDF 和模型回答不自动翻译。数据状态值与显示标签分开。
- Logo 使用已有明暗素材；PDF 纸张不自动反色。不得为了深色主题给整页添加反色滤镜。
- 页面滚动归内容区域，窗口外壳不滚动。右栏、列表和编辑器分别管理自己的滚动，切换视图时保留现场。
