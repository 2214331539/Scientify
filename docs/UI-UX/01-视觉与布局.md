# 视觉与布局

状态：现行标准（2026-11-14 前端重构后）。数值以源码为准：颜色在 [tokens.css](../../src/styles/tokens.css)，外壳在 `src/shell/`。设计依据见[整体重设计方案](2026-11-13-整体重设计方案.md)。

## 1. 外壳

- **一个窗口**：项目中心和项目在同一个窗口里切换。窗口默认 1440 × 900，最小 1000 × 640。Windows 用自绘标题栏和窗口按钮，macOS 用系统标题栏。
- **标题栏**（44）：左边是标志（回到项目中心）、侧边栏开关、后退、前进、位置；中间是搜索；右边在项目里是“共享”、通知、笔记、AI，在项目中心只有通知。标题栏不显示同步状态和运行中的任务，同步问题进通知。
- **侧边栏**（232）：
  - 项目中心：我的项目、团队项目；底部是账号、帮助、设置。
  - 项目里：返回、项目切换器、文献、笔记、实验、写作，下面是当前模块的资源（文献的文献库/订阅和目录树；笔记的全部笔记、回收站；实验的实验列表和当前实验的代码文件；写作的稿件文件树），底部同上。
  - 侧边栏一次只显示当前所在的一级，不把每个项目的模块重复列出。
- **主区**：圆角 10 的内容面，背景 `canvas`；外壳背景 `chrome`。
- **右侧栏**：AI 助手和笔记共用，只在项目里出现；Ctrl J 打开或收起 AI。
- **模块主区**：
  - 文献：固定的“文献库”标签页是文档表格，论文在新标签里读。
  - 笔记：左边 300 宽的列表（搜索、新建、标题加时间和摘要），右边是居中的页面（标题 26、正文最大宽 820）；主区窄于 680 时只显示一栏。
  - 实验：标题行是文字页签（实验、代码、版本、记录、环境）；“实验”是实验表格，“代码”下方输出面板的标题行放分支和 Python 解释器。
  - 写作：稿件和参考文献两个页签，主区是文件编辑器。
- **Ctrl K**：顶部居中的命令面板，没有标题和说明，Esc 关闭。
- **设置**：左侧分类、右侧分组卡片；外观用四个小窗口预览选配色；名称改动后行内出现“保存”。
- **不再有**：首页、概览、收集箱、收藏、状态栏（实验代码页的状态栏也去掉了）、图标导航栏、页面里的说明小字和快捷键提示。
- 不使用入口卡片、彩色模块图标、营销式大标题。列表、表格、树、编辑器是主要结构。

## 2. 尺寸与密度

单位为 CSS px，适用于默认字号。

| 项目 | 基准 | 说明 |
| --- | --- | --- |
| 标题栏 | 44 | `--sf-topbar-height` |
| 侧边栏 | 232 | `--sf-sidebar-width`；Ctrl \ 隐藏 |
| 页面标题区 | 上 28、下 18 | 项目中心页面；正文最大宽 1080，左右留白 40 |
| 模块标题/页签行 | 40 | `--sf-header-height` |
| 局部工具栏 | 36 | `--sf-toolbar-height` |
| 表格行 | 40（文献）/ 44（实验、记录） | 表头 32；名称下有一行说明时用 44 |
| 辅助区 | 默认 340，最小 280 | 窄窗口覆盖在主区上 |
| 控件 | sm 26 / md 30 | 主操作按钮 30 |
| 圆角 | 控件 6 / 浮层 10 / 对话框 12 | 书本封面 3 + 8（书脊一侧小） |
| 图标 | 16（侧边栏、标题栏）/ 15（按钮）/ 14（工具栏） | Lucide 单色 |

间距使用 2 / 4 / 6 / 8 / 12 / 16 / 24 / 32 / 40。按钮和可点击目标至少 24 × 24。

## 3. 字体与层级

| 用途 | 大小 / 字重 | 用在哪里 |
| --- | --- | --- |
| 页面标题 | 22 / 600 | 我的项目、团队项目 |
| 模块标题 | 20 / 600 | 文献库表格、实验 |
| 区块标题 | 13 / 600 | “在其他设备上”等 |
| 界面正文 | 13 / 400 | 列表、菜单、按钮 |
| 元数据 | 12 / 400 | 时间、计数、表格次要列 |
| 编辑器、代码 | 等宽 | `--sf-font-mono` |

界面字体是系统无衬线（Windows：Segoe UI、微软雅黑；macOS：苹方）；论文正文用 `--sf-font-read`。长名称单行截断并提供完整名称提示。

## 4. 颜色

- 三套配色共用同一组变量：**石墨**（默认浅色）、**纸**（暖色浅色）、**夜**（深色）。设置 → 外观 → 配色可选跟随系统、石墨、纸、夜；跟随系统时白天用所选浅色配色，晚上用夜。
- 界面用黑白灰和字号区分轻重；绿、黄、红、蓝只表达状态（完成、注意、失败、运行中），不作装饰。
- 项目封面只用 7 种低饱和中性色（`projectCoverColors`），旧项目的鲜艳颜色映射到其中之一。
- PDF 和网页在深色下保持纸色（`--sf-paper`），不反色。
- 品牌色只用于 Logo 和品牌素材；界面里的标志是黑白“开箱”标志。

| 变量 | 石墨 | 纸 | 夜 | 用途 |
| --- | --- | --- | --- | --- |
| `--sf-surface-chrome` | `#F4F4F5` | `#F1EFEA` | `#0E0E10` | 标题栏、侧边栏 |
| `--sf-surface-canvas` | `#FFFFFF` | `#FCFBF8` | `#151517` | 主区 |
| `--sf-surface-raised` | `#FFFFFF` | `#FFFEFB` | `#1C1C1F` | 菜单、弹窗 |
| `--sf-text-primary` | `#18181B` | `#1D1B18` | `#EDEDEF` | 标题、正文 |
| `--sf-text-secondary` | `#52525B` | `#5C574F` | `#A3A3AB` | 次要文字 |
| `--sf-text-muted` | `#71717A` | `#7A746A` | `#8A8A93` | 时间、计数 |
| `--sf-border-subtle` | 黑 8% | 暖棕 10% | 白 7.5% | 分隔线 |
| `--sf-accent` | `#18181B` | `#23466F` | `#EDEDEF` | 主按钮、选中 |
| `--sf-status-*` | 绿 `#2F7D4F`、黄 `#A5650E`、红 `#C0392B`、蓝 `#3B5BDB` | 同左（蓝为 `#23466F`） | 提亮的同色系 | 只用于状态 |

阴影只给浮层（菜单、弹出面板、对话框）和书本封面；页面里用背景层次和细线。

## 5. 主题、语言与内容

- 新文案使用 [i18n](../../src/i18n/README.md)，每个 `t()` 都要在 `messages.json` 里有中英两份。
- 界面文字有限、准确、精简：页面只放标题、主操作和内容，不写解释性小字；空状态只说“这里还没有什么”并给一个操作。
- 后端没有的数据不在界面上编造，也不放“开发中”占位入口。
- 用户名称、科研正文、代码、PDF 和模型回答不自动翻译。
- 页面滚动归内容区域，窗口外壳不滚动；切换视图时保留现场。
