## 形象是什么

**一颗会眨眼的软球**：Scientify 的标志“开箱”是一个箱子和一颗升起的圆点，AI 助手就是这颗圆点活了过来，住在你的项目里。

| 方面 | 定法                                                                             |
| ---- | -------------------------------------------------------------------------------- |
| 外形 | 正圆软球，只有两只竖椭圆眼睛，没有嘴、手和其他装饰；眼睛偏右，像在看着旁边的内容 |
| 质感 | 哑光，左上方受光，右下方透出暖色，边缘轻微压暗，底下一团柔和的影子（大尺寸才有） |
| 性格 | 安静、专注、可靠：不卖萌、不说话，只用眼神和动作表达状态                         |
| 状态 | 平时：看着你，偶尔眨眼；思考：抬眼左右看；工作：轻轻弹跳，眼睛扫动               |
| 尺寸 | 小于 24 px 时眼睛加粗，保证标题栏按钮（16 px）和页签（14 px）里也看得出是它      |
| 动效 | 系统打开“减少动态效果”时全部静止                                                 |

## 用在哪里

| 位置                     | 尺寸  | 状态                                     |
| ------------------------ | ----- | ---------------------------------------- |
| 标题栏右侧“AI”按钮       | 16 px | 平时                                     |
| 右侧栏“AI Assistant”页签 | 14 px | 平时                                     |
| 新对话的空白页           | 56 px | 平时，带影子                             |
| 回答中的进度行           | 18 px | 快速问答是思考；Agent 在调用工具时是工作 |
| 文档里的“问 AI”          | 14 px | 平时                                     |
